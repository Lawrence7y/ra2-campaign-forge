## §1218 R163 · F24 的 86.19% 是**主语错**不是算错（它测盘上语料覆盖率、被写成二进制性质）；`bounds` 的生成规则复原成一条等式，R162 遗留的「65 条指令内位移」作废

### 一 · 本轮入口与选择理由
- 从 R162 待办第 1 条进：`a2_sites` 的**生成器侧**，不再搜比值空间。
- 结果：生成器仍没找到（第五节），但**原始量测表**在盘上，且它把这数的**主语**写得很清楚。
- 判据全部可失败；正反控成对；数字先实测再填。

### 二 · 86.19% 的原始量测：主语是「盘上语料」
`R17_R95_T1_A2SITES/REPORT.md` §5.3（26,976 B / sha256 `be6d4d0f20ca18be`）逐字：

| 项 | 值 |
|---|---:|
| 扫描语料 | **4,743 份文本 EVIDENCE** |
| 提供「地址+字节+助记符」行的文件 | **961 份** |
| `bounds` 中被这些行覆盖 | **192,341 / 1,392,592 = 13.81%** |
| 其余（盘上无字节对应） | **1,200,251 条 = 86.19%** |

自洽性（本轮实测）：`1,392,592 − 192,341 = 1,200,251` 精确；`13.811727%` / `86.188273%` 四舍五入即 13.81 / 86.19。

⇒ **86.19% = 「盘上语料未覆盖」的补集**。F24 正文把这层主语丢了、写成「盘上（二进制）没有字节」⇒ **口径滑移**，不是算术错。

### 三 · 同一批地址的二进制判据给 100% / 99.992%，与 13.81% 不矛盾
- 弱判据（落在某节 `SizeOfRawData` 覆盖内）：**1,392,592 / 1,392,592 = 100.000000%**，未命中 0。
- 强判据（落在指令起始集）：R136 三实现同测 **99.992%**。
- 反控：`ImageBase` 不落在任何节；映像外 `0x900000` 不命中 ⇒ 弱判据非恒真。

⇒ 两个数**测的不是同一个东西**，R136 与 R95 之间从来没有矛盾。

### 五 · `bounds` 的生成规则复原成一条等式
三口径各自独立实现，实测：

| 口径 | 起点数 |
|---|---:|
| plain + 失败处单字节重对齐 | **1,394,120** |
| capstone `skipdata=True` | **1,394,186** |
| objdump（第三方） | **1,401,544** |

决定性结果（正反控全过）：
- `bounds` ⊆ skipdata 起点集，**缺 0 条**。
- `skipdata − bounds` = **1,594 条**，**全部**落在尾填充区 `0x7E038D..0x7E0FFF`（below-VS 0 条）。
- `1,392,592 + 1,594 = 1,394,186` 精确闭合。
- ⇒ **`bounds` == { skipdata 起点 : 地址 < VirtualSize 尾界 `0x7E038D` }**，两侧对称差 0。

反控：只有 skipdata 使「截到尾界后」与 `bounds` 逐条相等（objdump 差 **9,063** 条）；尾界 +1 ⇒ 恰多 1 条；尾界 −1 ⇒ `bounds` 侧恰缺 1 条；不截断 ⇒ 多 1,594 条。

### 六 · R162 的「65 条指令内位移」作废（基准选错，不是语义未定）
R162 的两个数本轮**逐条复现**：
- `bounds − plain起点 = 65`；
- `plain起点 − bounds = 1,593`（**全部** ≥ 尾界）；
- 65 条相对前一条 plain 起点的位移分布 **1:22 2:20 3:14 4:1 5:1 6:6 7:1**（与 R162 记录一致）。

但那 65 条在 skipdata 口径下**全部是真起点** ⇒ 它们是**数据区被逐字节跳过处**，不是「某条指令的内部地址」。R162 的「语义未定」是**基准选错**造成的假遗留。

### 七 · 切分点 `0x48948A` 是计数边界，不是内容边界
- 它恰是 `bounds` 排序后第 **192,341** 个元素（0-based 192,340）；`<= 0x48948A` 恰 192,341 条。
- R158 报的「两侧密度同族（0.3446 / 0.3428）」由此得到解释：**按秩切任何位置都得到密度接近的两段**。
- 全秩扫描（步长 2 万、**68** 个切点）实测相对差 min **0.0361%** / median **1.3992%** / max **12.8033%**；`0x48948A` 处 **0.5286%**，排第 **23.5** 百分位，**16 个切点比它更同族**（最小在秩 620,000）。
- ⇒ **密度同族不能标识这个切分点**；R158 那条形态观察不能用来判同源/异源。
