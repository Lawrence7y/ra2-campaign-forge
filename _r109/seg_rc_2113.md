### 2.113.2 owner 归因：82/277 = 29.6%（**未达目标，如实记**）
- A 槽归属：owner 直接出现在某类 vtable 槽值里 —— **66 个**（含 `jmp thunk` 跟随后仍 66）。

- 富集：随机 20000 个合法指令起点命中 A 87 (0.43%) / B 33 (0.17%) / 任一 109 (0.55%) ⇒ **54.3 倍**。
- 195 个缺口的形状：**147 个**是 call 直接目标、**48 个**调用次数为 0（只经虚表/函数指针调度），
  被调用次数中位数 **1**。⇒ 它们不是「虚方法漏了」，而是**普通函数**：既有静态调用、又不在任何虚表里。

### 2.113.3 判据 Q 判死：「按 caller 的类推 callee 的类」
想用「F 的多个 callers 都属于类 C ⇒ F 属于 C」补 195 个缺口。先在**真值集**上量，再外推。
真值集 = 5153 个「被槽值唯一反查到类」的函数（1319 个被多类共用，属继承未覆盖，排除）。
- k≥1：精确率 **1.3%**（76 例，1 对 75 错）；k≥2：**0.0%**（20 例全错）；k≥3：**0.0%**（15 例全错）。
- 多数票阈值 0.50 / 0.67 / 1.00：分别 **0.0% / 0.0% / 0.0%**。
- 只有 1 票的 56 例：精确率 **1.8%**（1 对 55 错）。
- **机制级反证**：caller 类与 callee 类同类的票 **3/618 = 0.49%**；
  随机取两个真值函数同类的基线是 **3.48%** ⇒ **实测同类性低于随机**。
- 根因清楚：真值集里大量是 `?$VectorClass@…` / 容器 / 辅助函数，被各类调用，**不属于任何类**。
  ⇒ 本条判据的方向在这类镜像上就是错的，不是「弱」而是「无效」，不得再用。

### 2.113.4 vt == [this+0]：三条独立证据（本轮正面成果）
R108 §EJ9 未取得项里「对象模型未独立证」本轮闭合。三条证据互不依赖布局假设：
1. **COL.offset 字段**（VC x86 COL 五字段：signature / offset / cdOffset / pTD / pCHD，本镜像 signature 全 0、
   cdOffset 全 0、共 954 条）：**offset == 0 的 vtable = 942/954 = 98.7%**，其余 **12 张全为 4**（基类子对象嵌入）。
2. **虚调用惯用法** `mov rX, dword ptr [rY]; call dword ptr [rX + 4k]`：**9551 个站点**，
   槽号全为 4 的倍数、284 个 distinct 槽号、最高 **第 342 槽**（落在 400 槽上限内）；
   随机 20000 个起点发火 **49（0.245%）** ⇒ 富集 2.8 倍（惯用法本身太常见，故只作辅证）。
3. **装配 + 字段读**：装配函数里「写 `[reg+0] = vt` 后同一 reg 又被 `[reg+disp≠0]` 取字段」= **1304/2438**；
   随机 2000 个起点满足同形态的 **9（0.45%）**。
辅证：`IUnknown` GUID（00000000-0000-0000-C000-000000000046）在镜像内只有 **2 处**（0x7f7c90 / 0x817bc0）。

### 2.113.5 slot 0/1/2 语义：字节特征直接定，不需要 YRpp
以往口径是「槽号→语义缺 YRpp，故取不到」。本轮改为找**构造性字节特征**：
- **slot0 = QueryInterface**：体内有 `repe cmpsd` 逐 16 字节比 IID、比对的常量含 IUnknown GUID、
  且返回码集合含 `E_POINTER 0x80004003` / `E_NOINTERFACE 0x80004002` —— **171/954 = 17.9%** 满足。
  反控：slot3..11 共 **3838** 个槽位只有 **79（2.06%）** 满足。
  实例：`AbstractClass` slot0 = 0x410260（比对 0x7f7c90/0x7f7c80/0x7f7c70 三个 IID）、
  `MouseClass` slot0 = 0x4f4240。
- **slot1/slot2 = AddRef / Release**：**88/954** 张表两槽皆为逐字节桩
  `B8 01 00 00 00 C2 04 00`（mov eax,1 / ret 4）；slot1 形态分布 stub 88 / forward 151 / inc_field 1 / other 714。
- **slot0 不是析构函数**（推翻我自己的首稿假设）：**0/954** 的 slot0 在体内把**本类**虚表写回内存
  （多态销毁才需要切回本类 vt），**0/954** 在尾部 call 释放语义（导入表 372 项里释放语义 10 项）。
