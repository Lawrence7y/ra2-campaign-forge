**背景（本轮主攻）**：R195 PX9 遗留③ 记「numContainedBases 最大 = 最外层」**无编译器侧依据**。本轮把它从「无依据」推进到「有字节判据、可被反控否掉」。

### 一 · 三层结构的字段级不变量（1214 / 954 / 2615）

**BCA 存指针不内联**：不同 BCD 地址只有 **1002** 个，槽位 **2615** 个 ⇒ 平均每结构被 **2.61** 张 CHD 共享。若按「内联 24 B 元素」误读，`arr+24*j` 落在结构中间，会读出 1071 种垃圾 ncb 值（反控 R3）。

### 二 · ncb 语义终裁：**ncb[i] == |subtree(i)| − 1**

用 BCA 顺序 + ncb 重建整棵继承树：结点 i 的子树区间是 `[i, i+ncb[i]]`，直接子结点链为 `i+1, i+1+ncb[·]+1, …` 直到 `i+ncb[i]`。

| 判据 | 结果 |
|---|---|
| 每张 CHD 恰一棵树（根恰为下标 0，覆盖全部 n 个结点） | **954 / 954** |
| 每个结点 `ncb[i] == 子树大小 − 1` | **2615 / 2615** |
| `ncb[0] == n − 1 == max(ncb)` | **954 / 954** |
| 子树大小分布 | `{1:1235, 2:804, 3:238, 4:27, 5:21, 6:22, 7:10, 8:82, 9:81, 10:49, 11:26, 12:5}`，最大 **18** |
| 分枝点（直接子结点 ≥ 2） | **117** 个，分布在 **99** 张 CHD 上 |
| 最大深度 | **10** |

⇒ **「最外层 ncb 最大」现在有字节依据**：ncb 最大项恰在数组下标 0（most-derived 视角），且等于 n−1。

**反控（同一判据下必须掉下来）**：

| 模型 | 通过率 |
|---|---|
| 真实 ncb | **954 / 954** |
| 全部置 0（全当叶子） | 256 / 954（= 只有 n=1 的链过） |
| 全部置 n−1 | 256 / 954 |
| 位置逆序 `n−1−j` | **954 / 954（同义反复，必须用分枝点否掉：其分枝点恒 0，实测 117）** |
| 单点 ncb−1 扰动 | 433 / 1380 |
| 单点 ncb+1 扰动 | 91 / 1380 |

### 四 · 阵列排布口径订正（推翻「恒 −24」）
