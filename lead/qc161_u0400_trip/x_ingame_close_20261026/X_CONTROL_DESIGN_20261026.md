## 0. 事实基线（观察成立，机制待定）

局内（战斗 60 s 后）WM_CLOSE，两趟一致（161412/200938，Guard=1+Bail=1）：
- 关窗后 **150 s 自然退出=NO**（R3 失败，2/2）——这是**回归失败项**，不是「无失败」；
- close 后**存盘采样（末 6 行 ≈+149 s 时点）exitstate=0、frame=0**（非「全程恒 0」——
  早期 close 行采而未存，见 §1b-D）；PostMessageW 返回值**未记录**（161412/200938 驱动缺陷，
  已在观测候选 v2 中补）；
- 与菜单态臂（同件同开关，hold=6 s 即关窗）行为**不同形**：菜单态 2/2 于 15.5–15.7 s 自然退出、
  exitstate 闩 1、singleton/hwnd →0。

**不得宣布**（REVIEW 点名）：不凭 exitstate 恒 0 定位断点；不凭 frame=0 断定主循环卡死的具体环节；
不把「静态可达」当「运行期必经」；不把局内两趟不外推到 200938 未采的 ws/窗口时间线。

A. 泵函数头 `0x5D4D50: mov eax,[0xB73550]; test eax,eax; je 0x5D4E66`
   ⇒ **hwnd 全局==0 时泵直接返回不取消息**（[强：字节]）。这解释 CTRL 僵尸：WM_CLOSE 处理块
   已把 `[0xB73550]` 清零（见 C），泵每次即刻返回，`cmp [exitstate],edi(1)` 恒等 ⇒ 死循环。
B. 退出序列宿主函数头 `0x6BE074 ret` / `0x6BE075 mov esp,[ebp-0x18]`，`0x6BE08C mov edi,1` ⇒
   **edi=1** 是该函数常量，`0x6BE0B6 mov [exitstate],edi` 与 `0x6BE0E1 cmp [exitstate],edi`
   用同一 edi=1（[强：字节]，与 §430 硬件断点「写值 1」互证）。
C. **WM_DESTROY 处理块 `0x7777F3..0x777828`（WndProc 分派，尾 `ret 0x10`）**——退出链真正的入口，逐条：
   **【异族审计标签修正 X3，本线独立复验：成立，含分派算式全链】**
   WndProc=`0x7775C0`（序言 `xor ebx,ebx@0x7775C8` 证 ebx==0）；分派算式（本线逐条解码）：
   `mov eax,[esp+0x18]`（uMsg）→ `cmp eax,0x18`（>0x18→0x77782B，==0x18→0x777A5B 旁路）→
   **`lea ecx,[eax-1]`（索引=uMsg−1，防 off-by-one）**→ `cmp ecx,0x13; ja 0x7779B9`（界 1..20）→
   `dl=byte[ecx+0x777A98]` → `jmp [edx*4+0x777A80]`。查表实算：
   **uMsg=2（WM_DESTROY）⇒ ecx=1 ⇒ dl=1 ⇒ table[1]=0x7777F3** ✓；
   **uMsg=0x10（WM_CLOSE）⇒ ecx=0xF ⇒ dl=5 ⇒ table[5]=0x7779B9（默认/转发路）**——
   WM_CLOSE 不直达本块，须经引擎过滤 `0x777665 call 0x778030`（返回非 0⇒0x77766E 自处理并返回；
   返回 0 才续走）+ DefWindowProc 的 DestroyWindow→WM_DESTROY 链才达本块。
   块语义逐条字节（原样）：清 singleton→调 slot0→清 hwnd→**仅当 exitstate 旧≠0 才写 2**。
   对局内分支读法（与 D 定义对齐）：**支甲=本块已执行**（链通到 DestroyWindow）⇒ 两全局已清、
   旧 exitstate=0⇒跳过写 2、其后无宿主被调；**支乙=本块未达**（0x778030 引擎过滤消费了
   WM_CLOSE / 确认层阻塞 / 链未走）。P3 post-close singleton/hwnd 三读仍为决定性变量：
   归零⇒支甲；存活⇒支乙。
   ```
   0x7777F3: mov ecx,[0x887368]      ; singleton
   0x7777F9: cmp ecx,ebx(0); je 0x777809
   0x7777FD: call [ecx]              ; slot0（析构/清理）
   0x777803: mov [0x887368],ebx(0)   ; ★ 清 singleton
   0x777809: mov eax,[0xA8EDD8]      ; exitstate 旧值
   0x77780E: mov [0xB73550],ebx(0)   ; ★ 清 hwnd 全局
   0x777814: cmp eax,ebx(0); je 0x777822   ; exitstate 原==0?
   0x777818: mov [0xA8EDD8],2              ; 非0 ⇒ 写 2（退出推进）
   0x777822: ret 0x10
   ```
   ⇒ **进入此块即清 singleton+hwnd 两全局，且仅当 exitstate 原≠0 才写 2**（[强：字节]）。
   这精确对上菜单态臂 head 观测（+0.1 s 两全局归零）与 §431「0x777818 是闩 1 后唯一出环通道」。
