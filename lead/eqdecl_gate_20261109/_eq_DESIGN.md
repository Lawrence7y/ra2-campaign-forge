## 3. (c) 三种失败型（各自独立检出，互不重叠）

设 `W` = 断言所在窗口，`E` = 显式等式/等价/集合断言标记（M1/M2/M4），
`I` = 强度标签（M3），`O` = 「仅 N 行观测」证据标记（M5 + Q3-(iii)），
`R` = 范围声明（Q4），`B` = 依据标记（Q3 四类任一），`T` = 重言半（Q1），`S` = 实质半（Q2）。
检出优先级 **F3 > F2 > F1**（一条断言只报一个最重的失败型）。

### F1 只写等式、两半都没写
**判据**：`E = True` ∧ `T = False` ∧ `S = False`（窗口内既无 Q1 标记也无 Q2 标记）。
**缺什么**：「重言半（Q1）+ 实质半（Q2）两半全缺；无 `A⊆B`/`B⊆A` 拆分」。
**真实锚点（本会话实读）**：`lead/comparability_20261109/COMPARABILITY_AUDIT.md:158`
逐字 `chain_changed=18 | unresolved_changed=18 | 集合恒等? True` —— 一行裸集合等式，
无两半、无依据、无范围。
> ★ 编排方 §4.3 S10 判它「措辞未升级为定理，风险低」；本门禁按**格式合规性**
> 仍报 F1，两者不矛盾（§5 边界会明写：格式缺失 ≠ 语义错误）。关二要求 S10 所在
> 类别「不报 F1/F2/F3」仅针对**关二的三个案例** S2/S4/S7，不含 S10。

### F2 写了重言半、实质半缺依据或依据是本批 N 行却未声明范围
**判据**（两种子型，合并为 F2）：
- F2a `T = True` ∧ `S = False`：只有重言半，实质半整半缺失；
- F2b `T = True` ∧ `S = True` ∧ `B = False`：两半都写了但**依据缺失**；
- F2c `T = True` ∧ `O = True` ∧ `R = False`：依据属 (iii)「本批 N 行」但**无范围声明**。
**缺什么**：按子型分别记「缺实质半（Q2）」/「实质半依据缺失（Q3）」/「仅 N 行观测缺范围声明（Q4）」。
**真实锚点**：`lead/layer_identity_20261109/_li_LAYER_IDENTITY_PROOF_20261109.md:146`
逐字含 `A ⊆ B` 是重言式（T=True）+ `B ⊆ A` 当且仅当…（S=True）+ 与 `P(r12|n13)=1`
是**同一个命题**（等价性断言错误）+ 结尾「`KEFF_CALC.md:314,340` 与
`EVIDENCE_INDEPENDENCE.md:310` 的『观测值非定理 / 只在这 74 行成立』才是对的」
—— 该行本身是**被纠正的错误等价式**，其整改意见指向范围声明；检测器按窗口判定，
具体实跑结果见 `_eq_full_out.json`。

### F3 把「仅 N 行观测」直接接强度标签，中间无范围声明
**判据**：`I = True` ∧ `O = True` ∧ `R = False` ∧ 二者在窗口内**相邻**（距离 ≤ 半径，
中间无 `；` 分句外的范围标记）。即：强度标签与观测证据同段共现，且该段没有
「本 74 行 / 本批语料 / 观测值 / 样本巧合 / 未验 / 95% 上界 / train=test」等范围词。
**缺什么**：「强度标签（逐字串）与观测证据（逐字串）之间缺范围声明；须补
『本 74 行观测等式』或撤回强度标签」。
**真实锚点（三关关三要求的三处，本会话实读）**：
1. S1「决定性集合等式」：`lead/metric_audit_20261109/METRIC_CONVENTION_AUDIT.md:108`
   逐字 `3. **决定性集合等式**：实跑命令 2 输出 … `set equal? True` … 18 个 id **恰好等于** …`
   —— `决定性`(I) + `实跑命令 2 输出`/`set equal? True`(O) 同段，全行无范围词。
2. S5「R12 增量 0 bit」全称：`lead/evidence_indep_20261109/EVIDENCE_INDEPENDENCE.md:149`
   逐字 `- **R12 增量判别力 = 0 bit**：`P(r12=PASS | n13=PASS) = 38/38 = 1.000`…`
   —— 数值观测 + 全称口吻，窗口内 `:148` 是先验/后验阶梯、`:150` 是负贡献，
   均无 `本 74 行` 范围词。
3. S8「38/38」：`lead/metric_audit_20261109/METRIC_CONVENTION_AUDIT.md:107`
   逐字 `⇒ `P(r12=PASS\|n13=PASS)=38/38=1`（`CHAIN_VS_SINGLE.md:206` 亦记 38/38=1.000）`
   —— 与 `:108` 同窗，`决定性` 标签在 `:108`；窗口半径覆盖 ⇒ 命中 F3。
> ★ `KEFF_CALC.md:314` 逐字「**本 74 行上的观测值，不是精确 1.000、不是定理**」
> 同时含 `定理`(I) 与 `观测`(O)，但**也含** `本 74 行`(R) ⇒ R=True ⇒ 不报 F3。
> 这是「范围声明」起作用的**负控**，检测器必须能区分。

### 三种失败型的独立性
- F1 看 `T`/`S` 两个布尔；F2 看 `T`/`S`/`B`/`R`；F3 看 `I`/`O`/`R`。
- 一条断言可同时满足多个，但**只报优先级最高者**，并在 `missing` 里列出全部缺失项，
  保证「各自能独立检出」（每条 finding 带 `all_missing` 数组，逐项独立布尔）。

## 4. 跨行段落窗口（第二步(b) 的形式定义，先在此定死）

**状态机**：按 `Q ∈ {SCAN, IN_WINDOW, EMIT, SKIP}` 逐行扫描。
1. `SCAN`：读入一行；若命中 M1–M5 任一形态 ⇒ 开一个新窗口 `W`，起点 = 该行，进 `IN_WINDOW`。
2. `IN_WINDOW`：继续吸收后续行，直到遇**硬边界**：空行、`^#{1,6}\s` 标题、
   `^---+$` 分隔线、`^```" 代码围栏。软边界（表格行 / 引用行 / 列表项）不切窗。
   相邻窗口若行号区间重叠或相差 ≤ 1 行 ⇒ 合并，避免同一段被切两次。
3. `EMIT`：对窗内所有行求 Q1–Q4 / E/I/O/R/B/T/S 布尔，按 §3 优先级产 finding，
   或按 §4(c) 判 `UNDECIDABLE` 并计 skip。
4. `SKIP`：该窗口不产 finding，仅累计 `skip` 计数与原因。

**窗口半径 `±R`**：以断言锚点行为中心，向前后各取 **R = 8 行**，且**再与硬边界取交集**
（即 `W = [anchor-8, anchor+8] ∩ 当前硬边界段落`）。
**为什么是 8**（本会话实跑，非拍脑袋）：
- 命令：`python -I -X utf8 -c "<扫 8 个只读目录全部 .md；按空行/标题分块；量测块内
  『重言半标记』与『实质半标记』的最小行距>"`；
- 输出：`n_blocks 958 / max_block_len 76 / median 3.0`；
  同时含两半标记的块 `42` 个，距离分布
  `[(0,32),(1,4),(2,2),(5,3),(8,1)]`，**最大距离 = 8**。
- 最远实例：`lead/tautology_audit_20261109/TAUTOLOGY_AUDIT.md` 第 386–400 行块
  （T 在 `:388`、S 在 `:396`，距离 8）—— 正是 §4.2 第 2 处「逐处判」的跨行两段式。
- ⇒ R=8 覆盖**已观测到的全部**真实跨行两段式，且小于最大块长 76，不会把整节吞进来。
  R=8 是**本语料上的经验值，不是全称定理**；换语料须重测（见 §5 边界）。

## 5. (c) 「无法判定」的 skip 判据（宁可报无法判定也不许猜）

**skip 判据**（满足任一即 skip，不产 finding，只计数）：
- K1 `E = False` ∧ `I = False`：既无显式等式/等价/集合断言（M1/M2/M4）、又无明显
  强度标签（M3）⇒ 该行不是恒等类断言，跳过。
- K2 命中 M3d `恒等` 但 `E = False` ∧ `O = False` ⇒ 只是别论域的「恒等」措辞
  （`TAUTOLOGY_AUDIT.md:609` 自记 GOAL 台账 46 行属别论域），跳过。
- K3 `I = True` ∧ `E = False` ∧ `O = False`（如 `METRIC_CONVENTION_AUDIT.md:290`
  「是否定理 ⇒ 未验」是**提问**不是断言）⇒ 无法判定断言对象，跳过。
- K4 窗口内 `T = True` ∧ `S = True` 但依据标记 `B` 与范围标记 `R` 同时矛盾
  （既写「本 74 行」又写「全称定理」且无消歧）⇒ 标 `CONFLICT`，跳过并计数，
  不猜哪一边对。
- K5 引用/转述行：整行是 `> ` 引用或含 `→ 改` / `须撤回` / `判错置` 的**整改意见行**，
  且窗内无本件自己的等式锚点 ⇒ 跳过（避免把「引用别人的错误」当成「本件犯错」）。
  ★ K5 只豁免**纯转述**；若该行自身含 M1 等式且带强度标签（如
  `LAYER_IDENTITY.md:376` 的整改表），仍进判定，只是 `R` 通常成立。

**skip 计数**：按 `{K1, K2, K3, K4, K5}` 分桶统计，落 `_eq_full_out.json` 的
`skip_by_reason`；`skipped_total` = 各桶之和。每条 skip 保留 `file:line` 与原文行，
保证「任何一条命中都必须附 file:line 与命中的原文行」对 skip 同样成立。

★ **自证要求**：检测器对每条 finding 必须输出 `file:line`、逐字原文行、
命中的形态串（哪个 M 子形态）、命中位置、以及 `all_missing` 的逐项布尔。
取不到原文行（如文件读失败）⇒ 报 `UNDECIDABLE` 并记 `read_error`，**绝不猜**。
