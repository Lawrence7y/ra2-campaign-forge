=== D. HOW REFUTING QUOTES ARE EXCLUDED FROM THE FIX LIST (R5) ===
1) needle inside a paired quote span (「」『』``) AND a negation/update
   lexicon hit on the SAME line => role != ASSERTION => needs_fix=False.
2) '改后' samples with 更新：/已定谳为/自该节起不再成立 but no quote => UPDATED_SAMPLE.
3) grep/命中/验收/逐字/原文逐字/改前/建议改 => ANALYSIS_MENTION, never ASSERTION.
4) A refuting quote INSIDE an appendable block (e.g. §609 :22) is KEPT in
   section A with risk=HIGH but role=REFUTING_QUOTE: full audit trail,
   without inflating the fix count. It is NOT silently dropped.
5) needs_fix requires BOTH role=ASSERTION AND risk=HIGH.
   Outside-block assertions (:215 §6.3) and standalone terminal docs
   get risk=NONE, matching MINHARD_SET_CHECK.md §3.2/§3.3.
