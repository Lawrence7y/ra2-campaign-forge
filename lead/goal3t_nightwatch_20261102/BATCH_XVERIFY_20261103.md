## ① 实现要点

按任务书定义逐字实现，未做任何"调整口径"：

| 量 | 实现 |
|---|---|
| T | 0.1 秒 |
| 平台 | `f` 值相同的连续样本段（闭区间 `[i,j]`） |
| 平台时长 | `t[j] − t[i]`（该平台最后样本 t − 第一样本 t） |
| 计入条件 | 严格 `> 0.1`（等于 0.1 不计入） |
| B% | `100 × Σ(计入平台时长) / (t[-1] − t[0])` |
| 有推进 | `∃k≥1: f[k] != f[k-1]` |
| freezeStart | `t[lastEdge] − t[0]`，`lastEdge = max{k: f[k]!=f[k-1]}` |
| 最长段占 | `max(计入平台时长) / Σ(计入平台时长)` |
| 单段主导 | `最长段占 > 0.80 且 B% >= 25` |
| 帧沿缺口 | `Σ_{f变化处 且 Δt>10ms} (t[i]−t[i-1]) / span × 100` |
| Pearson | 手写 `Σ(x−x̄)(y−ȳ)/√(Σ(x−x̄)²Σ(y−ȳ)²)` |
| Spearman | 手写平均秩（并列取平均秩）+ 上述 Pearson |

**口径 B 的一个关键性质**（影响 C5 解读，见下）：当窗内只有**一个**超 T 平台、
且该平台是**末平台**（起点即 `freezeStart`）时，
`Σ(计入平台时长) = t[-1] − t[lastEdge] = span − freezeStart`，
恒等式**代数上必然成立**（残差 0）。

**实测确认**该结构：15 个单段主导窗中——
- **f[0]!=0 的 12 窗：占主导平台全部是 LAST 段**（首段长 0.000–0.030s，均 <0.1 被排除）；
- **f[0]==0 的 3 窗：占主导平台全部是 FIRST 段**（首段长 2.556 / 3.209 / 3.778s，
  即"开局卡在帧 0"的那一段），与 `span − freezeStart` 无关。

这解释了 C5 的 12/12 与 0/3：它不是"判别规则有效"，而是上述结构的**算术后果**。

|---|---|

## ⑤ 反对意见

1. **C2 的集选择未在结论中声明，是隐性口径。**
   申诉值 −0.0403/+0.0395 只在 64 个 moving 窗上复现。若用全部 97 个有效窗
   （任务书"有效窗"的字面定义），得 `ρ(window)=+0.347`、`ρ(t0)=+0.346`，
   **符号翻转、量级 ×8.6**。任务书 C2 未写"限于 moving 窗"，而 C1 明写了"在有推进的窗上"——
   两者措辞不同，暗示 C2 可能不限于 moving。我按"能复现申诉值的口径"判 MATCH，
   但必须指出：**C2 的结论对窗口集合高度敏感**，"时间相位不驱动"这一物理结论
   在 97 窗全集上得不到支持（反而显示中等正相关 0.35）。
   这条 MATCH 是**数值 MATCH**，不是**结论稳健**。

2. **C3 的"31.1–34.0"区间像是先看数据再画的边界，且画在了数据点上。**
   12 个窗的 min 恰为 31.099081，与下界 31.1 相差 0.0009。任何"目测取整"都会
   把 31.099 写成 31.1 并宣布通过。这正是任务书要求"任何一例不符即 MISMATCH"要防的情况。
   我不接受"31.099 ≈ 31.1 所以通过"。

3. **C4 的 ws_delta_freeze 有采样混叠污染，0.670 是伪相关（已实测）。**
   4 个 freezeStart<1.1s 的窗，`ws@fs` 与 `ws@0` 落在同一 counters 采样点（粒度 1s），
   delta 恒为 0。这使 delta 的秩结构被"fs 小 ⇒ delta=0"主导，产生伪 Spearman。
   **实测**：剔除这 4 个零 delta 窗后（n=8），`ρ = −0.047905`——伪相关完全消失。
   （被剔除：`archive_T34/measure_w0`、`l1_20261023hc/measure_w0`、
   `archive_T38/measure_w1`、`archive_T39/measure_w1`）
   但**任务书没有授权剔除**，且"看到 rho 高再剔窗"属事后选择，我不能这么做。
   所以判定仍为：按定义算得 **0.670361 → MISMATCH**。
   证据强度需打折：这**不能**用来断言"存在真实触发指示器"，
   只能断言"`ws_delta_freeze` 未通过 |ρ|<0.6 的门槛，故'没有任何候选量 |ρ|>=0.6'不成立"。
   真正的实质问题是：**1 秒粒度的 counters 无法分辨 <1s 的 freezeStart**，
   这 4 窗上 `ws_delta_freeze` 是**不可测量**而非"等于 0"。

4. **`f_rate_last1s` 在 12 窗上恒为 0（零方差），Spearman 无定义（nan）。**
   这不是"ρ 很小"，而是"该量在冻结后完全无变化"——因为冻结窗最后 1 秒本来就没有帧推进。
   把它当作"候选量不相关"是**没有信息量**的，不应计入"7 个候选量都通过"的证据。
   申诉方若把 nan 当"通过"，属统计误用。

5. **C5 的恒等式是代数恒等，判别力有限。**
   已实测其机理（见①末）：f[0]!=0 的 12 窗，唯一计入平台**就是末平台**（起点 = freezeStart），
   故 `B% = 100×(span−freezeStart)/span` **必然**成立、残差恰为 0；
   f[0]==0 的 3 窗，计入平台是**首平台**（开局卡帧 2.5–3.8s），与 `span−freezeStart` 无关，
   故**必然**不成立。
   即：C5 的 12/12 与 0/3 **不是"规则有效性"的证据**，而是
   "该子集恰好由末平台主导/首平台主导"这一结构的算术重述。
   它对 f[0]==0 的区分能力，来自"卡在 0 帧"这一段落在窗首而非窗尾，
   而非来自任何物理判别规则。**结论成立，但证据的证明力被高估了。**

6. **我无法核验的部分**：`units_at_freeze` / `techno_at_freeze` 的"t_rel 最接近"取法，
   我采用 `min |t_rel − fs|`；若被核验方用的是"≤ fs 的最后一个采样"（前向保持），
   结果会不同。任务书写的是"最接近"，我严格照此实现。
   该差异可能影响 C4 中 `units_at_freeze`（我算 0.011）与 `techno_at_freeze`（0.396），
   但两者都远低于 0.6，不改变 C4 的 MISMATCH 结论（该结论由 ws_delta_freeze 单独支撑）。
