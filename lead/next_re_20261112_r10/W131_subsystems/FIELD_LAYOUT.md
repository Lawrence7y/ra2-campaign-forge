# 关键结构条目（milestone 4）

每个对象的字段按"被多少个方法触碰"排序（touch = reads + writes）。
来源：反编译后统计 `this` 相对偏移的访问；read/write 由赋值方向判定。
**这不是猜测的字段名，而是代码真实访问过的偏移。**
