# R17-R8-RESIDUAL — residual / 下一步

## 结论速览
- **Q1 有结论**：0x43F180 唯一静态引用 = `.rdata:0x7E3FE0`（函数指针表 slot #0）；0x449440 唯一静态引用 = `.rdata:0x7E4068`。两者 `E8` 命中 0 ⇒ 虚派发。全镜像 4B 扫描（4,817,024 B，已声明）。
- **Q2 有结论**：`0x47C620` 入口 `A1 AC E7 A8 00 …`，**精确尾界 = 0x47CA7C**（最后 `C2 0C 00` @0x47CA79，其后 4×`90`，0x47CA80 为新函数）。**非单 epilogue**：1 个成功 epilogue（0x47CA70→0x47CA79，al=1）+ 9 个 early-exit 尾巴（al=0；0x47CA4A 返回查表值）。
- **Q3 部分有结论 / 语义未取得**：可字节证实 —— thiscall、读 `[esi+0x418]`、经 `[vtbl+0x274]` 派发 `0xD`、`ret 4`、返回值在该路径被 `xor al,al` 丢弃、无字符串引用。“失败播报/音效”**仅为推断，强度中**。
- **Q4 有结论**：case 0（0x43F1CA，12 条指令 0 跳转）与 case 2（0x43F9A6，15 条跳转全在块内）**都不产生拒绝**，恒 `al=1 / ret 4`，都不写 `[esp+0x23]`，都到不了 0x43F5D8。

## 一致性核对（与 R7）
- `[esp+0x23]` 命中数 = **3**（0x43F24B / 0x43F501 / 0x43F5AD；指令首字节 0x43F249 / 0x43F4FF / 0x43F5AB）—— **与 R7 一致，差集为空**。
- 到 `0x43F5D8` 的跳转源 = **恰 2 条**（`0x43F220 jne` / `0x43F5B1 je`）—— **与 R7 一致**。口径提示：`0x43F5E0` 是另一个失败出口，按“拒绝出口”整体口径计为 3 个位置，数值本身不冲突。

## 本卡踩坑记录（供后续审计）
- 锚点规则须“终止符优先”：首版把 90 判断放在 C2 之前 → 0x43F1E9 被判无锚点（0x43F1E8 = `90` 落在 `C2 04 00` 的立即数内）。
- 节边界须按 rawsize：首版用 `max(vsize,rawsize)` → .text 吞掉 .rdata 起头，0x43F1E9 附近字节读成 `00 00 00`。
- `0x47CA6E+2` 直接起步会解出 `add byte ptr [esi-0x16ffbc07], ah`（R7 已实测，本卡复现）：正确入口是标签 `0x47CA70`，由 `0x47CA6A 0F 85 61 FC FF FF` 跳入。
