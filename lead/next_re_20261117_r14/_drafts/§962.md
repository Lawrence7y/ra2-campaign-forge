### 一、本节最有价值的结论 —— 「无独立位图」是用等价形式搜索验出来的 `[已证]`

执行员原结论「迷雾不是独立位图」与 RTS 常识（迷雾通常是一张 1 bit/格位图）相反。审计没有直接采信，而是**按纪律 18 做了五类等价形式搜索，且先做基线测试再判否**：v1 检测器被基线证明为瞎（`[全局+reg*1]` 全二进制 0 条），重写检测器后重跑，五类结果逐条如下。

| 搜索形态（全 `.text`） | 命中 | 结论 |
|---|---|---|
| `idx>>3` → `[reg+全局址]` | **25** | 全部指向 `0xB45BA8`，那是 **18 位标志集**（`cmp edx,0x12` 清位循环 + `or al,0x40`），**不是** `0x8000` B 位图 |
| `idx=(Y<<9)+X` → `[reg+全局址]` | **18** | 全是 `[eax*4+0x89F688]` 类 **8 邻域偏移表** |
| `bt/bts/btr/btc` 落绝对全局 | **0** | 全 **4 处都在 `[esp]`** |
| `push/mov imm=0x8000`（＝ `0x40000/8`，1bpp 精确尺寸）| **10** | 全是 CRT / HeapAlloc / DirectDraw / `0x100×0x80` Surface |
| `push imm=0x40000` | **2** | ① `0x565B87` 格指针向量 Resize；② `0x5FF769` → `[0xAC1838]` 是 **`0x10000` 项 × 4 B 调色板重映射表**（`cmp ebx,0x10000`、`mov [edx+ebx*4]`，用后 `0x7C8B3D` 释放） |

⇒ **确实没有独立 shroud/fog 位图。** 另：雷达自身有一个 1bpp 缓冲 **`+0x1274`**（`w·h/8`；簇内 8 处访问），但那是**雷达脏位图**，与迷雾无关。证据：`S08-K1\_audit\VERDICT.md`:23-32（§2 专段，基线见 :24、五类表见 :27-31、`+0x1274` 见 :32）；`S08-K1\_audit\E_audit_log.txt`:34-113（a06/a07/a08 检测器 D1b :35-60、D2b :62-80、D5 :82、D1c :83-113）、:134（`+0x1274 : 8 hits`）；分级 `[已证]`。

**方法学段（写进正文）**：这是 R14 里「**否定性结论用等价形式穷举 + 基线测试**」的**第二个范例** —— 第一个是 W173 对「`LayerClass::Add` 不经虚表派发」的**六类调用形式**全 0 才判否（① `jmp [reg+0x1C]`；② 绝对槽 `0x8A037C/…` 的 `call/jmp`；③ `mov r2,[x+0x1C]`→`call r2`；④ `lea r2,[reg+0x1C]`→`call [r2]`；⑤ `add reg,0x1C`→`call [reg]`；⑥ 数据段层数组指针）。本卡把范式从「调用形式」换成「位图载体形式」（位索引 / 行索引 / 位指令 / 1bpp 精确尺寸立即数 / 全量尺寸立即数），并**先以基线测试证明检测器不瞎**再下否定结论。⇒ 今后凡「不存在 X」类结论，须按此范式：基线自检 + 多类等价形式全 0，方可标 `[已证]`。证据：`S08-K1\_audit\VERDICT.md`:24、:46（§7 末「审计补齐五类搜索后该结论加固为成立——结论不改，取证等级须改写」）；`R14_COMMON.md`:346（纪律③）；`_drafts\§939.md`；`STATUS_BOARD.md`:196。

### 三、雷达「非每帧全量」成立，但两处字节级错 `[已证]`

**结论成立**（雷达确实不是每帧全量重绘）：脏门机制 `0x65715C`..`0x6571C3` 逐字节成立，增量路径 `0x6574C3`（脏矩形）/ `0x657520`（脏点倒序），全量仅 `0x657CE0`（10 调用点/10 函数）。但执行员两处字节判定错：

⇒ **纪律问题**：未与字节目标对齐，违**纪律 8**（先测基线、目标须实测）与**纪律 9**（数字/目标须与字节逐条核对）。
