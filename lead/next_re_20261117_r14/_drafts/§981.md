### 二、GetSize 定位（off0 slot9）

**穷举结论** `[已证]`：扫全 12 类 30 张表 770 槽，`B8 imm32 C3` 命中 **11** 处，**全部**位于 off0 主表 **slot9**；off4 slot12 **无一处**命中。叠加「值确在本类 vtable 槽」后裸判据 666→11，才具区分力（`EVIDENCE/fresh_core.txt:66-77`、`EVIDENCE/fresh_slots.txt:105-117`、`_audit/VERDICT.md:9,22`）。

| 类 | off0 slot9 地址 | imm=sizeof（十六进制） | 工厂 `push<size>;call new` 编码 | 闭合 |
|---|---|---|---|---|
| Drive | 004B4CF0 | 0x70 | 6A 70（imm8） | ✓ |
| DropPod | 004B66E0 | 0x30 | 6A 30 | ✓ |
| Fly | 004D0390 | 0x60 | 6A 60 | ✓ |
| Hover | 005172B0 | 0x78 | 6A 78 | ✓ |
| Jumpjet | 0054DF90 | 0x98 | **68 98 00 00 00（imm32）** | ✓ |
| Mech | 005B1B40 | 0x34 | 6A 34 | ✓ |
| Rocket | 006635B0 | 0x60 | 6A 60 | ✓ |
| Ship | 006A42A0 | 0x70 | 6A 70 | ✓ |
| Teleport | 0071A120 | 0x4C | 6A 4C | ✓ |
| Tunnel | 0072A200 | 0x3C | 6A 3C | ✓ |
| Walk | 0075CBD0 | 0x3C | 6A 3C | ✓ |

**双点闭合 11/11** `[已证]`：A 点=各类 off0 slot9 imm；B 点=各厂 `push<size>→call 0x7C8E17(operator new)→ctor 装本类三表`，逐类 `size==imm`、11/11 精确相等且 11 类 ctor / CreateInstance **全互异**（非同一 ctor 重复计数）。§972 陷阱复现：只扫 imm32 会漏 10 处（`EVIDENCE/fresh_closure.txt:28-43`；`_audit/VERDICT.md:10,22`）。

**imm 确为 sizeof 的独立佐证** `[已证]`：11 个 ctor 字段写入上界**全部 ≤ size**（DropPod/Jumpjet/Teleport/Walk 恰 =size）；基类 off0 slot9 返 0（纯虚桩）。⇒ imm 是对象真实跨度，非版本/标志常量（`_audit/VERDICT.md:19`）。

**巧合量级** `[已证]`：基线 666 处裸 `B8 imm32 C3` 中仅 **118（17.7%）** 的 imm 落在「926 个 `operator new` 前 `push` 尺寸集合（106 值）」内 ⇒ P(11/11 巧合)≈0.177¹¹≈**5.4e-9（1/1.9e8）**；按逐值经验频率严格算≈**1.1e-20（1/9e19）**；反向穷举 770 槽仅 11 命中且全在 slot9（`_audit/VERDICT.md:20-22`、`_audit/c2_baserate.txt`）。

**保留项** `[静态推断]`：全镜像 `call [reg+0x24]; push eax` **0 处**，「有调用者把它当 size 用」仍静态推断，不影响双点闭合分级（`_audit/VERDICT.md:19`）。

**惯例改述（改述而非废除）** `[已证]`：旧「`GetSize = v[12]`」只是 `AbstractClass` 派生类的取值，不是通则。新表述：「**GetSize/Size 是基类虚函数链之后返回 sizeof 的那个虚函数，槽号随前置虚函数数变化（AbstractClass 族 `v[12]`、ILocomotion COM 族 off0 `v[9]`）；必须用『imm == 工厂 push size』双点闭合定位，禁止固定槽号套用**」。受影响面：只有多接口 COM 类（本族）需改法，其余子系统仍可用 `v[12]`；无 sizeof 访问器的 4 类不得强套 `v[12]`（`_audit/VERDICT.md:36`）。

**收紧判据：`v[11]` 与 `v[12]` 同形风险** `[已证]`：**69/78** 类 `v[11]` 与 `v[12]` 同为 `B8 imm32 C3`（`v[11]`=`WhatAmI`、`v[12]`=size），纯字节形态有取错槽风险 ⇒ 全项目收紧为「必须闭合」（`_audit/VERDICT.md:36`；台账 §969/§975 同类结论）。

**反例实测：`B8 imm32 C3` 本身不特异** `[已证]`：`FootClass`/`ObjectClass`/`RadioClass`/`MissionClass`/`TechnoClass` 的 **slot35/36** 返回 `0x7FFFFFFF`、`0x8182E0`（`.data` 地址），说明裸形态既会命中尺寸也会命中非尺寸常量 ⇒ 真判据是双点闭合；执行员 `LAYOUT §3`「判据不特异已处理」表述**正确**，写入本节（`_audit/VERDICT.md:22`；`LAYOUT.md:50`）。
