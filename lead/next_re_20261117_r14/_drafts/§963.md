### 一、为什么会有这张卡（先写）

**`noinit_t` 误剔已确认复发两次** —— C09 错剔 **15** 处（`§942`，high 423→438）、C08 错剔 **9** 处（`§960`，high 408→417）—— ⇒ 判定为**系统性缺陷**，不能按片逐个补数，必须全量排查。`[已证]`（两处错剔数经 YRpp 原文行号与双向核对闭合）证据：`N_FIX\PROGRESS.md`:5、`N_FIX\BASELINE.md`:46-47、`N_FIX\IMPACT_BY_CARD.md`:134、:148；`_drafts\§942.md`、`_drafts\§960.md`。

**错源机理** `[静态推断]`（由 YRpp 文本行形态推出，`N_FIX\BASELINE.md`:33-35、`N_FIX\PROGRESS.md`:47）：YRpp 里 `JMP_THIS(0x...)` 常位于**委托初始化行的下一行**：

```cpp
SomeClass(noinit_t()) : BaseClass(noinit_t()) { }   // ← 提取器取走这一行的 "SomeClass"
JMP_THIS(0x6CAF90);                                 // ← 真地址在这行
```

提取器把 `: SomeClass(noinit_t())` 当函数名并给 `low`，导致**真实具名构造器被整批降级**（不计 high）。`noinit_t` 桩自身是 `explicit __forceinline … { }` 空内联桩、无机器码地址（`N_FIX\SUMMARY.md`:41）。证据：`N_FIX\BASELINE.md`:33-43、`N_FIX\EVIDENCE\scan_noinit_raw.txt`:6-8、:15-17。
