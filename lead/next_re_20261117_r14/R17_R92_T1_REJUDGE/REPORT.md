## Q2 · 按新口径逐件重判（落 `rejudge1242.tsv`）

### 2.1 盲区A 的修法：地址同时接受 `0x` 前缀与裸十六进制

```python
ADDR_PREFIX = re.compile(r"0[xX][0-9A-Fa-f]{6,8}")                        # 旧正则，保留
BARE        = re.compile(r"(?<![0-9A-Za-z_])([0-9A-Fa-f]{6,8})(?![0-9A-Za-z_])")  # 新增
```

**怎么避免把普通数字误当地址——四道闸（全过才算地址）**：

| 闸 | 规则 | 拦住的东西 |
|---|---|---|
| (1) 位数 | 6–8 位（卡里给定；gamemd.exe 的 VA 空间 `0x00400000`–`0x00A00000` 全落在此区间） | 1–5 位小整数 |
| (2) 纯数字 | 不含 `A-F` 的 6–8 位十进制，**只有落在 `.text` VA 区间 `[0x00400000, 0x00B00000)` 才收** | `1234567`、`20261117`、`398` 这类计量数 |
| (3) 大小写一致 | 含字母时须**全大写或全小写**（`entry=00524D70`、`ROW 00459900` 都是全大写）；混合大小写只在 `hex=`/`dump`/`字节` 语境才收 | `0aB12Cd` 这类哈希碎片 |
| (4) 上下文锚 | 须紧贴 `entry= / target= / callee / call / site / @ / off= / rva= / va= / ptr= / base= / addr= / slot / 地址 / 入口 / 站点 / 偏移 / 槽`，**或**落 `.text` VA 区间 | 随机 8 位十六进制单词 |

另补一条降误判：**十进制 VA 对** `[4198410, 4223232]`——要求一对里两个数**都**落 `.text` VA 区间且 `b >= a`，这样能收 JSON 里的地址对，同时拒掉 `[K=73, N=387]`、`[n=642, mine=0.199]` 这类计数/比例对。

### 2.2 盲区B 的修法：单行大文件按内容分隔符切段

```python
def segments(t):
    s = t.replace("}{", "}\n{").replace("},\n{", "}\n{")
    parts = [p for p in s.split("\n") if p.strip()]
    if len(parts) <= 1:                     # 既无换行也无 }{ 的单行件
        parts = [p for p in re.split(r"[;]", s) if p.strip()]
        if len(parts) <= 1:
            parts = [p for p in re.split(r'"\s*,\s*"', s) if p.strip()]
    return parts
```

**分母一律是「段数」**，不是行数。`q3_cfg.json`（846,854 B、0 换行）因此从「分母 1」变成 **34,729 段**。

### 2.3 判决流程（三问，内容优先）

```
R2  无段（全空白）                                → 过程（连内容痕迹都没有，只留「跑了一次」）
R3  以 {"sha":… 开头（发布元数据头）               → 过程（我核的是哪个二进制 + 哈希 + 规模）
R4  末段是「声明了内容的小节头」且其下无被指向内容  → 永久判不了（证据不完整）
R5  n_rev>=5 ∧ n_obj>n_proc ∧ obj段占扣封装后>=40% → 对象抄本
R6  其余且 n_obj>0                                → 过程（§2.49 问1 末句：不能回原址复核的降为过程）
R7  其余且 n_proc>0                               → 过程
R8  其余                                          → 永久判不了
```

- `n_rev`＝「地址/偏移 ↔ 值/字节/符号/字段」**同段并存**的段数（可回原址复核）；
- 运行封装行（`RUN_ID:` / `COMMAND:` / `CWD:` / `TIMESTAMP_LOCAL:` / `EXITCODE:` / `BEGIN RAW STDOUT`）**先剔除再算分母**——§2.49 只把运行时痕迹当痕迹，不当分界，但也不把它算进「对象内容」；
- 「值」的形态包括：连续 ≥4 个两位十六进制字节、反汇编行（`00524D70: push ecx | 51`、`+0x0000 83ec0c sub esp, 0xc`）、`Class::name` / `.?AV` 符号、`[reg+0xNN]` 字段位移、JSON 的 `"hex"/"a"/"entry"/"lo"/"hi"` 键、字节转储行（`0x010 C 0D -> 0E`）；
- 「统计量」段（`"K": 73`、`n=642`、`{'BUCKET': 120}`、`UNDECIDABLE 5598`、纯数值表行）**不算对象内容**，算过程——那是我数出来的，对象里不存。
