- 主索引：`FACT_INDEX.tsv`（TSV，5 列；表头 fact_id / statement / grade / evidence_paths / limitations），按 fact_id 排序（F01-F21）。F01-F16 为原版编号与顺序，新增 F17-F21 追加在后，不重排。

- `evidence_paths`：原有行相对仓库根；新增行沿用卡面给出的 run 内相对路径。括号内为节号/事项号/行号，便于回查。只做提取与归类，不新增技术结论。

## grade 含义
- `[已证]`：字节级/计数已在来源中给出并可回查。
- `[静态推断]`：依赖单源或未做动态取证，按 2.8 规则B 标注、不得升格。
- `未取得`：来源明确写“未取得”或事实层面未拿到（F09 调用方、F16 语义/身份；F21 的表内容）。
- `[流程]`：方法学/流程规则，非技术结论，不参与 `[已证]` 计数（F13、F20）。

## 必须带限定引用的行（limitations 非空；F20 以 `—` 表示无同引约束）
- 几乎每行都有必须同引的限制；以下尤其不可拆：
- F02：309 是连续 `.text` dword 长度、含重复值，不是“309 个不同函数”；槽内实测值须与槽号同框。
- F04 调用方链：只证“至少一个派发点到达”，不证唯一/不证运行期执行；不改 2.9 收口。
- F05 覆写+显式调：只证指令层 this 传送，不提供行为层区分证据、不升格。
- F07/F08/F17 2-b：定谳句 + a-e + 2.10 (a′) 是不可拆引用单元；引 (a)/定谳句须一并引 (a′) 与 a-e。F17 只记“旧写法适用范围被收窄”的字节事实，不得据此判 ②-b 升格。
- F09 调用方未取得：不得写成“不存在调用方”；不证全局/唯一/运行期；须带 2.8 规则A 正反控。
- F10 静态不可达：照抄“静态未发现任何到达路径”，不断言死代码；不改 2.9 收口。
- F11 双口径：引用必须写明 S/C 口径，只写数字不写口径即不可引用；旧值须同引 1062。
- F12 433：只说明地址锚定，不支持改判；COVERAGE_ONLY 不等于名字错；三桶须带 R19 三条限制。
- F13/F20 方法学：入口判定禁止按字节扫 C3/C2；报“调用了 X”不能只报存在性；VA→文件偏移必须走 PE 节表。
- F15 与 conflicts.md C01 联动：108/82/4/33 为已取代草稿的中间态，129/125/5/19 为台账正本与看板同值；C01 已改标“假冲突（已澄清）”。
- F18：`[已证]` 只覆盖用例数与观测数，归因结论不得写 `[已证]`；D 用例是不可构造/未观测到、不是判据不存在；A 组 4/6 为前卡读数、非本卡复现；观测数不得外推为行为唯一。
- F19：“已排除”只针对所声明的具体形态与扫描范围；不得引申为“不存在调用方”。
- F21：表内容静态不可见，不得声称已看到表项；不改变 ②-b 收口。
- 只有当引用的是 (a)/定谳句的文本时才触发“须同引 a–e + (a′)”；只写“不改变 ②-b 收口/grade”不触发，但不得改写成对 (a) 内容的复述。
