# FEED_W177D — 给真机卡的可观测清单（S12-K2 静态支撑）

**静态结论**：同格多对象在静态上**可能**（`[静态推断]`）——`0x47E8A0` 不查占用，且 `0x47C620` 只扫 head A(`+0xE4`)，不扫 head B(`+0xE8`)。真机需要判定的是：正常放置路径是否实际把第二个对象链入同一格，尤其 head B / 绕过 can-place 的路径。

## 构造/判证建议（供 W177-D 设计，不改内存/Hook）

1. **证实路径（优先）**：先按 W177-C 已成功的两步建造流程进入 ghost；在最终放置前后各读一次目标格 #3/#4/#5/#6/#9。若 ghost/建筑对象的 `[+0x8C]!=0` 且落入 B 链，而 A 链仍有原对象，则满足静态旁路条件 #4+#9；链长 ≥2 即证实。
2. **证伪路径**：若所有可观测放置对象的 `[+0x8C]==0`，且每次成功放置前后目标格 A 链长度始终 ≤1、B 链恒 0，则支持“引擎通过 can-place + head-A `0x47C620` 拒绝重叠”，与 W177-C 真阴性一致。
3. **开关解释**：同时记录 #11/#12/#13；若 #11 非 0 或 #12 为 0，则不能把“无重叠”归因于 `0x47C620` 的 WhatAmI 扫描。
4. **拒绝行为**：W177-C 已证“拒绝 + 保持 Limbo”（§959）。本卡补充：拒绝来自 `0x43F218`/`0x43F678` 返回非零 → `0x43F5D8`/`0x43F5E0` 令 `al=0 ret`；或 `0x47C620` 逐格失败 → `0x43F504` 跳下一格；不要把逐格失败误读为立即整体返回。
5. **停机条件**：若链遍历出现环（对象地址重复）或指针落在非映射区，停止该次采样并报原始地址，不要自行推导链长。
