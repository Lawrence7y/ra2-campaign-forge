## §0 结论

1. **§522 的数值逐位复现**：64 moving 窗 `ρ(uptime,B)=+0.0395`、`ρ(window,B)=−0.0403`。
2. **§528 异族指出的 97 全量口径也逐位复现**：`ρ(uptime,B)=+0.3461`、`ρ(window,B)=+0.3474`。
3. **⇒ §522 与 §528 的矛盾源于「窗口集选择」，不是 BOOT 混杂。**
   按真实 BOOT 重算**没有改变任何一个数值**——因为原计算本来就没按 BOOT 分组。
4. **★ BOOT 内相位方向混乱**：可算的 8 个 BOOT 中 **4 负 / 2 正**，中位 +0.4472。
   **没有任何一致的时间相位效应。**
5. **BOOT 间** `ρ = −0.2369`（n=11）——弱负相关，样本仅 11，不足以下结论。

---

## §1 方法

- BOOT 反推：`boot = round(t_abs0 − samples.t[0])`，**先取整再聚类**（避免浮点边界误差）。
- 聚类容差 ±2s（链式比较，与组内最后加入者比，避免累积漂移）。
- 三个层次分别算：
  - **P1 全量**（不控 BOOT）→ 复现原值
  - **P2 BOOT 内**（每个 BOOT 单独算）→ 看相位效应是否在 BOOT 内也存在
  - **P3 BOOT 间**（用每个 BOOT 的均值）→ 看是否只是 BOOT 层面的差异

探针：`_phase_recompute.py` → `_phase_recompute_out.txt`。
