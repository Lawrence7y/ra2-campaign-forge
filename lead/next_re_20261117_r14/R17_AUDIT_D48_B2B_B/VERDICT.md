# R17-AUDIT-D48-B2B-B · 审计结论

被审：`R17_D48_B2B_DESIGN\`（D-1 / D-2）。目标二进制 `ra2youli\gamemd.exe`
sha256 `73201cc021497c9567742f718bf1dc78c22e9ae16c7e7365354b65f3fcf67476`（4825360 B，
`.text` VA `0x401000`，ImageBase `0x400000`）。零真机、只读、仅两个窗口线性反汇编。

## 总结论

**D-1：成立。** `0x43F2B5` 确是 `0F 84 49 02 00 00`（`je 0x43F504`），目标算得
`0x43F2B5+6+0x249 = 0x43F504`；而 `0x43F504` 起是 `mov eax,[esp+0x18]; inc esi;
cmp esi,eax; mov [esp+0x1c],esi; jl 0x43F269`——循环增量 + 回边到 loop head
`0x43F269`，不是拒绝出口。拒绝出口 `0x43F5D8` 的跳转源**恰为 2 条**：`0x43F220`
（`0F 85 B2 03 00 00` = `jne 0x43F5D8`）与 `0x43F5B1`（`74 25` = `je 0x43F5D8`），
后者紧接 `mov al,[esp+0x23]; test al,al`，即按 `[esp+0x23]` 非零判成功。

**D-2：成立。** `0x449440` 的两条短路边 `0x449459`（`74 38`）与 `0x449460`（`74 31`）
目标都是 `0x449493`，该块经 `call dword ptr [edx+0xA8]`（BType 谓词）后
`neg al; sbb eax,eax; and al,0xF9; add eax,7` 映射成 `0 / 7`。全函数**没有任何**
"直接返回 7"的路径——直通路径（`call 0x47C620` 后同样的 `and 0xF9 / add 7`）也是 0/7。

## 必改项：2 项

1. `GATE_MAP.md` / `R14_COMMON §2.6`：`0x43F2B5` 不得记为「拒绝分支」，应记为
   「循环终止判定，跳到 `0x43F504` 的循环增量 + 回边」。拒绝出口只有
   `0x43F220 (jne)` 与 `0x43F5B1 (je, 按 [esp+0x23])`。
2. 任何把 `0x449440` 描述为「短路直接返回 7」的文字，改为「短路至 `0x449493`
   的 `vt[0xA8]` 谓词块，结果映射为 0/7」。

## 边界与残余不确定性（如实记录）

- 窗口严格限于 `[0x43F100,0x43F660)` 与 `[0x449440,0x449520)`；B6 三个函数各自
  线性解码至填充/ret/600 条，无全 `.text` 扫描、无函数索引。
- 该函数（`0x43F1E9..0x43F5D8`，278 条）起点 `0x43F1E9` 的确定依据：紧接
  `0x43F1E6` 的 `C2 04 00`（上一函数 `0x43F180..0x43F1E9` 的 `add esp,0xB0; ret 4`
  尾声）、解码无垃圾指令、命中 `0x43F2B5 / 0x43F504 / 0x43F5B1`、止于 `ret 4`。
  起点候选 `0x43F1F0/0x43F200` 解出 `fstp`/`push cs`/`iretd`，为**失步乱码，已弃用**
  （若按卡面建议的"从给定地址直接线性"起步，B3 会漏掉 `0x43F5B1`，必须用锚点对齐）。
- 残余风险（一处，不影响结论）：`0x43F1E9` 处即用 `edi`（`mov eax,[edi+0x520]`），
  而该函数序言不在窗口内可见——若编译器在 `0x43F100` 之前另有 prologue 块，理论上
  多出第三条指向 `0x43F5D8` 的跳转。已用**独立方法**交叉核对：对整窗口
  `[0x43F100,0x43F660)` 做原始字节扫描（`0F 8x rel32` / `7x rel8` / `E9 rel32`），
  命中同样只有 `0x43F220`、`0x43F5B1` 两条。故"只有这两条"在窗口内成立，
  窗口外未扫（`UNVERIFIED`，原因：卡面禁止扩大范围）。
- B2 措辞差异（不影响判定）：实际为首条 `mov eax,[esp+0x18]`，随后
  `inc esi; cmp esi,eax`（比较用寄存器而非内存操作数）。
