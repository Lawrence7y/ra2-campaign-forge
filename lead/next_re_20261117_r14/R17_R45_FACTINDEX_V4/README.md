# R17_R45_FACTINDEX_V4 用法说明（FACT_INDEX v4.0）

## 这是什么
v4.0 在 v3.2（R17_R44_FACTINDEX_V32\FACT_INDEX.tsv，F01–F26）基底上，只追加不改动 12 条新条目 F27–F38。v4.0 的关键变化：索引从「R17 事实底座」扩展为同时收录技术条/方法学硬规则——这些是 R14_COMMON 全节、PANEL M69–M102 与 LEAD_LOCK 技术条里反复踩坑才确立的「怎么读这个镜像/怎么写判据」规则，下游不应重新学一遍。

## 文件
- FACT_INDEX.tsv：TSV，5 列（fact_id / statement / grade / evidence_paths / limitations）。F01–F26 原文一字未动（前缀逐字节校验见 REPORT.md）；F27–F38 为新增技术条/方法学条目。
- GAP.tsv：系统缺口分析。6 列（rule_id / 一句话规则 / 来源 / 索引是否已覆盖 / 对应 fact_id / 覆盖判断依据）。枚举 40 条规则：已覆盖 17 条、未覆盖 23 条；未覆盖中 12 条补为 F27–F38，11 条列入 REPORT「已知未补」。每条判断均引索引原句或给出「全表检索命中 0」的依据，未凭印象。
- REPORT.md：新增条目逐条依据、已知未补清单、路径解析与 CR 校验结果。

## 新增条目的 grade 口径
沿用 v3.2 的定义：[已证]＝字节级/计数已在来源中给出并可回查；[流程]＝方法学/判据规则，非技术结论，不参与 [已证] 计数。新增 F27/F29/F31/F32/F33 为 [已证]（数值或字节形态有来源），F28/F30/F34/F35/F36/F37/F38 为 [流程]（读法/判据规则）。
