## 环境要点（必须照做，否则数字对不上）
- 只读模块：sys.path.insert(0,"/home/t628/projects/ra2-campaign-forge"); import _r185.pe185 as P
  P.RAW 全文件字节；P.r2o(va) 文件偏移；P.B[".text"] 取段信息（含 lo / rawptr / rawsize）；P.SECS 段表。
- capstone：Cs(CS_ARCH_X86,CS_MODE_32); md.detail=False; md.skipdata=True，逐字节 resync 扫描：
  pos 从段起始，每步对 RAW[pos:pos+16] 调 md.disasm_lite 取第一条，命中则 pos += 指令长度，解不出则 pos += 1。
  不要按固定 64KB 切块重启（会少指令），也不要开 detail=True 一次性 disasm 整段（会 OOM）。
- 所有数字必须实跑得出，禁止照抄本卡数字后声称一致；若与本卡期望不同，给出你的值与原因。

## 任务（一条脚本一次跑完，输出 9 组结果）

1. 代码数据区边界（用 P.r2o + struct，全部实测）：
   0x8758c4 起 16 字节；0x8758e4 起 178 字节；0x8758d4 起 16 字节；
   0x8759b4 起 5696 字节；0x876ff4 起 3360 字节；0x879b30 起 5696 字节；
   0x87b170 起 3360 字节；0x87bc90 起 256 字节；0x87bd90 起 256 字节。
   验证零间隙衔接断言（每条给 True/False）：
   0x8759b4+5696==0x876ff4；0x876ff4+3360==0x877d14；0x879b30+5696==0x87b170；0x87b170+3360==0x87be90；0x8758e4+178==0x875996。
   给出 0x877d14 起 16 字节、0x87be90 起 16 字节的十六进制（看后面是什么）。

2. 重复副本逐字节同一性（给 True/False + sha256 前 16 位）：
   0x8759b4 与 0x879b30 各 5696 B；0x876ff4 与 0x87b170 各 3360 B；0x8758c4 与 0x8758d4 各 16 B。
   另外用 RAW.find 全文件搜索这三段字节序列，给所有出现的文件偏移并换算成 VA（用 P.SECS 按 rawptr 区间映射）。

3. 索引表：0x8758c4 起 8 个 16 位字，按有符号给值；判断是否为 (-1,-1,-1,-1,2,4,6,8)。

4. 步长表：0x8758e4 起 89 个 16 位字，与标准 IMA ADPCM step table 逐项比对，给命中数/89。
   标准表前 8 项 = 7,8,9,10,11,12,13,14；末 3 项 = 24623,27086,29794 之后还有 32767，即末项 32767。
   完整标准表请自行按 IMA 规范生成或直接用本卡给出的两端点校核，只要给出实际 89 项序列的前 8 与末 3，以及是否单调递增。

5. 差分表生成律（最关键，必须给命中数/1424）：0x879b30 起 1424 个 32 位有符号整数，按 16 个一记录（index = 16*m + n，m=0..88，n=0..15）。
   律 D：对每个 (m,n)，令 s = IMA[m]（第 4 组测得的 89 项步长表），
   d = (s>>3) + (s if n&4 else 0) + ((s>>1) if n&2 else 0) + ((s>>2) if n&1 else 0)，其中 n 用 n&7；
   期望值 = -d（当 n>=8）否则 +d。统计 1424 项中命中多少，列出前 6 个不匹配的 (m,n,实测,期望)。

6. 状态表生成律（必须给命中数/1424）：0x87b170 起 1424 个 16 位字，同样按 16 个一记录。
   律 S：期望值 = 32 * clamp(m + ADJ[n&7], 0, 88)，ADJ = (-1,-1,-1,-1,2,4,6,8)。
   统计命中数，列前 6 个不匹配。并给该表全部 1424 字的 min / max / 是否全部是 32 的倍数。
   同一律在副本 0x876ff4 上也跑一遍，给命中数。
   同时把律 S 与律 D 在 0x8759b4（D 副本）上各跑一遍。

7. 反控（必须给数字，用来证明律不是拟合出来的）：
   K1 把律 S 的基址右移 2（从 0x87b172 读）后命中数；
   K2 按 R220 旧模型（每记录 8 个字、m 走 0..88）算命中数；
   K3 把律 S 的 clamp 上界改成 87 后命中数；
   K4 把律 D 的符号位判据从 n>=8 改成 n>=7 后命中数；
   K5 把律 D 的 n 改成 n&15（不去掉高位）后命中数。

8. 引用计数（.text 段逐字节 resync 全扫，纯静态）：统计含下列立即数/位移的指令条数与位点前 6 个：
   0x8758c4、0x8758d4、0x8758e4、0x8759b4、0x876ff4、0x879b30、0x87b170、0x87bc90、0x87bd90。
   对每条给形如 "ax, word ptr [ecx + 0x8758e4]" 的操作数文本，并给该目标在 .text 中被引用的最小/最大指令地址。

9. 两张 256 字节抖动表属性：
   A = 0x87bc90 起 256 B，B = 0x87bd90 起 256 B，各视为 16 行 × 16 列。
   给：A[r][c]==2*c 是否对全部 256 项成立；B[r][c]==2*r 是否对全部 256 项成立；B 是否等于 A 的转置；
   两张表的 sha256 前 16 位；A 是否等于 B。

附：读两个跳转表 0x7c7758 起 8 个 dword、0x7c7778 起 4 个 dword，给十六进制值。
