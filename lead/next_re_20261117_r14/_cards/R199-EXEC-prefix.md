## 已复核前置（主会话实测，直接用，不要重推）
P1 COL 结构 24 字节，判据：dword+0 在 {0,1,2}、+8 == 0、+12 指向 .data、+16 指向 .rdata，
   类名在 pTD+8（读名上限必须给 400，给 80 会截断长模板类名，R196 已踩过）。扫 .rdata 与 .data 两段得 COL = 1214。
P2 虚表判据：dword[vt] 落在 .text 且 dword[vt-4] 是 COL 地址。得 VT = 1214，槽总 14044。
   nslot(vt) = 从 vt 起连续多少个 dword 落在 .text 内（.text 文件内区间 0x401000..0x7E1000）。
P3 主表 = COL.mdisp == 0 的 vt，共 954 张。
P4 CHD 结构：dword[+0]==0、+4 attributes、+8 numBaseClasses(n)、+12 指向 BCD 指针数组（每个 dword 指向一个 BCD）。
   BCD 结构 24 字节：+0 pTD、+4 numContainedBases(ncb)、+8 mdisp（有符号）、+12 pdisp（有符号）、+16 vdisp（有符号）、+20 attributes。
   BCD[0] 是类自身，其余是全部基类（深度优先扁平排布）。
P5 直接子结点规则（R196 已验证 2615/2615 成立）：结点 i 的直接子结点链为 j = i+1;
   当 j <= i + ncb[i] 时，结点 j 是 i 的直接子结点，然后 j = j + ncb[j] + 1，循环。
   结点 0 的直接子结点就是该类的直基类。
