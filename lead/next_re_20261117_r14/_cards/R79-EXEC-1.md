# R79-EXEC-1 — 两种时钟下的旁证计数（只做一件事）

## 你是谁

R17 子代理，家族 deepseek，角色执行员。只写 _r79/exec/ 下两个文件：witness_exec_r79.py 与 REPORT.md。不得修改任何既有文件。卡面与本产物都不要出现反引号。

## 背景（一句话）

R74 写下一个数：36 个候选值里有 34 个「有跨源旁证」、2 个没有。这个数没有写时钟。你只负责把同一个规则在两种时钟下各数一遍。

## 输入与规则（全部写死，不许改判据）

候选值：从 live 文件 lead/next_re_20261117_r14/R14_COMMON.md 的 0x00 站点重建 —— 每个 0x00 后面紧跟的字母数字串，前面补一个字符 0，去重。应当得到 36 个，若不等 36 直接报失败停下。

语料域：仓库根下六个目录 lead / re_atlas / out / docs / ra2youli / YRpp。遍历时跳过名为 R17_LEAD_BASELINE 与 __pycache__ 与 .git 的目录，跳过路径中出现子串斜杠下划线上字母 r 的目录（R74 原文规则，逐字照抄），跳过大于 20000000 字节的文件。

命中规则：整个 token 出现即算命中，前后都不能是字母或数字。例：空格包围的 0x47C432 算命中；0x47C4320 不算；x0x47C432 不算（左边是字母 x）。

时钟 A 的锚：文件 lead/next_re_20261117_r14/_r74/forensic_nul_r74.log 的 mtime，用 stat -c %Y 取。打印出来。

## 三种口径（各数一遍，都要报数）

1. btime 口径：只收 btime（stat -c %W）小于等于时钟 A 的文件。
2. mtime 口径：只收 mtime 小于等于时钟 A 的文件。四个文件在时钟 A 之后被改写过，用它们在 R74 写入前的备份顶替，备份都在 lead/next_re_20261117_r14/R17_LEAD_BASELINE/ 下、名字以 R74.before 开头并以 004604.md 结尾：R14_COMMON.md、LEAD_LOCK、GOAL_THREE_TARGETS_20261018.md、STATUS_BOARD.md。备份顶替时匹配的模板串是 R74.before 加上目标文件名主体，自己按 ls 结果对齐，不要猜。COMPACT_STATE.md 没有备份，如实记为「时钟 A 内容不可复原」，并另外报出：它里面那两个候选值出现在哪个三级标题之下（给标题文字）。
3. 独立口径：mtime 口径的语料里再整体移除五个「报告过这件事」的文件 —— R14_COMMON.md、lead/LEAD_LOCK、lead/GOAL_THREE_TARGETS_20261018.md、STATUS_BOARD.md、COMPACT_STATE.md。

每种口径都报：有旁证几个、无旁证几个、无旁证的具体是哪几个。

## 必须做的三条控制（缺一条即无效）

1. 正控：自己造一个合成语料，里面放空格包围的 0x47C432，你的命中函数必须报命中。
2. 负控：同一合成语料把尾随改成 0x47C4320，必须报不命中。
3. 时钟控制：对 lead/next_re_20261117_r14/COMPACT_STATE.md 同时打印 btime 与 mtime，并断言 btime 小于等于时钟 A 而 mtime 大于时钟 A。

## 输出

- _r79/exec/witness_exec_r79.py —— 可复跑，最后一行打印自测项数与 FAIL 数。
- _r79/exec/REPORT.md —— 三行表格（口径 / 有旁证 / 无旁证 / 无旁证是哪些），三条控制的实测结果，一句结论：同一个规则在两种时钟下各得什么数。

## 纪律

- 不许读 _r79/ 下除你自己写的文件以外的任何文件；不许引用任何既有报告里的数字当结论。
- 没跑过的数一律写「未测」。
- 步骤就五步：建语料、建候选值、跑三种口径、跑三条控制、写两个文件。
