# 卡 R17-B3-REVIEW · 对 B3 那 12 处「ctor 装表写」做第二源独立复核（前源 hy4，本卡须跨家族）

纯静态、只读、有界。目标 ra2youli\gamemd.exe。

## 一、为什么要复核
`R17_AUDIT_R9` 的 B3 判定基于 12 处 `mov dword ptr [esi/ebp+off], imm32`，认定其为**构造器装表写**，
并据此把「无取用者」从全称否定改成局部否定。该结论目前是**审计单源**。
本项目在同类判断上有**四次翻车历史**（R16），失败形态固定为两类：
 ① 把**栈临时写**当成装表（如 `mov [esp+0x20], 0x7e1668`）；
 ② 把**析构器 / scalar deleting destructor** 当成构造器。
所以本卡的任务不是复述，而是**定向证伪**。

## 二、必须回答
对 `R17_AUDIT_R9` 列出的 12 处 site（目标槽 0x7E3E90 / 0x7E3E98 / 0x7E3EA0 / 0x7E3EBC，三 host 0x43B680 / 0x43B740 / 0x43BCF0）：

**C1 · 逐处判定装表形态是否成立**，必须逐项给 G1–G5：
 G1 目标**不是栈**（操作数不是 [esp+..] / [ebp+..] 局部）；
 G2 目标是 **this**（来自 ecx 或 this 的派生）；
 G3 **非析构**（写后无基类析构调用、无 `test al,1` / `[esp+X],1` 删除签名）；
 G4 前序有**分配**（`call operator new`）或**基类构造**；
 G5 收尾**返回 this**（`mov eax,esi` 一类）且与 ret 形态自洽。
 任何一项不成立，必须写明是第几项、字节依据是什么。

**C2 · 位置断言**：对每处给 host <= site < fn_end(host)，fn_end 必须字节实测（ret / 填充 / 下个函数锚点），
不得用手填 forced_host、不得只按操作数形态匹配。

**C3 · 槽内容复核**：0x7E3E90 / 0x7E3E98 / 0x7E3EA0 / 0x7E3EBC 四槽的值是否确为
0x410590 / 0x410580 / 0x4105E0 / 0x410260（均 .text）？若不同，报差集。

**C4 · 与前源的分歧**：若你判定某处不成立，明确指出前源错在哪一步。若全部成立，也要写明你额外排除了哪些失败形态。

## 三、铁律
1. 反汇编必须**锚点对齐**（C3 / C2 xx xx / 90|CC 填充之后起步），禁从任意地址线性起步。
2. 有界：只在 3 个 host 的 [host, fn_end) 内反汇编，不扩到全镜像。
3. 只读打开 gamemd.exe；不建进程、不调试、不启动 gamemd；产物只写本卡目录；**不得修改 R17_AUDIT_R9 下任何文件**。
4. 中间结果先落盘，严格 **7 分钟**预算。
5. 取不到写「未取得」，严禁编造。指令地址用 0x 前缀。
6. 不得只因为「前源是异族审计」就放行 —— 你的价值在于独立重解字节。
