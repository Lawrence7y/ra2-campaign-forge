# 卡 R198 审计（deepseek）：只读复核主会话本轮三条核心数

## 角色与边界
只读审计。不得写任何文件、不得修改任何文件，不得运行 gamemd.exe。只允许写 stdout。
全部静态取证。一条命令跑完全部复核（单个 python 脚本，直接打印结果）。预算 8 分钟，回合数 <= 12。
镜像基址 0x400000。PE 映射：
  import sys; sys.path.insert(0,'/home/t628/projects/ra2-campaign-forge/_r185'); import pe185 as P
  P.RAW / P.B[段名]（lo 虚拟起点 / rawptr 文件偏移 / rawsize）/ P.dw(va) / P.where(va) / P.cstr(va,n) / P.r2o(va)
capstone：capstone.Cs(capstone.CS_ARCH_X86, capstone.CS_MODE_32)
OOM 红线：禁止对整段 .text 开 detail=True 的 md.disasm()；线性扫描用 md.disasm_lite()。

## 数据结构定义（照此实现，不要另立口径）
COL 24 字节：dword+0 在 {0,1,2}、+8 == 0、+12 指向 .data、+16 指向 .rdata；类名在 pTD+8，读名上限给 400。
  扫 .rdata 与 .data，按 dword 步进。VT：vt 处是 .text 地址且 vt-4 是 COL 地址。
  槽数 nslot(vt) = 从 vt 起连续多少个 dword 落在 .text 内。

## 三条待复核主张（逐条独立复算，给数）
A1 【基线】COL = 1214；VT = 1214；全部表槽数总和 = 14044。
A2 【最长表 0x7F5C70】其类名是 .?AVUnitClass@@、mdisp 0、槽数 344；
   它的 344 个槽目标地址**两两不同**（不同实现数 = 344，出现次数 >= 2 的实现数 = 0）。
   并且全 1214 张表里有 1181 张也满足「槽目标两两不同」。
A3 【槽位唯一性】对下面 18 个 (槽号, 地址) 对，扫全部 14044 个槽位，记录该地址出现的槽号集合：
   槽0=0x410260 槽1=0x410300 槽2=0x410310 槽3=0x4C9150 槽4=0x410450 槽5=0x5F5E80
   槽6=0x4C9150 槽7=0x4103E0 槽8=0x4105A0 槽9=0x410470 槽10=0x410480 槽11=0x4C9150
   槽12=0x4C9150 槽13=0x5F6250 槽14=0x410490 槽15=0x4104A0 槽16=0x4104B0 槽17=0x410440
   主张：除 0x4C9150 这个纯桩出现在 33 个不同槽号外，其余 14 个不同地址**每个都只出现在它那一个槽号**上。
   并给这 14 个地址各自的「出现表数」（例如 0x410260 应出现在 75 张表、0x410450 在 77 张）。

## 你还要独立回答的两问
Q4 【A2 的解释力】「0x7F5C70 的 344 槽两两不同」能不能被「长表本来就这样」解释？
   给数：把 1214 张表按槽数分档（1..7 / 8..63 / 64..127 / >=128），每档给「表中 uniq == nslot 的比例」。
   若 >=128 档的 8 张表全是 uniq==nslot，说明这不是 344 槽的特例而是长表的普遍形态。
Q5 【反控】把 A2 的判据从「目标地址两两不同」改成「目标体前 16 字节两两不同」，
   0x7F5C70 的不同实现数变成多少（说明按字节前缀去重会掉下来多少）。给两个数并说明差异来源。
