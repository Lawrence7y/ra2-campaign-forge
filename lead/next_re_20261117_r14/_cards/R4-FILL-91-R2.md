# R4-FILL-91-R2 — 补写 91 行成文 ④（放开 COL/TD/构造器 三类地址的取数许可）

## 上一版为什么被打回

`R4-FILL-91` 产出了 91 行，但 ④ 句里 **COL 地址 / TD 地址 / 装表点宿主构造器 entry** 三类字段全部写成 `未取得`——因为：

- 卡面 ④ 格式**要求**这三类数值地址
- 但输入 `all848.tsv` **只有**装饰名字符串、vt、槽号、entry、装表点地址，**不含**这三类
- 而卡面硬约束又**禁止重新反汇编**

⇒ 两个要求互斥。执行者按项目惯例写 `未取得`、没编造，这是对的；**是 Lead 的卡错了**。

**Lead 裁定：`未取得` 版本不予接受。** 一条 ④ 里有三个占位符不构成「成文 ④」，把它计入「④ 已成文」等于自欺。**本卡放开这三类的反汇编许可**，其余不变。

## 本卡要做什么

给 91 行补写成文 ④，写进 `coverage.tsv` 第 4 列语义栏**末尾追加**，**grade 不动**。

### 允许的取数来源（按优先级）

1. **优先**从 `R4_DERIVABILITY\all848.tsv` 取：装饰名、`vt` 地址、槽号、entry、装表点地址
2. **允许**为补齐 `COL 地址` / `TD 地址` / `装表点宿主构造器 entry` 三类而**回二进制取数**：
   - `COL 地址` = `[vt-4]` 处的值
   - `TD 地址` = `COL` 的 `pTD` 字段（**注意：绝对 VA，不是 RVA**）
   - `装表点宿主构造器 entry` = 含该装表点指令的函数起点
   - 工具：capstone 5.0.7（`skipdata=True`）+ pefile；`gamemd.exe` 期望 SHA-256 `73201CC021497C9567742F718BF1DC78C22E9AE16C7E7365354B65F3FCF67476`
3. **仍然禁止**：改动或"修正"`all848.tsv` 里已有的 vt/槽号/entry；若你反汇编结果与 `all848.tsv` 的 vt/槽号**不一致**，**停下报告**（这属扫描误差，须先查清）

### ④ 句格式（统一）

在该行第 4 列**原有文字之后**追加：

```

```

**六个字段必须全部是实测数值**：vt / 槽号 / COL / TD / 装表点 / 构造器 entry。

- 任一字段取不到 ⇒ **该行剔除**，进报告单列原因（这是上一版被打回的关键：不许用 `未取得` 占位）
- 类名 = RTTI 装饰名去修饰（`?AV<Name>@@` → `<Name>`）；解不出也剔除
