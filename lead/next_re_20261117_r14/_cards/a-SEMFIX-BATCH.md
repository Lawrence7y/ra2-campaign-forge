# a-SEMFIX-BATCH — 异族审计 SEMFIX 批次的 ③b② 改写

## 身份

你是**异族独立审计员**。执行器家族是 Hy4，你不是。只采信你自己反汇编出的字节。

## 为什么要审

两个独立批次（B1、B2）各报 **17/17 全部改写、类名 17/17 取得、③b② 17/17 成立、rate 1.0000**。两个批次同时 100% 完美，是被反审的典型信号：上一轮同一族里，执行器报 11/11 四环齐全，异族审计只给 7 PASS / 4 FAIL（虚报率 36%）。

**你的任务是把真成立的行与不成立的行分开**，不是复核"是否 100%"。

## 待审内容

见任务下发时指定的批次目录（`SEMFIX_ENGFAM_B1\` 或 `SEMFIX_ENGFAM_B2\`）：

- `coverage_delta.tsv`：**17 行**，6 列（`entry / subsystem / name / one_line_semantics / grade / evidence_path`）
- 执行器自留证据（**只当线索，不作证据**）：`EVIDENCE\ROW_<entry>.txt`、`REPORT.md`、`base_rate.tsv`

## Lead 已独立核过的格式事实（不用重复花时间）

- 两批共 34 行、34 个唯一 entry、6 列、`entry` 全为 8 位大写十六进制无 `0x` 前缀
- 语义串 34 行**各不相同**（无模板复制）、无 `unproven` 字样、无 `③b④`/`非栈写` 字样
- 34 行**全部在 atlas 内**

格式已过关。**你要审的是内容真假。**

## 每行必须验的五件事

1. **元素类是否真的取得**：给出 `.bss` 向量地址、构造写入点地址、元素类 RTTI 描述符地址、**类名字符串所在地址与读出的名字**。
   - 若你取不到，判该行 ② **不成立** ⇒ `FAIL`。
   - 执行器写在语义串里的类名，必须与你自己读出的字符串**逐字一致**；不一致即 `FAIL`（哪怕只是拼写差异）。
2. **③b② 检查点是否真实**：`call` 后确有 `test eax,eax` / `cmp eax,<常量>` / `or eax,eax`，给地址与字节。
3. **失败路径是否与成功路径动作不同**：不是同一处 call 只差参数。给两条路径各自的地址与动作。
4. **返回值是否真被消费**：调用方拿它做了可观察分支，给消费点地址。
   - **陷阱**：`test eax,eax` 之后 `eax` 立刻被 `mov eax,[esi+0x??]` 之类覆写 ⇒ 检查失效、返回值未被消费 ⇒ `FAIL`。上一轮就有一行正是这样被否的。
5. **④ 使用见证**：真实调用者或活虚表派发，**direct-only 不足**。

## 已知陷阱（主动排查）

- **`0045A640` 类**：循环内只有栈写 + 寄存器推进 ⇒ ③b 不成立。
- **常量返回但从不比较** ⇒ 不算可伪证。
- **`bool` 型返回 + 两路径汇合到同一点** ⇒ 上一轮被判 FAIL 的形态之一。
- **"对象初始化"式模板假句**：语义串写得像 ③b② 但实际只是构造/清零 ⇒ 上一轮另一行被判 FAIL 的形态。

## 输出（只写自己目录）

- `<批次目录>\_audit\VERDICT.md`：逐行一节，含上述五件事的地址与字节 + 判定
- `<批次目录>\_audit\verdict.tsv`：表头 `entry	verdict	class_name_read	check_at	consumed_at	reason`
  - `verdict` 只能 `PASS` / `FAIL`
  - `entry` 大写十六进制、无 `0x` 前缀

- `<批次目录>\_audit\SUMMARY.md`：PASS n / FAIL m，并列出 FAIL 行及一句话原因
