## 环境与硬性口径（必须照做）
- PE 映射：sys.path.insert(0,'/home/t628/projects/ra2-campaign-forge'); import _r185.pe185 as P
  P.RAW 是全文件字节；P.r2o(va) 给文件偏移（返回 None 表示 virt-only）；P.dw(va) 读 dword；P.B['.text'] 给 lo/rawptr/rawsize。
- 反汇编：capstone，CS_ARCH_X86 + CS_MODE_32，必须 md.skipdata = True，逐字节 resync 推进：
  while 循环，每步对 raw[pos:pos+16] 调 md.disasm_lite，取第一条，pos += 长度；解不出则 pos += 1。
  禁止对整段 .text 开 md.detail=True 一次性 md.disasm()（会 OOM）。全段扫描只用 disasm_lite。
  只对少数命中地址（<=200 个）单独开 md.detail=True 读操作数细节。
- 后台命令一律 timeout 900。

## 待取证（全部给实测数字，禁止预估）
T1. 两份副本一致性：分别对 0x876ff4 起 2576 B 与 0x87b170 起 2576 B 算 sha256（按文件字节原样），
    报告两值是否相同、是否逐字节相同；再算 0x87b170+2576 之后 16 B 的十六进制。
T2. 表结构：把 0x87b170 起 2576 B 当 1288 个 16 位小端字读出，输出前 48 个字的十进制值；
    判定记录周期（16 B = 8 字），验证每 8 字一组的第 1..8 分量是否分别构成等差序列；
    给出差值分布（每个分量的相邻差 distinct 值集合，最多列 12 个）。
    同时按 dword 读法给出前 12 个 dword（解释 0x00800040 只是两个相邻字被读成 dword）。
T3. 孪生表 0x879b30：读 64 个 dword 打印；判定它与 0x87b170 的 16 位字之间的数值关系，
    至少检验三种假设并给出命中数/64：H1 dword[i] == word[i]*65536；H2 dword[i] == word[i]*256；
    H3 dword[i] == word[i] shl 16 或 word[i] 的定点展开。再给出 0x879b30 与 0x87b170 的字节区间长度
    （各自被引用的有效跨度：用引用指令的最大 disp 反推）。
T4. 全 .text 引用扫描（逐字节 resync sweep，一次跑完）：找出所有 disp32 或基址常量落在
    [0x876ff4,0x880000) 区间的指令（0x87b170 表、0x879b30 表、0x87c484 派发表都属此区间），
    每条输出：指令地址、助记符+操作数串、命中的表地址。
    另单列：命中 0x87b170 / 0x876ff4 / 0x879b30 / 0x87c484 四者的条数分别多少；
    以及访问宽度（word / dword / byte）分布。
T5. 宿主函数：0x7c742f 处 mov dx,word ptr [edx+0x87b170] 所在函数。
    用 0xCC 填充判界：从 0x7c742f 向前找最近的 >=2 连续 0xCC，其后第一个字节为函数入口（记 start）；
    向后找最近 >=2 连续 0xCC 或函数内 ret 后全部填充，记 end。输出 start/end/长度，
    并把 start..end 的全部指令用 disasm_lite 逐条列出（若指令数 > 400 则只列前 400 条 + 总条数）。
    再从其中标出：所有内存访问 [edx*2+0x879b30] 与 [edx+0x87b170] 的上下文（前后各 3 条指令），
    说明 edx 的取值范围（谁的循环变量）、写回的变量、以及该函数是否被 E8 调用（给出 E8 站点数）。
T6. 写入端：全 .text 中是否存在把 imm 或寄存器写入 [0x876ff4,0x880000) 区间的指令（mov [mem],imm / mov [mem],reg），
    给出条数与地址清单（若 0 条也要明确写 0）。
T7. 正反控：
    正控 —— 0x7c7428 的 add eax,dword ptr [edx*2+0x879b30] 必须被 T4 扫描命中（带 index*2 的形态）；
    反控 —— 把区间改成 [0x880000,0x890000) 重扫一次，报告条数（应与 T4 无关或另计），
    另把 0x87b170 改成 0x87b180 扫一次，报告条数（应少于原值）。
