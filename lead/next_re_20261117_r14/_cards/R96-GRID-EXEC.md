## 背景与唯一问题

两个独立实现都对同一份 objdump 输出数「基本块首地址个数」，得到不同的数：

- 实现 A 得 205542
- 实现 B 得 204546
- 差额 996

上一轮（R95）的结论是：把口径限定在「跳转到非指令边界的间接目标怎么处置」这一
个开关上，只能复现 62，剩余 934 找不到来源，登记为未取得。

本轮的任务是：**不要预设只有那一个开关**。把两个实现之间所有可能不同的开关
自己列出来，逐个量化，看 996 能否被某组开关**精确复现**。

## 要做的事

### 一、指令起始集（先钉死，这是所有分母）
1. 用 objdump -d -M intel 生成反汇编（可缓存到 /tmp）。
2. 解析出「有 mnemonic 的行」为指令起始，报总数。
3. 报「只有字节、没有 mnemonic」的行数。
4. 正控：报首地址、末地址。
5. 报 .text 段表末端地址（从 PE 段表现读）。

### 二、自己定义「块首集合」的构造，并把每个可变量单列成一个开关
至少要考虑下面这些（不要只做最后一个）：
- S1 跳转指令的助记符集合：jmp 与哪些条件跳转算跳转？
  特别核对：jz / jnz / jpe / jpo / loop / loope / loopne / jecxz / jcxz
  这些助记符在本镜像里各出现多少次，它们是否被算进跳转集合。
- S2 块终止指令集合：ret / retn / retf / iret / iretd 算终止；
  int / int3 / int1 / hlt / ud2 算不算终止？
  逐个报这些助记符在镜像中的出现次数。
- S3 跳转目标的地址上界：目标落在哪个区间才算「代码内跳转」？
  分别用 .text 段表末端、以及一个比它小的常数（例如段末端减去若干字节）各算一遍，
  报两者分别排除了多少条指令。
- S4 跳转到非指令边界的地址时怎么处置：丢弃目标，还是取其后第一条指令？
- 你若发现还有别的开关（例如最后一条指令之后是否补一个块首、跳转目标是否要求
  必须出现在指令起始集里），也单列，并量化。

### 三、全枚举
1. 把上述开关做**全组合**枚举（每个开关取其 2 个候选值），打印每个组合得到的块首个数。
2. 报出：哪个组合精确等于 205542？哪个组合精确等于 204546？
3. 报出两个组合之差。若正好是 996，则写明「996 已由几个开关的组合精确解释」，
   并给出每个开关单独翻一次时块首数的增量（从 204546 那个组合出发，一次只翻一个）。
4. 若无法精确复现 205542 或 204546，如实写「未能复现」，并给出最接近的组合与差多少。
   **不许把期望值改成你的实测值当作复现成功。**

### 四、反控（缺一项本卡不合格）
- 把块首集合与「全部指令起始集」比，块首数必须严格小于指令数是合理量级；
- 只把 S4 开关从「丢弃」改成「取下一条」，块首数必须发生变化，报差多少；
- 把 S2 里 int/int3/hlt 从终止集合移出，块首数必须发生变化，报差多少；
- 把 S1 里 loop 系列全部从跳转集合移出，块首数必须发生变化，报差多少。
