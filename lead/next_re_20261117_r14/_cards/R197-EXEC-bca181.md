## 你要独立回答的六问
Q1 用 P1 独立复算三个基数：不同 CHD 地址个数、BCD 槽位总数（各 CHD 的 n 之和）、不同 BCD 地址个数（去重）。
   把结果与 954 / 2615 / 1002 比对。若不一致，逐个列出差异 CHD 地址。
Q2 【相邻差值分布】对每张 CHD 的 BCA 数组，按顺序算相邻元素地址差 diff = bcd[i+1] - bcd[i]（有符号）。
   给出 diff 的完整直方图（diff 值 -> 出现次数），按出现次数降序，前 20 项全部列出，剩余项只给总次数。
   同时给三类计数：diff < 0（递减）、diff == 0（相等）、diff > 0（递增）。上报你算出的三个数。
Q3 【递增处的完整分类】把所有 diff > 0 的位置收集起来，逐条给出：所在 CHD 地址、n、下标 i、bcd[i] 地址、bcd[i+1] 地址、diff 值、ncb[i]、ncb[i+1]、md[i]、md[i+1]。
   然后按 diff 值分组统计：diff == 24 / 24 < diff <= 48 / diff > 48 各多少处。
Q4 【递增处的树关系】用 ncb 重建每张 CHD 的树（子结点定义：结点 i 的直接子结点为 i+1, i+1+ncb[i+1]+1, ... 直到不超过 i+ncb[i]，即用区间 [i, i+ncb[i]] 内逐段跳）。
   对每个 diff > 0 的位置，判定 bcd[i+1] 相对结点 i 的关系类别，四选一：
   (A) 是 i 的直接子结点  (B) 是 i 的兄弟（同父）  (C) 是 i 的祖先层结点  (D) 以上都不是
   给出四类的计数。若树重建失败（根不是唯一或覆盖不满），如实报失败并说明。
Q5 【mdisp 联合判据】对全部相邻对（不只递增），统计 (diff 符号) x (md[i+1] > md[i] / == / <) 的 3x3 交叉表。
   再单独看 diff > 0 的 181 处（或你算出的真值）里，md[i+1] > md[i] 的比例是多少。
Q6 【BCD 复用与递增的关系】把 2615 个槽位按 BCD 地址分组，给出每组被引用次数（引用数 -> 组数直方图）。
   然后回答：diff > 0 的位置上，bcd[i+1] 是否是「首次出现」（即该 BCD 地址在全局出现序列里第一次被引用）、bcd[i] 是否是「最后一次出现」。
   给出 2x2 交叉表：bcd[i+1] 首现/非首现 x bcd[i] 末现/非末现。
