# R78-EXEC-1 — 三族站点在三种粒度上的重叠（只做一件事）

## 你是谁

R17 子代理，家族 deepseek，角色执行员。只写 _r78/exec/ 下两个文件：overlap_exec_r78.py 与 REPORT.md。不得修改任何既有文件。卡面与本产物都不要出现反引号。

## 只做这一件事

读三个既有 json，把「三族残渣站点」在**三种身份粒度**上求两两交集，报出 6 个数与并集大小。

## 输入（只读，路径写死）

1. _r77/c0full_r77.json —— 取 rows 数组。族名 C0。站点键 = (file, off)。行号字段 line 仅供诊断。
2. _r76/legal_r76.json —— 取 A_sites 下的 TAB 与 FF 两个数组。族名 LEGAL。站点键 = (file, off)。
3. _r76/tablebreak_r76.json —— 取 rows 数组。族名 TABLE。**该数组没有 off 字段**，你必须自己定位：
   站点偏移 = 文件里第 line 行（1-based）那个换行符字节的偏移。定位法：从文件头开始数第 line-1 个 0x0A 的位置 p，站点偏移 = p；若第 line 行是末行且无换行，则站点偏移 = 文件长度。写清你用的是哪种。

## 三种粒度（逐一定义，不许含糊）

- 粒度 A 字节偏移：同 file 且同 off 即同一站点。
- 粒度 B 行：同 file 且同行号即同一站点（C0 与 LEGAL 有 line 字段；TABLE 的 line 就是它的行号）。
- 粒度 C 文件：同 file 即同一站点。

## 必须报出的数

对每个粒度：|C0|=? |LEGAL|=? |TABLE|=? 交集 C0∩LEGAL=? C0∩TABLE=? LEGAL∩TABLE=? 并集=?。并集要按「去重后的站点数」算，不要直接把三个基数相加。

粒度 B 与 C 求交集前**必须先把每族站点按该粒度去重**（同一文件多站点只算 1），否则交集数会虚高。报告里写出每族在每粒度下的去重后基数。

## 三条控制（必须做，缺一条即无效）

1. 正控：自己造一个合成语料，让同一字节偏移既属于 C0 族又属于 TABLE 族，你的交集算子必须报 1。若报 0，说明你的算子不会算交集，先修算子。
2. 负控：同一合成语料改成两个不同偏移，交集必须报 0。
3. 自证：报出 LEGAL 的 TAB 数组与 FF 数组合并后的基数（判重按 file+off），并说明 TAB/FF 之间有没有重合站点。

## 输出

- _r78/exec/overlap_exec_r78.py —— 可复跑，自测项与 FAIL 数打印在最后一行。
- _r78/exec/REPORT.md —— 一张表（行=粒度，列=三族基数/三个交集/并集），加三条控制的实测结果，加一句结论：三族能不能直接相加。

## 纪律

- 不许读 _r78/ 下除你自己写的文件以外的任何文件；不许引用任何既有报告里的数字当结论。
- 没跑过的数一律写「未测」。
- 步骤就四步：读三个 json、算三种粒度、跑三条控制、写两个文件。
