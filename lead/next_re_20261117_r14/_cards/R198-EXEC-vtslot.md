## 已复核前置（主会话本轮实测，直接用，不要重推）
P1 COL 表 24 字节，判据：dword+0 在 {0,1,2}、+8 == 0、+12 指向 .data、+16 指向 .rdata，
   类名在 pTD+8，读名上限必须给 400（给 80 会截断长模板类名）。扫 .rdata 与 .data 两段得 COL=1214。
P2 虚表地址 vt 判据：vt 处是 .text 地址、vt-4 处是 COL 地址。得 VT=1214，槽总 14044。
   槽数 nslot(vt) = 从 vt 起连续多少个 dword 落在 .text 内。
P3 0x7F5C70 = .?AVUnitClass@@ 主表，槽数 344（全表最长）；次长 0x7EB058 .?AVInfantryClass@@ 343、
   0x7E22A4 .?AVAircraftClass@@ 341、0x7E8C94 .?AVFootClass@@ 341。
P4 全表槽数分布里 <128 槽占绝大多数（>=128 槽只有 8 张）。

## 你要独立回答的六问
Q1 复算 P1/P2/P3：COL 数、VT 数、槽总、0x7F5C70 的槽数与它对应的类名。
Q2 对 0x7F5C70 全部 344 个槽位，逐槽给出目标地址。统计：
   (a) 不同实现地址数 uniq；(b) Top1 地址 + 出现次数（前 10 名，含次数）；(c) 出现次数最多的 3 个实现。
Q3 体形态普查：对 Q2 里出现的**每一个**不同实现地址（预估几百个），用 detail=True 单点反汇编，
   取到第一个 ret 为止（限 200 条 / 400 字节）。对每个实现记录：
   (a) 指令条数；(b) 字节长度；(c) ret 形态（ret / ret 立即数 / jmp 尾调用 / 无 ret 逃出窗口）；
   (d) 是否体内含 call（call 目标前 3 个）。按这四维做分组统计（每组给实现个数 + 这些实现覆盖的槽位数）。
Q4 纯桩识别：把「体内等价于 xor eax,eax; ret」或「ret 0 且无副作用」的实现归类为纯桩。
   给出纯桩的个数、它们覆盖的槽位数、占 344 槽的比例。注意按**指令语义**判，不要只按字节前缀匹配。
Q5 槽位分组：把 344 个槽位按「实现是否相同」切成连续 run（相同实现的相邻槽合并），
   给出 run 的个数、最长 run 的长度与起止槽号。再给「每个 run 内的实现是否与上一 run 相同」的相邻 run 对比。
Q6 与父表关系：0x7F5C70 是 .?AVUnitClass@@（mdisp 0 主表）。找出全表所有 .?AVUnitClass@@ 的表
   （含子表，mdisp != 0），给它们的 vt / 槽数 / mdisp。逐槽比较这些表与 0x7F5C70 的实现是否一致，
   给出「完全一致 / 前缀一致 / 有明显差异」三类的槽位数，并给出差异最大的前 10 个槽号。
