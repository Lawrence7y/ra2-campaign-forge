# 卡 R195 执行 A（hy4，取证实测）：CRC 状态对象的归属方式与初值来源

## 角色与边界
执行类。只允许写 _r195/exec_a/ 目录下的文件；不得修改任何其他文件。
不得运行 gamemd.exe，全部静态取证。必须一条命令输出全部证据（单脚本一次跑完）。
OOM 红线：禁止对整段 .text 开 detail=True 的 md.disasm；全段线性扫描只用
md.disasm_lite() 或 <=64KB 分块，且只对少数命中地址单独开 detail=True。
PE 映射直接用 _r185/pe185.py（P.RAW / P.B 段表 / P.dw / P.where / P.r2o / P.cstr），
capstone 已装（capstone.Cs(CS_ARCH_X86, CS_MODE_32)）；.text 段描述 P.B['.text']，
lo = 段虚拟起点，hi_file = 段文件末虚拟地址（只用这段，不要越过）。

## 已复核前置（可直接用，不要重推）
P1 镜像基址 0x400000。0x4A1CA0 / 0x4A1D50 / 0x4A1DE0 / 0x4A1FB0 / 0x4A1FF0 是同一族
   序列化写 + CRC32 例程；CRC 查表基址 0x81F7B4。
P2 0x4A1CA0(ecx=状态对象, 55 条, ret 4) 与 0x4A1DE0(esi=状态对象, 174 条, ret 8)
   用同一套状态布局：+0x0 = CRC 值 / +0x4 = 已填计数 0..4 / +0x8..+0xB = 折叠缓冲 /
   +0xC = 折叠时的计数影子。
P3 该族只写 +0x4 / +0x8..+0xB / +0xC；**没有**任何一处对 +0x0 的写或初始化。
   本轮要回答的是「状态对象从哪来、+0x0 由谁初始化」。

## 你要独立回答的六问（只要这六问，不要扩）
Q1 收集 .text 内全部 E8 call rel32 且落点 == 0x4A1CA0 的调用点（给总数与全部地址升序）。
   对每个调用点，从该点向前反汇编 <=96 字节（在函数边界/ret 处截断），判定 ecx
   （即状态对象指针）的来路，归成四类并给计数：
   a) lea ecx,[esi+imm] / lea ecx,[edi+imm]（成员子对象）
   b) lea ecx,[ebp-imm] / lea ecx,[esp+imm]（栈上局部）
   c) mov ecx,[...]（指针来自内存字段）
   d) 无法判定（给原因与地址）
   给出每一类的首个地址与 imm 值（十进制与十六进制各一）。
Q2 对 0x4A1D50 与 0x4A1DE0 做同样的事（ecx 与 esi 各看一个），给四类计数。
Q3 状态对象 16 字节：若为成员子对象，给出宿主对象被当作 this 的证据（同一函数内
   对 [esi+imm] 其它字段的读写），并给出该 imm 的最小与最大值。若为栈上局部，
   给出该栈帧的总大小（sub esp,N 的 N）与状态对象的栈偏移。
Q4 初值来源：在全部调用点所在函数里，检索「对状态对象 +0x0 的 4 字节写」——
   含 mov dword ptr [reg],imm / mov [reg],reg / lea 存储 / memset 类调用。
   给出命中数；若为 0 明确写 0。再检索这些函数体内是否出现 immediate 0xFFFFFFFF
   或 0 的 4 字节写入到状态对象基址（这两种都是 crc32 的合法初值候选）。
Q5 若状态对象是成员：给出宿主对象的分配点或构造函数线索（该 imm 偏移在 .text 里
   被 mov/lea 访问的全部不同函数起点数）。若为栈上局部：给出所在函数起点地址清单。
Q6 对 Q1 检出的每个宿主函数起点，给出函数体前 24 条指令的助记符序列（地址 + 助记符），
   用于判断它是「序列化器/存档器/校验器」中的哪一类形态（只看是否有循环、是否有
   对文件句柄或内存缓冲的写、是否有 call 到 0x4A1xxx 族）。

## 三条反控（必须给出你的数）
R1 把 E8 判据从「线性解码 + 目标相等」换成「字节模式 E8+rel32 且目标相等」，
   Q1 的总数变成多少？（两者差值即失步噪声，必须给数）
R2 若把状态对象的槽位判据从 {0,4,8,0xC} 放宽到全 16 字节任意偏移，
   0x4A1CA0 体内出现的不同偏移集合是什么？
R3 把 Q1 的前向反汇编窗口从 96 字节改成 32 字节，四类计数如何变化（给数），
   用以说明窗口选择的敏感性。
