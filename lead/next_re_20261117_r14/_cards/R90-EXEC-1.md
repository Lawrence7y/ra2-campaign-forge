# R90-EXEC-1 — gamemd.exe 的 .data 虚拟尾部与 272 B overlay 独立复算（只做一件事）

## 你是谁

R17 子代理，家族 deepseek，角色执行员。只允许在目录 _r90/_exec/ 下写三个文件：tail_exec_r90.py、REPORT.md、tail_exec_r90.json。不得修改、移动、删除任何其它文件。你写的所有文件里都不要出现反引号字符。

## 硬性禁令（违反即作废）

1. 不许复制仓库存放树。临时文件只许建在 /tmp/r90exec/ 下（自己 mkdir）。产物总量上限 10 MB。
2. 不许读 _r90/ 下除 _r90/_exec/ 以外的任何文件，尤其不许读 _r90/ 里主会话写的脚本与 json。
3. 不许把任何既有报告里的数字当结论抄进来；每个数都必须你自己从镜像字节算出来。
4. 只做下面五步，不做扩展分析。

## 输入（路径写死）

镜像：ra2bench/gamemd.exe（只读打开，4825360 B）。本机可用 python3 的 pefile 模块、i686-w64-mingw32-objdump、和 python3 的 capstone 模块（版本 5.x）。禁止 import 仓库里任何模块。

## 要测的五件事（每件都要正反控）

第 1 件 · 段表事实：用 pefile 打印全部 5 个段的 Name / VirtualAddress / Misc_VirtualSize / PointerToRawData / SizeOfRawData。算出 .data 的虚拟尾部区间（起点 = ImageBase + .data.VirtualAddress + .data.SizeOfRawData，终点 = ImageBase + .data.VirtualAddress + .data.Misc_VirtualSize），报起点、终点、长度（字节）、并换算成 MiB（1 MiB = 1048576 B，保留 4 位小数）。再用 objdump -h 的输出作为第二台仪器核同一组数；两台仪器的 .data 四个字段必须逐字段相同，不同就如实报差异并停。

第 2 件 · 尾部内容形状：该区间超出文件末尾，因此文件里没有它的字节。必须写出「为什么这段无法从文件读字节」的机制理由（看 PE 头里与装载有关的字段），并用两条独立事实支撑：(a) 该文件有没有重定位表（数据目录 5 的 VirtualAddress 与 Size）；(b) 可选头 DllCharacteristics 的 0x0040 位是否为 1。报这两个值。反控：如果 (a) 非空或 (b) 为 1，则"装载时这段一定是零"这个说法不成立，你必须明确报"不成立"。

第 3 件 · 引用普查：用 capstone 32 位模式从 0x401000 线性反汇编 .text（长度 0x3DF38D），把所有指令操作数字符串里形如 0x十六进制的立即数取出，统计落在尾部区间内的指令条数、去重后的目标地址个数、目标地址的最小值与最大值、以及这些目标地址落在多少个 0x1000 页上（尾区间共多少页，两数都要报）。正控：用同一方法统计落在 .data 文件内区（ImageBase+0x812000 到 ImageBase+0x87E000）的引用，条数应远大于尾部（报数即可，不设阈值）。反控：用固定随机种子（自己定，写进报告）生成同样数量的随机 4 字节对齐地址（限定在 0x401000 到 0xB79BE4 之间），统计落在尾部区间的个数，作为随机基线。

第 4 件 · 静态指针表：在 .rdata 与 .data 的文件内区里按 4 字节对齐扫 dword，统计其值落在尾部区间的个数（两个段各报一个数），并列出 .rdata 命中项的前 5 条（给出持有该 dword 的地址与它指向的值，均为十六进制）。正控：用同一扫描统计值落在 .data 文件内区的 dword 个数，应远大于尾部命中数。反控：把尾部区间整体平移 +0x1000 再扫一次，报命中数。

第 5 件 · overlay：文件尾超出「最后一个段的 PointerToRawData + SizeOfRawData」的部分有几字节，报该长度与它的前 64 字节十六进制。做账面恒等式核对：SizeOfHeaders + 5 个段 SizeOfRawData 之和 + overlay 长度 是否恰好等于文件字节数，报三个量与你算出的和，并明确写 yes 或 no。再把 overlay 前 32 字节里的可打印 ASCII 串提取出来（连续 >=4 个可打印字符），逐条列出。

## 输出

- _r90/_exec/tail_exec_r90.py —— 可直接复跑，最后一行打印自测项数与 FAIL 数（自测项至少 8 条，必须包含上面每件要求的正控/反控，且每条断言都要能真的失败）。
