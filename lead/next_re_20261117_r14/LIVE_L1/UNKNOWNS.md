# LIVE-L1 UNKNOWNS.md

1. **②-b 最终定性未闭合（本卡 FAIL）**：A 组多数成功自检未达标（l1_v2 A=1/5），故不给三方配对最终定性。B/C 真机观测（ infantry/vehicle 均被拒、无重叠）与静态 §2.5「head A 闸拒绝」方向一致，但缺合格 A 基线，不能抬为 [已证]。

2. **mode 语义混淆未解**：任务书面「mode 1/3 挂链 / mode 0 摘链 / mode 2 附属刷新」指 `0x43F180` 的**函数参数**（BuildingClass slot 73）；本卡只读到的全局 `0xA8B238` mode 全程=5（局内/暂停），二者不是同一量。挂链子模式在放置路径内自动执行，本卡未（也不能）用 Hook 直接观测 mode 1/3 的参数值。

3. **拒绝闸动态值未读**：`0x47C620` 的 arg2(=BuildingTypeClass*) 与 `0x47C853` 断点未采（需硬件断点/写内存，授权禁止）。本卡仅字节层沿用 R14_COMMON §2.4（静态比较集 {6 Building,2 Aircraft,0x24 Terrain} 不含 15/1）。

4. **ghost 在手判定不稳**：`o1(+0x81)=1` 同时覆盖「已下单 limbo」与「Ready 待拾取」与「ghost 在手」三态，单靠 o1 不可判。本卡改用足迹像素（绿或红≥3000）判定，但受地形/相机/暂停菜单漂移影响，v3/phase2/final 多次 run 未能稳定重建 ghost 在手态。

5. **随机地图/视口漂移**：每次新会话单位起始格不同（(105–113,55–63) 与 (26–36,81–90) 两族都出现过），`find_empty` 固定格范围与闭环 SAFE 边界在部分会话失效，致 A 锚点不可达（good_A=[]）。10 分钟会话间隙还导致 gamemd 自行退出（except.txt 未变，非崩溃）。

6. **C4 伪成功**：l1_v2 中 C4 `success=True` 仅因 NAPOWR 计数增加，落点 (112,61) 与目标车格 (113,59) 不重合（link_after=False），不计为重叠。

7. **绿基线非 0**：l1_v2 无 ghost 绿=1009（亮草地/UI），非纯黑背景；判据用同页配对比值 15.34×，未用 0 基线夸大倍数（区别于 W177-I 的 0.0008 纯背景）。
