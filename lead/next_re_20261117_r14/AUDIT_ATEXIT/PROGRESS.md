## 1 判据（本卡核心，必须先说清）
**活 vptr = 构造器写入某个 global 的那个 `mov dword[<global>],<vt>`。** 判据实现（`work\analyze_lib.py: classify_v2`）：
1. 先分 **C**：entry 出现在 `E8/E9/rel8/jcc` 直接目标（指令边界 68,244 个 call / 14,993 个 jmp）**或**是 .text 内任一立即数（95,242 个值）⇒ 不属虚表可达型。
2. 否则找 entry 在数据段的所有落位 P，取所在 code-pointer run 内的表起点 T（候选 = run 首 / COL 锚 **1,212** 个 / 实装目标），槽 K=(P−T)/4。
3. 取 T 的**全局锚定**写入：`mov dword[abs],<T>`（6,089 个 imm-store 中 407 个落在 292 张表上）。
   - 写点函数 ∈ **atexit 注册函数集**（`push <fn>; call 0x7C978A`，336 个 atexit 调用 / 321 个注册函数）⇒ **析构器侧，非活值**
   - 否则 ⇒ **构造器侧 = 活值** ⇒ **A**
4. 只有析构器侧 ⇒ **B**；两侧都没有 ⇒ **D**（fail-closed）。
> 反例防线：`VectorClass<T>::~VectorClass()`（`0x40BBC0`）用 `mov [esi],<基类 vt>` 装基类表——它是**析构器**，且该表从不是任何 global 的活 vptr。按“表中出现 entry”判 A 会全错（首版即如此，26 行对照 0 命中）。
