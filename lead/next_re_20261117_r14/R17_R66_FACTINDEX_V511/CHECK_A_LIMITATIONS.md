# R17 第 35 轮 · Check A：`limitations` 列中**非 `§` 形式**引用的核验

## 一、口径（两段式，沿用 §2.20 / §2.21 纪律 9 的两步法）

对 `limitations` 列里每一处**非 `§` 形式**的引用（`Fnn` / `Mnn` / `R17_*` 卡名 / 裸文件名 / `LEAD_LOCK` / `台账` / `看板` 等），逐处判两件事：

1. **可解析**：被引对象在磁盘上真实存在（fact_id 在索引内、M 项在其所属卡内、卡目录存在、裸文件存在）。
2. **锚内性**：若该句是**证据声称**（「X 支撑本行某事」「X 给…原文」「原稿 X 记为…」），则 X 必须落在**本行** `evidence_paths` 里；
   若该句只是**引用义务**（「须同引 X」「与 X 同看」「引用时二者同看」），则**不要求**在锚内——它规定别人怎么引，不声称自己是证据。

> 第 2 步的分界是本轮的方法要点：上一轮（§2.21）已发现 13 行属「引用义务」而非缺陷。
> 若把引用义务也判为「锚不在本行」，会把 13 条本来正确的记录改坏——这正是两次 adequacy 审计（13 条 PARTIAL 驳回 9 条）的同一错型。

### 🔴 缺陷 1 · `F15`：`stats.tsv` 现值错配 + 引用的草稿卡不在锚内

原文（v5.10）：

> `stats.tsv` 的 108/82/4/33 是过期中间态、已被 REPORT.md 取代、不得引用(见 conflicts.md C01)；…；原稿 R17_LEDGER_1063 记为 108/82/4/33

**实测（现盘）**：`R17_R28_R12_REPAIR\stats.tsv` 记录

| 指标 | 现盘值 |
|---|---|
| `host_changed` | **129** |
| `fn_end_changed` | **125** |

| `unresolved` | 3 |

与同目录 `REPORT.md`（`129 / 125 / 5`、未解出 3、应改判 19）**完全一致**；`interim.json` 亦为 129/125/5/19。
⇒ **`stats.tsv` 现盘并不含 108/82/4/33**，且它**不是**过期中间态、恰恰是权威值。

**108/82/4/33 的真实出处**：被取代的**草稿目录** `R17_LEDGER_1063`（事项 4）——
其 `SUPERSEDED.md` 逐字写明「本目录：`host_changed` 108 / `fn_end_changed` 82 / `position_assert` 翻转 4 / 需重分类 33」，权威为 129/125/5/19。

⇒ 这条限制把**草稿卡的数字**归因给了 `stats.tsv`，并对一个正确的文件下了「不得引用」的禁令。两个后果都是实质的：
① 读者按本条会拒绝引用当前权威文件；② 「原稿 R17_LEDGER_1063」这个引用**不在本行锚内**（锚里只有 `1063R`）。

**修法**：正文改为陈述现盘值 + 把 108/82/4/33 归到草稿目录 + 权威值归 1063R；并把 `R17_LEDGER_1063\SUPERSEDED.md` **加入锚**（不是删引用）。
