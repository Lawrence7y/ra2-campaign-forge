- **108/82/4/33 的真实出处**是被取代的**草稿目录** `R17_LEDGER_1063`（事项 4），其 `SUPERSEDED.md` 逐字记载该四数并列明权威值 129/125/5/19。

### `F35` — `M44 给 proved_strict 定义` 不成立

### ② `F24` — 正文把**行动裁决**当证据 + 数字**缺口径**

- 正文原写「**改指针无解，不再投卡**」，而同一行 `limitations` 自认它「属单源归因 + 行动裁决，不随数字一并作已证」⇒ 正文与自身限制矛盾。审计并核出该裁决在台账 `§1054` 是作为 **Lead 裁决**记的。
- 数字「23,791 文件 / 1.29 GB」是 **primary 口径**（6 类扩展名）下的规模，`REPORT.md` L39 逐字「扩展名限制不是形式，它把搜索面缩小了 58 倍」。按本项目自身规则「只写数字不写口径即不可引用」（`F11`/`F25`）必须补口径。
- 改法：删「不再投卡」、补 primary 口径与 58 倍；`limitations` 同步指明裁决在台账 §1054（该锚本就在本行内）。

### ② `F29` — 推断词写成直陈事实

- 正文原写「`0x6C2AC0` **是** `InterlockedIncrement` 真 AddRef」。字节只到 `call [0x7E11C8]`，被调方函数体未给；本行 `limitations` 自认该词是「推断措辞、未经字节证实」。
