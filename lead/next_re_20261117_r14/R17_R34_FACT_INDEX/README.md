# R17_R34_FACT_INDEX 用法说明

- 主索引：`FACT_INDEX.tsv`（TSV，5 列；表头 fact_id / statement / grade / evidence_paths / limitations），按 fact_id 排序（F01-F16）。
- 来源仅三类：`R14_COMMON.md` 2.6-2.10；台账 1062-1065（落盘为 `R17_LEDGER_106x/SECTION.md`，1063 另有修订 `R17_LEDGER_1063R/SECTION.md`）；看板 `STATUS_BOARD.md` 第10-13轮段。另：看板第7-9轮段承载定名链/槽表/反向映射的既定事实，按“主题必须覆盖”收录并在 limitations 标明段位。
- `evidence_paths` 相对仓库根；括号内为节号/事项号/行号，便于回查。只做提取与归类，不新增技术结论。

## grade 含义
- `[已证]`：字节级/计数已在来源中给出并可回查。
- `[静态推断]`：依赖单源或未做动态取证，按 2.8 规则B 标注、不得升格。
- `未取得`：来源明确写“未取得”或事实层面未拿到（F09 调用方、F16 语义/身份）。
- `[流程]`：方法学硬规则，非事实命题（F13）。

## 必须带限定引用的行（limitations 非空，禁止留空或写“无”）
- 几乎每行都有必须同引的限制；以下尤其不可拆：
- F04 调用方链：只证“至少一个派发点到达”，不证唯一/不证运行期执行；不改 2.9 收口。
- F05 覆写+显式调：只证指令层 this 传送，不提供行为层区分证据、不升格。
- F07/F08 2-b：定谳句 + a-e + 2.10 (a′) 是不可拆引用单元；引 (a)/定谳句须一并引 (a′) 与 a-e。
- F09 调用方未取得：不得写成“不存在调用方”；不证全局/唯一/运行期；须带 2.8 规则A 正反控。
- F10 静态不可达：照抄“静态未发现任何到达路径”，不断言死代码；不改 2.9 收口。
- F11 双口径：引用必须写明 S/C 口径，只写数字不写口径即不可引用；旧值须同引 1062。
- F12 433：只说明地址锚定，不支持改判；COVERAGE_ONLY 不等于名字错；三桶须带 R19 三条限制。
- F13 方法学：入口判定禁止按字节扫 C3/C2；报“调用了 X”不能只报存在性。
- F15 与 conflicts.md C01 联动：108/82/4/33 为过期中间态，129/125/5/19 为 REPORT.md 权威。

## 文件
- `conflicts.md`：来源间互相矛盾的清单（本轮 1 条，并列记录、不自行裁定）。
- `REPORT.md`：抽取统计、覆盖主题、未取得行、CR 校验结果。
- 全部 LF，无 CR。
