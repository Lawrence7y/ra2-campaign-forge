## 9 派发工作流的标准形状

每个推进工作流必须含：

```
phase("盘点/调查") → 并行子调查（分批 ≤ max_concurrency）
phase("独立复核")   → 每项一道独立复核（不同上下文，默认怀疑）
phase("撰写")       → 汇总成对外交付件
phase("复核")       → 冷读挑错（不许「是不是好」，要问「什么会让它崩」）
phase("门禁")       → world.run 跑 python -I -X utf8 确定性检查，exitCode 记入交付
```

**门禁必须有实质检查**，不能只验「文件存在」：
- 指纹绑定（实算，非手抄）
- 算术自洽（各段和 == 合计、rate == 分子/分母）
- 反扫描（禁采样 API 关键词）
- 一致性（如 verdict=PASS 则阻断项必须为空）
- 必填小节与字段

**每个子代理 TASK 都要写**：铁律照抄、唯一写域、上游指纹绑定、判定规则、未验清单要求。
