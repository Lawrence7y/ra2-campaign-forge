## 3 · 已证关键事实（引用前自己复核一遍字节）

### 3.1 类与虚表（里程碑 1，§846–§850）
- canonical 虚表集 = `W130_atlas\vtables_canonical.json`：**1,214 虚表 / 954 个有实现的类 / 954 主表**；类名总数 **988**（954 + 34 个纯接口）。
- **主表判定必须用 `COL.offset == 0`**，不能取"类的第一张虚表"（引擎按 offset 降序发射，主表在最后）。子表**可以**比主表长（`LocomotionClass` offset=4 子表 49 槽 > 主表 10 槽）。
- `COL.offset` 可以很大（`MouseClass` = 21784）。
- **`+0x2C` = WhatAmI() 只在 `ObjectClass` 继承树上成立**，1,214 张表里真正是 `mov eax,smallN;ret` 的只有 **144**。
- 槽计数要用 v2 规则（终止于"下一 dword 是合法 COL **或** 簇间常量 `404E0000/A2529D39/3F91DF46` **或** 非代码非 0"）。
- **镜像里没有 RTTI 符号**（`.?AV`/`COL` 0 命中）——但**有** MSVC 的 `COL` 结构（可反查类名），别混淆。

### 3.2 函数图谱（里程碑 2，§851/§864/§871/§872）
- **可枚举函数 12,916**（管理器总数 13,286，差 370 = `EXTERNAL` 空间的 PE 导入函数，§860 已闭合）。旧"8,578"**已废弃**。
- `.text` 覆盖率终值 **91.245%**（不是 79.5%，也不是 86.39%）。
- ⚠️ **`function_atlas.tsv` 的 `size` 列是十进制**，按 hex 读会让 81% 函数越界（§863）。

### 3.4 每帧链路（① 的真锚点，§881–§883）
- 唯一 `inc` 型帧推进：`0x55DE6A`（在 `0x55D360` 内）读写 `0xA8ED84`；目标帧 `0xB07784`；跳过标志 `0xA83D48`。其余 19 处对 `0xA8ED84` 的引用都是初始化/复位。
- 链路：**`0x6BB9A0`（引擎初始化）→ `0x48CCC0`（Conquer.CPP 主循环）→ `0x55D360`（每帧更新）**。
- 主循环内层（我亲自反汇编，§881-2）：`0x48CE5D call 0x7241A0`（②-a 受害例程）→ `0x48CE85 call 0x69BAB0` → `0x48CE8A call 0x55D360` → `0x48CE93/0x48CEA1 call 0x55CFD0` → `0x48CE9C call 0x48C8B0` → `0x48CEA8 je 0x48CE8A`。
- `0x55D360`：2,940 B、**90 处调用 / 44 个唯一 callee / 6 个循环**、自身不引用任何数组 Count；BFS 深度≤4 可达 **913 个函数**。
- **每帧主要候选**：`0x67D300`（4,411 B、**111 个回边**、遍历 House/Unit/Infantry/Building/Aircraft/Anim/Trigger **7 种数组**），路径 `0x55D360 → 0x67CEF0 → 0x67D300`；它只有 1 个调用者 `0x67D1AF`。`0x67CEF0` **未定性** ⇒ "它每帧必跑"**未证**。
- `0x647260`（`0x55D360` 的深度 1 callee）入口：`mov al,[0xA8D5F8]; test al,2; je 0x6474C7`。`0x6474C7` 是**按 `[0xA8B238]`（模式 0..5）分派的事件泵入口**，内含事件环形缓冲生产者（111 B/条 + `timeGetTime` 时间戳 + 16,384 项环），末尾无条件调消费者 `0x64C380`（2,474 B，遍历全环）。
- **SYNC 转储 `0x64DEA0`（11,242 B，`SYNC%01d.TXT`）/ `0x6516F0`（2,417 B，`SYNC%01d_%03d.TXT`）默认一次都不执行**（被 `[0xA8D5F8] & 2` 与 `-MPDEBUG` 门控，BSS 默认 0）。⇒ 不是每帧开销。
- 命令行解析器 `0x52F620`，共 **23 个开关**：`-MPDEBUG -ATTRACT -DROP= -jabber -str -nostr -noaudio -record -play -? -h -CD -DESTNET -SOCKET -SPEEDCONTROL -DLINK1 -NETGEAR -NOROUTER -STEALTH -MESSAGES -%dX%d -WIN -X`。`-ATTRACT` ⇒ `[0xA8D5F8] |= 4`；`-MPDEBUG` ⇒ `[0xB04880] = 1`。
- `[0xA8B238]` = **模式选择器（0..5）**，30 个写者；`0x52D9A0`(Init.CPP) 与 `0x48CCC0`(主循环) 写入 **0/3/4/5**。

### 3.5 ① 的定量模型（真机，72 趟量级，§732/§784/§3''3b）
- 度量口径：用每趟自带的 `run.ndjson`（harness 同步采集，约 12 MB/趟，字段含 `A8ED50`/`frame`/`t_monotonic`/`mode`），按 **10 秒分段**算 `ms/frame = 1000·Δt/Δframe` 与该段 `A8ED50` 均值，再算段间相关。**绝不可用自制采样器**（§3''3d）。
- 分桶（701 个干净分段）：子弹 **0–24 → 32.00 ms**（1.00×，满帧）/ 25–49 → 32.85 / 50–74 → 38.70 / 75–99 → 59.43 / **100–124 → 85.33（2.67×）**。
- 线性拟合（bullets ≥ 30，n=60）：**`ms/frame ≈ 0.6496 × bullets + 7.61`**（RMSE 10.73）。
- 饱和：子弹数被几何饱和在 **~250**，与单位总数无关（570+1200 贴脸 → 峰值 250）。
- 决定性对照：r(子弹数, ms/帧) = **0.921**；r(目标搜索/帧, ms/帧) = 0.442；r(目标搜索/帧, 子弹数) = 0.329。
- `Range` 干预：子弹降到 6.0，但最差帧 **123.26 ms（全组最高）** ⇒ 单位够不到敌人而堆积寻路，成本反升。`ROF`/`Burst`/`Speed` 干预全部**无效**（不动接战几何）。
- ⚠️ **精度限定**：某些窗口的 `ms/帧` 呈 **2:1 离散台阶（25.30 / 50.40）**，所以"≤24 满帧 / 100 发 2.67×"应理解为**分档结论**，不是精确连续函数。（这条正是 W153 要独立复核的对象。）
- 引擎**无子弹数上限**：`RULESMD_expandmd01.INI` 全键检索无 `MaxBullets`/`MaxProjectiles` 类键。

### 3.6 崩溃三条线（②-a / ②-b / ③）
- **②-a（NULL 单例入口）**：6 个入口守卫 + 3 处判空，已做**真机 A/B**：control 臂 `ecx=0` → `0xC0000005` 进程死；patched 臂存活（§842–§845）。真机现场 `Access address = 00000250` ⇒ **是真 NULL，不是悬空指针**（§876）。
