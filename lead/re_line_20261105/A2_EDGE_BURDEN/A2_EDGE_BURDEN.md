## 3. ★ 意外收获：既有口径误杀 1 窗（可复算的具体差额）

### 3.1 事实

`l1_20261023e4/measure_w1.json`：

```
stats.samples        = 12501
stats.logic_frames   = -3557
stats.n_edges        = 113
stats.n_multi_advance= 0
stats.frame_ms_p50   = None
stats.note           = 'frame not advancing'

frame_edges: 首沿 f=3557 t=17133.074818 ；末沿 f=0 t=17142.340036
帧号回退次数 = 1 ：3668 → 0 @ t=17142.340036（掉幅 3668）
```

harness `_measure_stats()`（`lead/goal1_harness8_20261031/qc151_trip.harness8_v4.py:4759`）算
`logic = int(f_b) - int(f_a)` = `0 − 3557 = −3557`，命中 `:4784 if logic <= 0`，
于是 `frame_ms_p50/p90/p99/max` **全部留 `null`**、`note='frame not advancing'`。

### 3.2 候选件复算（`_a2_rescue_check.py`）

把**同一份 `frame_edges`** 逐沿喂 `FrameEdgeTracker`：

```
事件总数 = 111
edge(df=1)       = 111
edge_missed(df>1)= 0
unjudgeable      = 1
first            = 1
missed_frames_lower_bound = 0

候选件保留的 df=1 帧时样本数 = 111
  p50 = 32.764 ms  (fps 30.52)
  p90 = 42.401 ms
  p99 = 47.463 ms
  max = 47.657 ms  (fps 20.98)
```

⇒ **同一窗，既有口径 `null`，候选件 111 个样本、p50=32.76 ms。**

### 3.3 规模（`_a2_scale.py`）

| 类别 | 窗数 |
|---|---|
| `p50=None` 的窗 | 29 / 87 |
| ├ **被误杀**（有 ≥10 个可用 df=1 沿） | **1** |
| └ 真·帧不推进（`logic=0`、`edges=1`、usable=0） | 28 |
| 有 `p50` 的窗 | 58 |
| └ 其中含 `df>1` 漏沿 | 1（`QC161-U0800-L3-H8-20261031B/w1`，n_multi=3，p50=182.86） |

**误杀率 = 1/87 ≈ 1.15%**，可救回 **111** 个帧时样本。

### 3.4 这说明了什么（以及**不**说明什么）

**说明**：harness 用「净推进 `f_last − f_first`」作早退判据，遇到**帧号回退**
（回菜单 / 重开局 ⇒ 帧号归 0）会把一个**本来完全可用**的窗整体判死。
候选件把回退标 `unjudgeable` 但**不污染前面的有效沿**，所以能救回。

**不说明**：
- 这**不**是「候选件更准」的普遍结论——只是**一个可复算的具体差额**（1 窗 / 111 样本）；
- 这**不**推翻任何既有**结论**（该窗此前也没被当作有效窗引用过）；
- **不**意味着应当改 harness——是否改、怎么改，是**独立决定**，本文只记录事实。
