## 1. 口径（决定结果对错的关键）

任务书要求「统计出现的动作 kind 直方图」。`[Actions]` 的行格式由项目自身代码写死：

- `ra2forge/triggers.py:19–20`：`[Actions]  ID=COUNT,(CODE,P1..P6,P7)*`（P7 未用时写 `A`）；
- `ra2forge/maplib.py:463–472`：写出时 `parts = [len(t["actions"])]`，然后每条动作追加
  `CODE + 6 个参数 + P7` = **8 个 token**；故一行共 `1 + COUNT*8` 个逗号分隔 token。

实例（`ra2youli/[2]0LoadBench_U0400.yrm:401–404`，实读）：

```
[Actions]
03F504FC=9,99,7,_Amb_BirdsTemperate1,0,0,0,0,AE,99,7,_Amb_BirdsTemperate1,...,AM
03F50E1C=4,99,7,_Amb_UrbanMurmur1,0,0,0,0,AA,...,AD
03F51C4C=2,99,7,_Amb_WindPlains,0,0,0,0,AN,99,7,_Amb_WindPlains,0,0,0,0,AO
```

第一行的 `9` 是 **COUNT=9**（该触发器有 9 条动作），不是 kind；其 9 条动作的
kind **全是 99**（`PlaySoundEffectAtWaypoint`，见 `docs/re/trigger_system_manifest.md:236`）。
全图三行共 `9+4+2 = 15` 条动作，`kind` 直方图 = `{99:15}`。

探针 `_q3b_probe.py:56–105` 同时算两套直方图以对齐领队口径：
`count_hist`（首 token 的频次）与 `kind_hist`（每 8-token 组的首 token，即真实 kind）。
全量 **1,261 条记录零畸形**（`len(rest) == COUNT*8` 全部成立，`_q3b_probe_out.txt:12`），
且额外做了与布局无关的交叉校验：`[Actions]` 段值里**裸 token `110`/`127` 出现 0 次**
（`_q3b_probe_out.txt:13`）——即使 8-token 口径假设有误，也没有任何 110/127 漏网。
154 个文件各只有 1 个 `[Actions]` 段（`:8–9`）。

动作 110 / 127 的名称与编号取自 `docs/re/trigger_system_manifest.md:247`（110 = `0x6E` `PauseGame`）
与 `:264`（127 = `0x7F` `StartChronoScreenEffect`）。
