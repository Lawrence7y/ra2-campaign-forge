## 3 `alpha_i` 的本质：它不是引擎常数，而是「每次事件平均耗时」的倒数

设窗口内第 `i` 个成本中心发生 `n_i` 次原子事件，第 `j` 次墙钟耗时 `d_{i,j}`，则

$$ T_{Ci} = \sum_{j=1}^{n_i} d_{i,j} = n_i \cdot \bar{d}_i .$$

- **流量型**（`i=1,4`）：若每次事件产生 `k_i` 个计数增量，则 `y_i = k_i · n_i`，于是

$$ \alpha_i = \frac{k_i n_i}{n_i \bar d_i} = \frac{k_i}{\bar d_i}. $$

- **水位型**（`i=2,3`）：`y_i = L_i(t_\text{sample})` 是**某一采样瞬间**的队列/容器长度，与窗口积分 `T_Ci` 不是同一泛函，上式**根本不成立**（详见 §4.2、§4.3）。

关键点：`\bar d_i` 不是常量。静态证据显示同一「事件」的工作量跨度极大：

## 4 逐 `alpha_i` 的理论下界 / 上界

记号：`τ_{i,max}` = 单次事件**墙钟耗时上界**，`τ_{i,min}` = 单次事件**墙钟耗时下界**，`k_{i,max}` = 单次事件最多产生的计数增量数。所有含 `τ` 的界都是**条件化**的（条件写在每一条里）。

### 4.1 `alpha_1`（`y_1 = ΔGenStamp`，C1 寻路：流量型）

**(a) 条件化下界 —— 即 `TASK.md:63` 范例的形式。**
若：① 每次 `FindPath` 至少推进 1 个代际戳（`0x42A5FB/0x42A5FE/0x42A5FF`，本次实跑 ① 确证 `inc` 写回 `this+0x28`）；② 窗口内无回绕 / 无重置 / 无进程重启，且 `Δ` 取的是同一生命周期内的差分；③ `τ_{1,max}` 已知，则

$$ \alpha_1 \;=\; \frac{k_1}{\bar d_1} \;\ge\; \frac{1}{\tau_{1,\max}} \qquad \left(\text{即 } \alpha_1 \ge \frac{1}{\text{单次搜索耗时上界}}\right). $$

- 条件 ① 的**上侧**并不干净：`0x42CC80` 同步重试再次调 `0x42A5B0`（本次实跑 ①），`Q1_C1_PATHFIND.md:69-71` 给出重试上限 5；`FACTBASE_D19.md:32,120-122` 记载回绕路径 `0x42A67F..0x42A685` **再自增一次跳过 0**；`0x42D17D` 属于另一个入口 `0x42D170`（`FACTBASE_D19.md:31`），故 `TASK.md:23` 写「**入口覆盖不全**」。⇒ `k_1 ≥ 1` 只在「未回绕、未重置、写点穷尽」的子情形成立。
- 条件 ② 被 `TASK.md:23`（回绕跳 0、重置）与 `FACTBASE_D19.md:37`（对 `0x00A8EC34` 的同类告诫「不穷尽间接别名写、加载/进程重启，**不背书跨生命周期无条件单调**」）直接破坏。重置可使 `Δ y_1 ≤ 0` 而 `T_{C1} > 0` ⇒ **`alpha_1` 可为 0 甚至为负**。
- 条件 ③ **静态不可得**：见 §3。Q1 只给指令数上界（65,527 节点 × 1500 指令，`Q1_C1_PATHFIND.md:112,135`），不是墙钟上界；换算所用的 0.35–0.4 ns/指令是**假设**（`:143`）。

**(b) 条件化上界。** 若 `τ_{1,min}` 已知，则 `alpha_1 ≤ k_{1,max}/τ_{1,min}`，其中 `k_{1,max} ≥ 5`（重试）+ 回绕多增。`τ_{1,min}` 只受「`inc` 前后的几条指令 + 早退路径」约束，静态字节给不出墙钟下界（同样受 §3 的机器/OS 项影响）⇒ **无有限静态上界**。

**(c) 严格无条件界：`alpha_1 ∈ (-∞, +∞)`，即无约束。** 只有附加「无重置/回绕、写点穷尽、`Δ ≥ 1`、`T_{C1}>0`」后才退到 `alpha_1 ∈ [1/τ_{1,max},\; k_{1,max}/τ_{1,min})`，且两个端点**均未校准**。

### 4.2 `alpha_2`（`y_2 = DirtyAreas.Count`，C2 渲染：**水位型**）

**(a) 下界 = 0，且这是可实现的。** `FACTBASE_D19.md:37`：该 VA 是 `0x00B0CE78` 脏矩形向量**当前条目数**，有初始化 `0x6D1A60..0x6D1A9C`、插入递增 `0x6D2A94..0x6D2AB8`、删除搬移递减 `0x6D2983..0x6D29BE` 与 `0x6DA980..0x6DA9BD`、且可**合并去重**（`docs/re/dirty_rect_l4.md:179-218`）。队列可在一帧绘制后被排空 ⇒ `L_2(t_\text{sample}) = 0` 与任意大的 `T_{C2}` 相容。故 `inf alpha_2 = 0`，`RULING_D19.md:23`(F7) 明说「**少量/零 Count 不能自动排除全部渲染**」，并否定 `<0.05 ms` 推论。

**(b) 上界 = +∞ / 无定义。** `RULING_D19.md:23`(F7) 「Render 还检查其他标志和视口位移」，静态上不能排除 `L_2 > 0` 而该窗 `T_{C2} = 0`；此时 `alpha_2 = L_2/T_{C2}` 发散。`FACTBASE_D19.md:37` 亦否定「少量/零队列 ⇒ 全部光栅化短路」的逆命题。

**(c) 更根本：`y_2 = alpha_2 · T_{C2}` 这一行模型不成立。** 左端是**瞬时水位**，右端是**窗口累计耗时**；二者之间还隔着「脏矩形 → 可见单位数 → `DrawIfVisible` 调用数 → VXL 光栅化」整条链（`Q1_C2_RENDER.md:147,252-255`），而 `TASK.md:25,27` 明定它**不是可见单位数、不得换算为耗时**；`RULING_D19.md:103` 明定「不以 D-19 采纳四 VA 替代真实视口坐标、可见单位数……附加字段需另补证」。

⇒ **`alpha_2 ∈ [0, +∞]`，完全不受约束（平凡界）；且该行方程本身是误设。**

### 4.3 `alpha_3`（`y_3 = BulletCount`，C3 物理：**水位型**）

**(a) 上界 = +∞ / 无定义（本次实跑 ① 直接支持）。** `0x55B93F` 读 `0x00A8ED50` 得到 Count，循环内 `0x55B954 mov al,[ecx+0x98]`、`0x55B95A test`、`0x55B95C je 0x55b963` —— **活跃标志为 0 就跳过 `0x55B960 call [edx+0x5c]` 更新**。因此「注册 Bullet 对象数 > 0 而本帧实际更新 ≈ 0」是静态可见的可实现状态，⇒ `T_{C3} → 0` 而 `L_3 > 0`，`alpha_3` 发散。这正是 `TASK.md:26` 的「实际更新另受活跃标志门控」与 `RULING_D19.md:24`(F8)。

**(b) 下界 = 0，且这是可实现的。** `T_{C3}` 还包含 `AnimClass::Array.Count`(`0x00A8E9B8`, `Q1_C3C4_PHYS_TARGET.md:196`) 与 `DamageArea` 结算（`:269-289`），二者**不在 `y_3` 里**；`BulletCount = 0` 与 `T_{C3} > 0` 相容。`RULING_D19.md:24`(F8) 明说「Count 不会直接提供动画/伤害耗时或推出 ≤60 就 <0.1ms」。

**(c) 同为水位 → 累计耗时的误设**（同 §4.2(c)）。`Q3_SAMPLE_PLAN.md:20,126-130` 的「`≤60 ⇒ <0.1ms` / `≥2000 ⇒ C3 异常`」阈值本就被 D-19 F8 否定。

⇒ **`alpha_3 ∈ [0, +∞]`，完全不受约束（平凡界）；且该行方程本身是误设。**

$$ \alpha_4 \;=\; \frac{1}{\bar d_4} \;\ge\; \frac{1}{\tau_{4,\max}} .$$

## 5 「四方程四未知」能否因此变成可解？

### 5.1 判定：**不可解**

### 5.2 构造性反证：这四个方程对分解不施加任何约束

把 `alpha_i` 还原为未知量后，W3 的系统是：

$$ \underbrace{y_i = \alpha_i T_{Ci}\ (i=1..4)}_{\text{4 个双线性方程}},\qquad \underbrace{\textstyle\sum_i T_{Ci} = \Delta T_\text{deficit} - \epsilon}_{\text{1 个和方程}} .$$

未知量至少 `T_{C1..C4}`(4) + `alpha_{1..4}`(4) + `ε`(1) = **9 个**，方程 **5 个** ⇒ 至少 4 个自由度；`y_i = alpha_i T_i` 是**两个未知量的乘积**，不是线性方程，因此 `Q3_SAMPLE_PLAN.md:178` 所算的「5×4 矩阵 Rank = 4」是**在假设了待求校准量之后**才算出来的秩，对真实系统不成立（`RULING_D19.md:20`(F4)、`:39`、`:66`）。

更直接地：**任给**一组观测 `(y_1..y_4, ΔT)`（`ΔT>0`）与任意满足 `T_{Ci}>0`、`ΣT_{Ci}=ΔT` 的向量（这是一个 3 维单纯形，无穷多组），令 `alpha_i := y_i / T_{Ci}`，则五个方程**全部精确成立**，`ε=0`。也就是说，对**任何**观测结果，四种成本中心可以任意分配 `ΔT`（可以让 C1 占 99%，也可以让 C2 占 99%），都能找到一组 `alpha_i` 自洽。⇒ **这五个方程对 `T_{Ci}` 的分解零约束**，`Q3_SAMPLE_PLAN.md:178` 的「超定 ⇒ 唯一解」不成立。这与 `Q3_SAMPLE_PLAN.md:145` 自己的断言「纯宏观时间序列在信息论上缺少至少 3 个维度的独立信息」一致，只是 W3 在 `:149-151` 换了一组观测量后没有补上那 3 个维度的依据。

### 5.3 为什么即便「多采几个窗」也补不上（理论退路及其失效条件）

形式上，若 (i) `alpha_i` 在 `W` 个窗间**是同一个常数**、(ii) 每窗都测到 `y_{iw}` 与 `ΔT_w`、(iii) `ε=0`、(iv) 四行模型都成立，则代入 `T_{iw}=y_{iw}/alpha_i` 得 `Σ_i y_{iw}·β_i = ΔT_w`（`β_i := 1/alpha_i`），当 `W ≥ 4` 且 `y` 矩阵满秩时 `β` 可解 —— 这相当于用跨窗变化把 `ΔT` 回归到四个代理量上。这条退路**在本案全部四个前提上都失败**：

1. **(i) 与静态证据冲突**：`alpha_i = k_i/\bar d_i`，而 `\bar d_i` 随节点数（0…65,527，`Q1_C1_PATHFIND.md:112`）、扫描格数（361…3,481，`Q1_C3C4_PHYS_TARGET.md:154-157`）、地形/缓存/OS/挂起（`W1_HOLD_SURFACE.md:129`）变化 —— 它不是跨窗常数，是**逐窗随机变量**。每多一个窗就多 4 个 `T` 与 4 个 `alpha`，自由度不收敛。`RULING_D19.md:41` 亦指出跨窗 p50 变化推不出窗内带宽。
2. **(ii) 当前没有数据、也没有采集权**：§2.3 实跑证实既有 harness 四个 VA **0 命中**；`Q1_C3C4_PHYS_TARGET.md:318-319` 记「历史 `measure_w*.json` 的 `counters` 从未读取该 VA」。任何新增采集须走 `TASK.md:34`、`RULING_D19.md:61,75` 的双闸（候选代码/离线验证 → 指定批次真机/活进程采集），E3 另裁。
3. **(iii) 残差不可消**：`Q3_SAMPLE_PLAN.md:183-185` 自己承认残差会吸收「系统调度、内存换页、GC 抖动」等未建模噪声并造成伪阳性；`RULING_D19.md:59-60` 要求先写定跨帧/`df>1`/null/时间戳口径才谈回归。
4. **(iv) 两行误设**：§4.2(c)、§4.3(c) —— 水位不是累计耗时。

⇒ 在「不采帧内数据」+ 现有授权边界下，**没有任何途径把 `alpha_i` 变成已知常数**。

### 5.4 能诚实说什么

`RULING_D19.md:60`：「没有成本映射证据只能报告**关联、代理变化与残余缺证**」；`:99`：「不裁实际慢帧主因、四成本时间占比、优化排序或完整因果闭环」。本文不产出任何 `alpha_i` 数值、任何 `T_{Ci}` 分解、任何主犯判定。
