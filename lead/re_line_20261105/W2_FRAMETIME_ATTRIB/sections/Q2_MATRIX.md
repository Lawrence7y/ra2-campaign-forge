判断条件：
1. 同一地图：`r1.map_sha8 == r2.map_sha8`；
2. 初始兵力相差 ≤10%：`relative_diff(u1, u2) <= 0.10`；
3. 帧时中位数相差 >1.5 倍：`max(p1, p2) / min(p1, p2) > 1.50`（要求两窗 p50 均非 None）。

- **大者基准口径（主口径，Max-based）**：`|u1 - u2| / max(u1, u2) <= 0.10`。命中 **107 对**。任务书 §2（行 44-45）明确将 `v4d`（1225）与 `v3a`（1349）定性为「单位数只差 10%，帧时差 2–5.7 倍」，在此口径下 `|1349 - 1225| / 1349 = 9.19% <= 10%`，恰好覆盖该任务靶子核心对照组。
