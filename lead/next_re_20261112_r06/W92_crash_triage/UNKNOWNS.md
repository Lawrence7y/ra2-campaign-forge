# W92 UNKNOWNS（未证项清单）

1. **R03 dose800 原件丢失**。EIP=0x0051C2D3、EAX=0、Access=0x1D4 全部 `[转述，不可复核]`。镜像侧仅证实：0x51BF90 是函数入口、0x51C2D3 处指令为 `call [eax+0x1D4]`（FF 90 D4 01 00 00）。崩溃寄存器与现场不可证。
2. **覆盖者未定位**。本卡证明的是"哪个字段坏了、坏成什么值"（vptr 槽 ×4、索引字段 ×1、全局单例 ×1），**没有证明是谁写的**。离线无内存时序证据。
3. **类名无 RTTI 证据**。gamemd.exe 无 `.?AV` 类型描述符与 Complete Object Locator（pe_disasm2 §C 全 0）。"槽 +0x2C = WhatAmI、N=6=BuildingClass" 中，槽语义为镜像实证，**类名映射沿用项目已知信息**。
4. S5（0x6F36FE）的字段语义：`[eax+0x9C]`（索引）、`[edx+0xAC]`（数组基址）、`[ebp]`（this）各属什么结构，无符号名，仅按指令形态描述；函数入口只能定到"0x6F36DB 起的共用尾/入口候选"，未回溯到真正 prologue。
5. **archived vs archived_late 逐字节相同**的原因未证（同一现场双落盘 vs 流程复制）；不影响签名结论。
6. W88_C7 与 W91_P1 的 wanted-WhatAmI 参数同为 0x24（36），不同战役输入下同参数是否巧合 `[未证]`。
7. 四个 vptr 垃圾值（0x000A0008 / 0x001E0000 / 0x15FD38E8 / 0x10D6E7A0）的具体来源（堆块、写入时刻）未证，需运行时内存取证。
8. S1–S4 与 S5 是否共享同一上游写穿 bug：无证据连接或排除。P3（1522 对象）满时长不崩与 S5 的关系未证。
9. 全镜像仅核对了三处可读 EIP 各 32 字节的"Bytes at CS:EIP == 镜像字节"；其余代码区域未做全量比对。
