### 5.4 根本性、无法加固的漏洞

**P7**：本生态无密码学身份机制。「真实外来 sessionId + 一件机器记载形态的伪造外部记载 + 一个真读环境的取值机制」三件套，在任何离线文书协议（无论 A-G 检项多密）面前都能走到「A-G 全 PASS、无已知伪造痕迹」——因为协议的全部检法都是文书核对，而伪造者提交的也是文书。协议 §6-1（:173）自认「核心命题不可第三方终证……这是降依赖，不是消除依赖」；§6-3（:175）自认「一个真读环境的机制在其会话里产出的值被事后替换文本仍不可检」；自证件 :250-252 自认同类上限。本演练以实跑坐实：三件套每一件都有盘上实跑证据（§3 A1/A4/A6 行）。**必须承认：这是根本性漏洞，无法在文书协议层加固消除。**

### 5.5 协议效力上限

协议的真实效力 = **抬成本，不是消除伪造**：迫使伪造者至少①伪造一件机器记载形态的外部记载（而非纯散文）；②构造一个真读环境且 F1 双分支都可解释的机制；③长期暴露于可撤回性巡检（D4 跨件矛盾随时触发降级/撤销）。加固后（P1-P6 落地）可把单 actor 伪造从「逐字面零成本」抬到「至少伪造机器记载 + 双硬条件」，但**不可能把通过档变成「值为真」的证明**——协议自己的话：「把一次性不可证的真转换为持续性可证伪的一致 + 多方合谋成本 + 可检痕迹」（:173）。若编排方见证仍只是文本，P2 加固也只抬成本。
