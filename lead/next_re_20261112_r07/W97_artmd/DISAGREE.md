## D1 【已裁·主任务】`TESLA` 底座：`1×1`（W89 对） vs `3×2`（W95 错）

**别人（W95，`r06\W95_audit\AUDIT.md:134-137` 与 `UNKNOWNS.md:26`）**
> 按 3×2 底面普查：col 步长 2 → NAPOWR 10 + **TESLA 14** = 24；col 步长 3 → 0 + **TESLA 14** = **14**。
> "去掉重叠"字面为假 —— C3/C6 上仍有 14 格是两座建筑共用一格。

**我看（`[本次实测]`）**
- `artmd.ini`（sha256 `e1f03783…`）里 `[NATSLA] Foundation=**1x1**`；`TESLA` 在 rules 里 `Image=NATSLA`，`artmd.ini` **没有 `[TESLA]` 节**。

**证据**：`EVIDENCE/probe06_stdout.txt`（artmd 原文+行号）、`probe07_stdout.txt`（A/B 对照）、`probe09_stdout.txt`（锚点敏感性）、`foundation_evidence.json`。

## D2 【已裁】"`mixlib` API 用法有误"——不是用法错，是名字假设错

**别人（`§630-3-2`，行 10511）**
> `Foundation` 在 `artmd.ini`，本会话未能提取（`mixlib.get('artmd.ini'/'rulesmd.ini')` 均 `None`，与 W89 曾抽出 743 KB `rulesmd.ini` 矛盾 ⇒ **API 用法有误**）。

**我看（`[本次实测]`）**
- `mixlib` 的 `crc_hash = zlib.crc32(UPPER(name))` 是**对的**：我用 `gamemd.exe` 自带的文件名字符串反查，`LOAD.MIX` / `ISOGENMD.MIX` / `ISOTEMMD.MIX` / `TEMPERAT.MIX` / `BATTLEMD.INI` / `AIMD.INI` / `UIMD.INI` / `MAPSELMD.INI` **全部命中**存档 id。
- 引擎自己声明它要 `ARTMD.INI`（`0xAF902833`）和 `RULESMD.INI`（`0x1F674573`），而这两个 id 在 **17 个顶层 mix + 一层嵌套**里**都不存在**。
- 三个大 INI 的 xor 差异互不相同 ⇒ **换了名字**，不是换了种子。
- W89 那份 743,215 B 与 `expandmd01.mix:0x8218F9F4` **sha256 全等** ⇒ 它是**按内容/大小**枚举出来的，不是 `get()` 出来的。

**判定**：`get()` 返回 `None` 是**正确行为**。真正的坑是 **`mixlib` 完全没有嵌套 MIX 支持**（`ra2md.mix` 的 25 个 entry 全是嵌套 MIX），且 `names()` 是**存根**（只回 `_XXXXXXXX`）。这两点才是可复用的教训。

**证据**：`probe11_stdout.txt`（100+ 条名字反查）、`probe13_stdout.txt`（可达性普查）、`probe14_stdout.txt`（xor 非恒定）。
