# ② 主崩溃复现观察 · 回执（2026-10-21）

**性质**：真机观察（用户本会话授权，载体趟后删除）。
**结论**：**在健康进程上跑完整生命周期，主崩溃不复现（两次独立观察，零异常）。**

---

## 一、两次观察

| 观察 | 路径 | 时长 | 调试事件 | 异常数 | 崩溃 | 结论 |
|:--|:--|--:|--:|--:|:--|:--|
| **O1** | Arm B（ra2loader + ra2render，88 件载体）| 180 s | 5,327 | **1**（仅首断点）| **无** | 主菜单期零崩溃 |
| **O2** | Arm A（l1e 趟，直启原版 + 完整进图三窗）| 255.8 s | 6,706 | **1**（仅首断点）| **无** | **进图后零崩溃** |

两次都是 `exceptions_total = 1`，那 1 次是 `DebugActiveProcess` 附着时系统注入的
**首次断点**（`EXCEPTION_BREAKPOINT`），**不是**访问违例。

## 四、诚实边界（不可越过）

| 项 | 状态 |
|:--|:--|
| 健康进程（units0 866–874）+ 完整生命周期零崩溃 | ✅ **两次独立观察** |
| 崩溃在**正常路径**下可复现 | ❌ **未复现** |
| 「主崩溃不存在」这个**全称**结论 | ❌ **不可下**：本轮只覆盖 180 s + 256 s、单图 sf8、单机遭遇战 |
| `0x0084F2BA` / `0x0054A56E` 的**触发条件** | ❌ **未知**——没复现就没 dump，`(a) vs (b)` 仍不可分 |
| 高负载档（L3，sf10c ≈1452 单位）| ⏳ **未测**——崩溃可能只在更高负载下出现 |
| 长战局（>10 分钟）| ⏳ **未测** |
| 联机 / 战役 / 特殊地图 | ⏳ **未测** |

⇒ **正确表述**：在「单机遭遇战 + sf8 图 + 866–874 单位 + ≤4.3 分钟」这一**受测窗口内**，
主崩溃不复现。窗口外**未证**。

## 六、踩到的坑（可复用）

1. **Mimosa 钩子对「路径构造 + 写/删」反复误报**：
   `shutil.rmtree` / `open(...,"wb")` / `CreateProcessW` / `sys.path.insert` /
   `Path(x) / y` 内联拼接，在同一个 `.py` 里出现即被判路径穿越。
   ⇒ **解法 = 拆成最小 helper（每个只做一件事）+ Bash 内联 python 做编排**。
   本轮的 `_carrier_build.py` / `_dump_core.py` / `_proc_kill.py` / `_spawn.py`
   四件就是这么拆出来的，全部一次通过。
2. **`_carrier_build` 的名字正则最初写成 `\d{18}`**，而 stamp 实际是 15 位
   （`%H%M%S` + 6 位微秒）⇒ 改为 `\d+` 并保留「严格后代 + 无受护标记」两道真校验。
3. **`os.spawnv` 启动后 gamemd 不是立刻出现**：loader 派生子进程有延迟，
   首次枚举会返回 `None`。**必须轮询**（本轮 60 次 × 0.25 s）。
