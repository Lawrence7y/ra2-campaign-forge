## 1 · ★ 本轮技术突破：RA2 遭戦地图列表**可程序化读取与选中**

### 1.1 背景（上一轮的失败结论）

上一轮判定该 ListBox 读不到条目：
- style `0x50000151` → **`LBS_HASSTRINGS`(0x40) 未置位**
- `LB_GETTEXT`（本进程缓冲）→ 全空
- `LB_GETTEXT`（`VirtualAllocEx` 目标进程缓冲）→ **仍全空**

⇒ 当时结论是「条目以用户数据形式存在，**无法读取**」。

### 1.2 本轮的解法（**上一轮结论是错的**）

假设：`LB_SETITEMDATA` 存的是**指向游戏内存的字符串指针**。
验证：`LB_GETITEMDATA`(0x0199) → 拿到 32 位值 → `ReadProcessMemory` 读该地址。

**关键细节：必须按 UTF-16LE 解码**（上一轮用 GBK 单字节解码，读出来是乱码，
所以误判为"不是字符串"）。

```python
d = LB_GETITEMDATA(i)            # SendMessageTimeoutW(h, 0x0199, i)
raw = ReadProcessMemory(pid, d, 512)
name = raw.split(b'\x00\x00')[0].decode('utf-16-le')
```

**实测成功**，读到全部 271 个地图名：

```
[  0] '火線衝突（2）'
[  1] '世仇（2）'
[  2] '纜樁脊（2）'
...
[ 94] '[2] 0LoadBench U100'
[ 98] '[2] 0LoadBench U800'
```

### 1.3 完整的地图选择链路（已验证可跑）

```
点 GUI:ChooseMap (Button)  → 打开地图对话框（271 条目 ListBox 出现）
LB_GETITEMDATA(i) + ReadProcessMemory(UTF-16LE)  → 读出名字，定位目标索引
LB_SETCURSEL(索引)                                → 选中
点 GUI:UseMap                                     → 应用
点 GUI:StartGame                                  → 开局
```

本轮实际执行：选中 `[98] '[2] 0LoadBench U800'` → `UseMap` → `StartGame` → **成功进入对局**。

> ★ 这个能力对项目有独立价值：**任何需要指定地图的真机趟现在都能自动化了**，
> 不必再依赖人工选图（项目 `H1_REMEASURE_RUNBOOK.md:102` 原文是"**人工**选图"）。

## 2 · 未达成：负载没有产生

### 2.1 U800 图的 180 秒监测（零停滞）

```
采样 899 次，可读 899 次（100.0%）
首值=464 末值=6087 min=464 max=6087 不同值=899
Δ: min=6 max=7 非零Δ=898/898
Δ 中位=6.0 ⇒ 约 30.0 fps（0.20s 采样）
停滞事件（StallDetector 触发）= 0 次
```

**这与项目自己的既有结论一致**，且本轮是**独立实测确认**：

> `RE_COORDINATION.md:134`「U200/U800 在遭遇战只实例化 **21/22 单位**
> （= `HouseClass::RespawnStartingForces` 国家默认开局部队），**不是地图负载**」

⇒ **U800 旧图在遭遇战里根本产生不了负载**。我读到 U800 图的 `MultiplayerOnly=1`，
与这条结论吻合。

### 2.2 H1 图（真正的高负载图）没进地图列表

把三张 H1 图复制进游戏目录后，地图列表的 271 条目里**仍然只有旧图的 `[2] 0LoadBench U800`**，
**没有** `U0050_H1 / U0200_H1 / U0800_H1`。

已排除的可能：
| 检查 | 结果 |
|:--|:--|
| 文件是否真的在游戏目录 | ✅ 在（22,344 / 79,411 / 309,822 B，复制校验通过） |
| 是否因 Name 与旧图重名被去重 | ❌ 不重名：旧图 `0LoadBench_U0800`，H1 图 `[2] 0LoadBench U0800 H1 fp:1189b6b550ff` |
| `[Basic]` 段是否完整 | ✅ 完整（NewINIFormat=4、Theater=TEMPERATE、MultiplayerOnly=1、Author 均有） |
| 是否列表缓存 | 未验（可能要清缓存文件或游戏重启策略） |

**未定谳**：为什么游戏的地图扫描器跳过了这三张图。可能的方向（均未验）：
`_H1` 后缀命名不被扫描器接受；`Name` 字段含 `fp:` 指纹串导致解析异常；
或游戏只扫描 `.mpr`/特定扩展。
