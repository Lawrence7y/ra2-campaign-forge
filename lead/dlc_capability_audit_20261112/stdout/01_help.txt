usage: python -m ra2forge [-h]
                          {validate,build,install,uninstall,example,inspect}
                          ...

Generate a complete Red Alert 2 / Yuri's Revenge storyline campaign from a
design JSON.

positional arguments:
  {validate,build,install,uninstall,example,inspect}
    validate            validate a campaign design JSON
    build               compile a design into game files
    install             install an already built package
    uninstall           remove the package and restore backups
    example             write an example design JSON
    inspect             show summary of a .map file

options:
  -h, --help            show this help message and exit
