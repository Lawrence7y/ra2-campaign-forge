## 2 第二步：V1/V2 分界规则（可执行判据，实装于 `_v12_rule.py`）

### 2.0 分析单元（先切单元，再判，杜绝跨行污染）

- 命中在表格行（`行.lstrip().startswith('|')`）⇒ 单元 U = **该命中所在的那个单元格**（`|…|` 之间）；
- 否则 U = **命中所处子句**，边界 `。！？；\n`（与 R10 的 `CLAUSE_BREAK` 同族，但 R10 只用它截回看窗，本规则用它切分析单元）；
- 上下文 L = 命中所在整行，仅供表格/引证/疑问的同行判定；
- `pre` = U 内命中之前，`post` = U 内命中之后。所有判据**只用 U / pre / post**，不跨 U。

## 5 第五步：适用边界与后续建议

### 5.1 (a) 本规则判不了哪些写法（如实写「判不了」）

1. **跨行 / 跨段落的支配关系**：规定词在上一行、完成词在下一行（「须按下列格式填写：\n三个身份字段已填」）。本规则的 U 只到子句/单元格，跨行支配会落 S3 默认 V2 + 人工复核，不会静默放过，但也**判不了**其真实语义。
2. **依赖上下文的指代**：「该槽已填」——「该槽」指上一节的见证槽还是登记件字段？本规则只看 U/pre/post，不做篇章级共指消解，**判不了**，落 S3。
3. **反讽 / 转述他人断言**：「复核回件声称三值已填」——「声称」把断言降级为转述，本规则无 `声称/据称/自述` 归属词表时**判不了**（可能误拦，fail-closed 安全侧）。
4. **自由句式里省略支配词的待核条件**：「三值已填、四路哈希实算、占位残留清零」若既无编号、无「须/应/是否」、也无表格/分支标记，本规则**判不了**，落 S3 默认 V2 + 复核（不会漏，但会误拦）。
5. **跨文件的状态同步**：本规则是单文件文本谓词，不判「A 件说已填、B 件实际是否落盘」——那是 R11 引用锚 / 独立核验轮的职责，**不在本规则适用域**。
6. **新出现的硬性完成宣称词族**：`V2_OVERRIDE` 是枚举词表；未登记的等价说法（如「已由本人署讫」）判不了，落 S3 默认 V2（安全侧）。词表须随语料增补，但**增补只加 V2 词，不加 V1 放过项**，避免放宽。

以上 1–6 的共同兜底都是 **S3 默认 V2 + `review_flag=True` + 要求人工复核/改写为显式规定式**，即「判不了就拦、不编规则假装能判」。

### 5.2 (b) 与 R10/R12 的并入顺序：**V1/V2 应在 R10 之前做前置分类**

推荐执行链：

```

  → V1/V2 前置分类（新，本任务 _v12_rule.py）
  → R10（只对 V2 命中跑否定/引证豁免）
  → R12（只对 R10 判 double_neg 的 V2 命中复核）

```

理由（三条，均有实跑支撑）：

1. **R10 的输入契约被污染**：`r10_scan` 对每个禁用词字面命中都产一个 `kind`，它默认「命中即候选断言」。V1/V2 前置分类把「规定/疑问/表格/占位/分支」从候选集里摘掉，R10 只处理**剩下的真候选**，7 条误报从源头消失（`_v12_gate_compare_out.txt` §F：现 R10 `occ=6/3`，前置后应为 `occ=0/0`）。
2. **不能放在 R10 之后做修正**：R10 之后只剩 `problems/warnings/hits`，`problems` 里已经丢了「这处为什么被判 assertion」的完整单元信息（虽有 `hits` 带 pos，但 `quote_mention` 与 `assertion` 的豁免结果已合并）；且 R12 消费 `r10_context` 的 `dbl` 分类，后置修正会让 R12 跑在已被污染的 kind 上。前置分类不改 `_g7_predicates.py` 一字（本任务铁律：历史 payload 绝对只读），只在调用层过滤，指纹零漂移。
3. **最小侵入**：`_g9_gate.py:125` 现在是 `g7.r10_scan(text, forb)`；改为 `g7.r10_scan(text, [t for t in forb if ...])` 不够（过滤的是 token 不是命中），正确接法是对 `r10_scan` 的 `hits` 做逐命中 V1/V2 标注，再由外层只把 `V2` 命中的 `assertion` 计入 problems。本任务**只给设计与判据，不实施到 `_g9_gate.py`**（该件只读，且改之会使已录绑定行失效）。
