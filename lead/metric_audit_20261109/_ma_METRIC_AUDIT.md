## 1 复核口径错置（第一步，独立核对）

### 1(a) 两种口径的定义与逐层数值

**正确口径** `q_i = P(layer=PASS | E) = fn_i / 39`：分子 = 真断言类（`expect=CATCH`，39 行）里被该层放过的行数；分母 = 39。它是「真断言上放过率」，是 `P(all PASS|E)` 的各层似然因子。
**错误口径** `fp_rate = P(layer=CATCH | ¬E) = fp_i / 35`：分子 = 非断言类（`expect=PASS`，35 行）里被该层误拦的行数；分母 = 35。它是「非断言被误拦率」，方向相反、条件类相反、分母也相反。

`_ma_verify_out.txt:2-6`（从 `_gp_regression_out.json:rows` 独立实算；`KEFF_CALC.md:78-85`、`CHAIN_VS_SINGLE.md:51,57-61` 同值）：

### 1(b) 为什么 `fp_rate` 相乘会得到 0（逐层分解）

`_ma_verify_out.txt:11-12`：

```
fp_rate(r10)*fp_rate(r12)*fp_rate(n13) = 0.571428571 * 0.000000000 * 0.000000000 = 0.000000000
```

- `fp_rate(r10) = 20/35 = 0.571429`（唯一非零因子）；
- `fp_rate(r12) = 0/35 = 0` —— **R12 的 4 次 CATCH 全部落在 `expect=CATCH` 行**（本会话实算 `r12=CATCH` 四行 id：`R10-TV3 / R10-CTX-05 / R10-CTX-06 / GP-C04`，全部 `expect=CATCH`，`_ma_verify_out.txt:18` 另证 4 行全 `r10=PASS`），非断言类 0 行被误拦；
- `fp_rate(n13) = 0/35 = 0` —— N13 在 35 行 `expect=PASS` 上 0 次 CATCH；
- 任一因子为 0 ⇒ 乘积 0。**两个 0 都来自"分母 35 的那类里没出错"**，而"独立假设错率"要的是"分母 39 的那类里放过多少"，两者条件事件不同，故 0 不具备任何错率含义。

`KEFF_CALC.md:110-112`、`_kc_run_console.txt:36`、`_ke_calc_stdout.txt:64-66` 已定位同一式；本会话独立复现无误。

### 1(d) 为什么用两层乘积而不是三层连乘

**根因不是"R12 数值接近 1 所以可省"，而是 R12 不是独立证据根。** 本会话实算（`_ma_verify_out.txt:16-22`）：

- **独立证据根 = 1**（`EVIDENCE_INDEPENDENCE.md:299-301`、`KEFF_CALC.md:165-167`）。
- **R12 对"全 PASS"零增量，实测而非假定**：`n13=PASS` 共 38 行，其中 `r12=CATCH` **0 行** ⇒ `P(r12=PASS|n13=PASS)=38/38=1`（`_ma_verify_out.txt:17`；`EVIDENCE_INDEPENDENCE.md:149,294`；`CHAIN_VS_SINGLE.md:204` 后验 `3/18→3/18`，`R12 bit delta = 0.000000`）。
- **决定性集合等式**：`{r10=PASS 且 n13=PASS}` 的 18 个 id **恰好等于** `{r10=r12=n13=PASS}` 的 18 个 id（`_ma_verify_out.txt:16` 输出 `True`）。即在 R10|N13 两根已全 PASS 的行上，R12 **恒 PASS**，加第三层不改变事件；乘 `q_r12=35/39` 等于把一个"条件概率 =1"的因子当独立层乘进去。
- 上游口径依据：`KEFF_CALC.md:103`「因 R12 对『全 PASS』零增量，上游只按 R10|N13 两层算联合漏报期望」、`EVIDENCE_INDEPENDENCE.md:252` 明记 `q13·q10 = 3.75%` 是**独立假设下的期望，不是分布无关上界**、`KEFF_CALC.md:262-263` Fréchet `min q_i = 0.076923` 恰被实测 `3/39` 取等（`_ma_verify_out.txt:22` `True`）。
- **补充（不构成口径错置，但须声明）**：3.75% 也**不是**严格的"2 个独立层的联合漏报"——R10 与 N13.C 在代码级同根（`EVIDENCE_INDEPENDENCE.md:111` 明记「现有 4 层中没有任何一对能同时过 5 检」）。它是**反事实基线期望**，正确措辞见 `KEFF_CALC.md:423-424`。硬乘三层 `3.3632%` 只是"若真有 3 个独立层"的算式，其倍数 `2.2872`（本会话实算 `_ma_verify_out.txt:30`）在本轮任何文档中都未作为结论使用。

## 3 判错置的模式（第三步）

### 3(a) 本轮口径错置的类别（逐类给例）

1. **条件类 / 事件方向倒置**：把 `P(CATCH|¬E)`（fp_rate，分母 35）当 `P(PASS|E)`（q_i，分母 39）。例 #1 `indep_wrong_prob=0.0`；**唯一把结论数值推到 0/∞ 的一类**。
2. **后验 ÷ 似然乘积的类别错误**：分子 `P(E|allPASS)=3/18`（分母 18），分母 `Πq_i`（似然、39 类）。例 #2 `EVIDENCE_INDEPENDENCE.md:131/:305`、例 #4 `_ei_07_final.py:94「2.6 倍」`、被 `KEFF_CALC.md:108-109` 明令禁用的 `4.4474`。

4. **期望 ↔ 上界**：把 `Πq_i`（独立假设期望）命名为/当作分布无关上界（`min q_i`）。例 #3 `_ei_05_admission_out.json` 键名；`EVIDENCE_INDEPENDENCE.md:252,274(a)`、`KEFF_CALC.md:262-263` 已驳。
5. **三估计量张冠李戴**：概率比 `0.6064` / 后验几率比 `0.6697` / 信息增益比 `0.8042` 混标。例 #7 `_ei_07_final.py:89` 把 `0.61` 写成"按后验信息量折算"。

### 3(b) ★ 为什么这类错置容易被忽略

- **数值碰巧接近**：`3.75%`（两层）vs `3.36%`（三层）只差 0.38pp；`2.05`（似然放大）vs `2.07`（后验放大）只差 0.98%（本会话实算比值 `1.009768`）；`0.150`（后验比）与 `q_n13=0.0769` 同量级、`1.000` 与 R12 真 LR=1 **精确相等**；`2.0526` 在 `EVIDENCE_INDEPENDENCE.md:131`、`:256`、`KEFF_CALC.md:106` 反复出现却有两个不同分子（实测似然 3/39 与 Fréchet 上界 `min q_i`，本会话 `_ma_verify_out.txt:22` 证两者取等）。校对者看数值范围合理就放过。
- **方向看起来合理**：所有错置都指向"独立假设过于乐观 / 风险被放大 / 别按 3 层计"，与主结论同向；`fp_rate` 乘积给 0 甚至"更支持"三层不可信，于是没人追问分子分母。
- **同名缩写掩盖条件类**：`q_i`、`fp_rate`、`LR`、`n_eff`、`ρ̄`、`上界`、`倍数` 在不同段落指代不同条件分布；`q_i` 在 `KEFF_CALC.md:78` 明确为 `fn/39`，到了 `CHAIN_VS_SINGLE.md:199-204` 的"似然比"就成了后验比。

- **结论本身被上游复核反复确认**：`EVIDENCE_INDEPENDENCE.md:270-275` verdict `partial`、`KEFF_CALC.md:35-39` 记 `partial⇒unconfirmed`，复核重点是"数值/区间/破口"而非"这个数的分母是谁"，口径错置落在复核盲区。

### 3(c) 「怎么在报告里防止口径错置」的机制（不靠人仔细）

**必须做成可机检的门禁**，本轮已有现成基础可复用：

1. **每个比率强制结构化声明**（`COMPARABILITY_AUDIT.md:458-467`【数字声明】九项 + `SCORE_DECOMP.md:283` 18 项），加一项**本轮必补**：`分子事件 / 条件类 / 分母 N / 分母的 SHA / 是似然还是后验 / 是期望还是上界`。缺任一字段 `sys.exit(1)`——这直接拦住 #1、#2、#4、#9、#12。

### 4(a) `2.05 倍`（似然）与 `2.07 倍`（后验）不得混用 — 验证

### 4(b) `4.4474 = 16.67%/3.75%` 为什么是「类别错误」

`_ma_verify_out.txt:31-32`：

```
4.4474 (后验/2层乘积) = 4.447368421
4.4474 / 2.0526 = 2.1666666666666665 = P(E|allPASS)/P(allPASS|E) = 2.1666666666666665
```

- 分子 `3/18 = P(E|allPASS)` 是**后验**（分母 = 18 个全 PASS 行）；分母 `q10·q13` 是 `P(allPASS|E)` 型的**似然乘积**（分母 = 39 个真断言行）。两者条件方向相反、分母不同、且**没有用 Bayes 公式把 π 与 `c_i` 换底**。
- 正确换底须经 `P(E|allPASS) = πΠq_i/[πΠq_i+(1−π)Πc_i]`（`EVIDENCE_INDEPENDENCE.md:242`），得 `0.088785`（2 层）/`0.080411`（3 层）；直接用后验除似然乘积等于把 Bayes 因子 `P(E|allPASS)/P(allPASS|E) = (3/18)/(3/39) = 2.1667`（含先验 `π` 与 `Πc_i`）**偷偷乘进去**，故 4.4474 = `2.0526 × 2.1667`，不是任何"风险放大倍数"。
- `KEFF_CALC.md:108-109` 判「属类别错误，禁用」；`_kc_run_console.txt:38`、`_ke_calc_stdout.txt:68-69` 同判。本会话独立复现该乘法恒等式。
