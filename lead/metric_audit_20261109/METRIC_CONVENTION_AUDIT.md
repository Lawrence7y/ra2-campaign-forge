### 2.3 `fp_rate` 相乘为什么产物为 0（逐因子分解）

`_ke_calc.py:37` 抄入 `"indep_wrong_prob": 0.0`；`KEFF_CALC.md:110-112` 判其来源为 `fp_rate` 乘积。实跑命令 2 输出 `fp_rate product = 0 = 0.0`，即

```
fp_rate(r10) × fp_rate(r12) × fp_rate(n13) = 0.571428571 × 0.000000000 × 0.000000000 = 0.000000000
```

- `fp_rate(r10)=20/35=0.571429`：唯一非零因子；
- `fp_rate(r12)=0/35=0`：R12 的 4 次 CATCH 全在 `expect=CATCH` 行，实跑命令 2 输出 `r12=CATCH ids= ['R10-TV3', 'R10-CTX-05', 'R10-CTX-06', 'GP-C04'] all expect=CATCH? True all r10=PASS? True`；
- `fp_rate(n13)=0/35=0`：N13 在 35 行 `expect=PASS` 上 0 次 CATCH；
- 任一因子为 0 ⇒ **产物为 0**。两个 0 都来自「分母 35 的那类里没出错」，而独立假设错率要的是「分母 39 的那类里放过多少」。条件事件不同 ⇒ 这个 0 不具备任何错率含义。

**结论（本会话独立复现）**：编排方 `indep_wrong_prob=0.0` 确系把 `fp_rate=P(CATCH\|¬E)`（分母 35）当 `q_i=P(PASS\|E)`（分母 39）相乘；`KEFF_CALC.md:110-112` 的判定成立。若沿用，`KEFF_CALC.md:257` 记「宣称 100%，差 16.67 pp」，且 `0.1667/0 → ∞` 或结论消失——注意 `:257` 原文是「**若沿用**编排方 `indep_wrong_prob=0.0`（错置口径）则宣称 100%」的**条件句**，不是已发布结论（见 §4「改变方向」）。

### 2.5 为何用 q10×q13 而非三层连乘（独立证据根 = 1）

根因不是「R12 数值接近 1 所以近似省一层」，而是 **R12 不是独立证据根**：

1. 依赖图为单一根 `R10 → {R12, N13.C}`，**独立证据根 = 1**（`EVIDENCE_INDEPENDENCE.md:299-301`、`KEFF_CALC.md:160-168`、`CHAIN_VS_SINGLE.md:206` 因果图）。
2. **R12 对「全 PASS」零增量，实测而非假定**：实跑命令 2 输出 `n13=PASS n= 38 r12=CATCH among them= 0` ⇒ `P(r12=PASS\|n13=PASS)=38/38=1`（`CHAIN_VS_SINGLE.md:206` 亦记 38/38=1.000）。
3. **决定性集合等式**：实跑命令 2 输出 `all3PASS= 18 expect=CATCH= 3`、`2layerPASS= 18 set equal? True`，即 `{r10=PASS 且 n13=PASS}` 的 18 个 id **恰好等于** `{r10=r12=n13=PASS}` 的 18 个 id。在两根已全 PASS 的行上 R12 恒 PASS；乘 `q_r12=35/39` 等于把一个条件概率 =1 的因子当独立层乘进去。
4. Fréchet 兜底：实跑命令 2 输出 `Frechet min q_i= 0.07692307692307693 equals measured? True`，即 `P(all3PASS\|E)=3/39=1/13` 恰取 `min_i q_i` 的等（`EVIDENCE_INDEPENDENCE.md:252,256`、`KEFF_CALC.md:262-269`）。
5. 因此 `KEFF_CALC.md:102-103` 明写「3.75% 是两层乘积，因 R12 对全 PASS 零增量，上游只按 R10\|N13 两层算联合漏报期望」；**三层连乘 3.36% 只是「若真有 3 个独立层」的算式**（`_ma_METRIC_AUDIT.md:79`），其倍数 2.2872 在本轮任何文档中都未作为结论使用。
6. 补充：`3.75%` 是**反事实基线期望**，不是「2 个独立层的联合漏报」——R10 与 N13.C 在代码级同根（`EVIDENCE_INDEPENDENCE.md:111,131`）；也不是分布无关上界（`EVIDENCE_INDEPENDENCE.md:252` 已驳 `decorrelated` 段的「上界」措辞）。

## 4 错置模式

### 4.1 七类（逐类给例，判据均为分子分母定义）

1. **条件类 / 事件方向倒置**：把 `P(CATCH\|¬E)=fp_i/35` 当 `P(PASS\|E)=fn_i/39`。例 #1 `indep_wrong_prob=0.0`；唯一把结论数值推到 0/∞ 的一类。
2. **后验 ÷ 似然乘积的类别错误**：分子 `P(E\|allPASS)=3/18`（分母 18）、分母 `Πq_i`（似然、39 类）。例 #2 `EVIDENCE_INDEPENDENCE.md:131/:305`、#4「2.6 倍」、`KEFF_CALC.md:108-109` 明令禁用的 `4.4474`。
3. **同值异义（命名层）**：数值相等但分子分母不同。例 #5 `0.150/2.111/1.000` 被叫「似然比」（真 LR 是 `0.0769/2.3333/1.0`）；`1/q10` 与 `(3/39)/(q10·q13)` 相等只因 `3/39 == q_n13`；`n_eff` 同名两口径（#10）；`2.0526` 在 `EVIDENCE_INDEPENDENCE.md:131`（实测似然 3/39 为分子）、`:256`（Fréchet 上界 `min q_i` 为分子）、`KEFF_CALC.md:106` 反复出现却有两个不同分子。
4. **期望 ↔ 上界**：把 `Πq_i=3.75%`（独立假设期望）命名/当作分布无关上界。例 #3 `_ei_05_admission_out.json` 键名 `n_independent_2_error_bound`；真上界是 `min q_i=7.69%`。**本会话实算 `q_max²=0.805391`、`q_min²=0.005917`** ⇒ 上游件把 `q_min²` 误标成 `q_max²` 的算例必须删除（#11）。
5. **三估计量张冠李戴**：`0.606412`（概率比）/ `0.669663`（后验几率比）/ `0.804233`（信息增益比）混标。例 #4 `_ei_07_final.py:89` 把 0.61 写成「按后验信息量折算」（`EVIDENCE_INDEPENDENCE.md:274(c)` 已列）。

- **数值碰巧接近**：`3.75%` vs `3.36%` 差 0.38pp；`2.05` vs `2.07` 只差 0.98%（实跑命令 3 附算 `ratio 2.0727/2.0526 = 1.0097680097680097`）；`0.150` 与 `q_n13=0.0769` 同量级；`1.000` 与 R12 真 LR **精确相等**；`2.0526` 反复出现却有两个不同分子。

### 4.3 防错机制（不靠人仔细，全部可机检）

1. **结构化【数字声明】**：在 `COMPARABILITY_AUDIT.md:454-467` 九项与 `SCORE_DECOMP.md:253-257` 18 项基础上，补 6 个必填字段：`分子事件 / 条件类 / 分母 N / 分母数据 SHA / 似然或后验 / 期望或上界`；缺任一 `sys.exit(1)`。
2. **typed API**：`q_i` 与 `fp_rate` 用不同键名 `P_PASS_given_E` / `P_CATCH_given_notE`；相乘前 `assert all(x.kind == "P_PASS_given_E")`。`_ke_calc.py:85` 已同时算出四列，升级为类型即可，不依赖人记住哪个是 39。
3. **倍数出入口配对断言**：`assert numerator.event == denominator.event and numerator.condition == denominator.condition`——直接拦 `4.4474` 与「2.6」。
4. **同值异义登记表**：每个数带 `(value, formula_string, denominator_set)`；扫到同值不同式强制并列声明（抓 `1/q10` vs `(3/39)/(q10·q13)`、`0.150` vs `0.0769`）。
5. **上界/期望字段名分离 + 正则门禁**：写「上界」必须能追到 Fréchet 或 CI 公式；`KEFF_CALC.md:263,296` 的「不得写 Πq 为上界」做成断言。
