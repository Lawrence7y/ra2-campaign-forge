# UNCOVERED.md —— RE-N04 W12 未覆盖与不确定项

## 1. 能力性未覆盖（口径级）

1. **无干净零售 1.001 对照臂** ⇒ 全部读数是单臂基线。任何"是否比原版慢/快"的问题
   本卡无数据支撑。本镜像含 `.detour` + `ra2opt perf` 栈扩容 + 第三方 `xyr.dll`。
2. **无经校验的单位计数** ⇒ R4 载体（文件名含 U0800）是否真的在场景中生成了对应规模
   的单位/对象，本卡无判别手段；候选代理字段（A8ED50/B0CE88/87E8E0）语义未定，
   不能当负载度量。R4 的"速率未变"因此**只对本载体实例成立，不构成"负载无关"的结论**。
3. **30 ms 轮询非逐帧采样** ⇒ 逐帧 FPS、帧时间分布、P95/P99、1% low、微卡顿
   （<1 s 的停顿若未跨过 ≥1 s 停推阈值）均不可见。增量分布 ≠ 帧时间分布。
4. **加载/局内边界无已证判别器**：mode（全 5）与速率（loading 段即 ~31/s）都区分不了
   加载与局内。"稳定段"入口是时间切片（R1–R3 ~20.0 s、R4 ~35.0 s，逐趟确定性触发）。
   若真实加载完成点晚于门控时刻，则采样段前部含加载尾——本卡读数集内不可排除，
   但 10 s 窗速率全程平稳（无爬升段），且 R1–R3 与 W7 三趟逐拍重演，提示该切片
   与真实边界高度重合（未证）。
5. **Δframe==0 占比（4.6–4.9%）**：主要是 32 ms 帧周期 vs 30.5 ms 实测采样间隔的拍频
   效应；是否混有单帧停推不可分辨（见 3）。

## 2. 条件记录的不确定项

1. **难度键位语义未定**：`[Options] Difficulty=1 / CampDifficulty=0` 逐字记录，但遭遇战
   对话框内的难度选择是否由这两个键承载、`[Skirmish] Slot0x=…` 三元组的字段含义，
   均未解码。四趟哈希一致保证"同一 INI 输入"，但"同一难度"是推断不是测量。
2. **游戏速度键位语义未定**：`[Skirmish] GameSpeed=2` 与 `[Options] GameSpeed=1` 并存，
   会话实际生效哪个未证。同为逐字记录口径。
3. **显示名 ↔ 文件对应关系是推断**：地图列表给出的是内部 `Name=` 派生的显示名；
   "选中 `[8] Proving Grounds` 即加载了磁盘上哈希钉定的那个 .yrm"未做直接证明
   （无列表项→文件路径的已证通路）。载体哈希钉定 + 显示名唯一命中 + 三趟逐拍重演
   是间接证据链。
4. **R4 内部显示名含前导空格与非常规大小写**（`" [2] 0LoadBench U800"`）——模式
   匹配用小写子串，命中唯一；但显示名与文件名差异大（`U0800` vs `U800`），检索
   本卡地图时以显示名为准。
