### 0.2 本文要回答的唯一问题（先限定，防止外溢）

> **在本机、本镜像、本配置、单机、官方战役/单人局路径上，向隔离沙箱安装「v13 工具链构建的包」之后，与不装包的同一沙箱相比，局内可观测行为是否等价？**

1. **改造对象是 DLC 包安装（文件层），不是改 `gamemd.exe`**。本会话纪律明令「禁止注入/attach 写内存/改 exe」（`RUNLOG.md` §7、W44 §2）。`gamemd.exe`/`ddraw.dll` 两臂必须保持 `73201cc0…`/`85e0f7d5…` 逐字节不变 `[本次实测]`。因此这里**不是**「补丁前后函数级等价」，而是「**装包不扰动官方既有路径**」的等价。
2. **A 臂不是「官方未修改原版」**。真 `ra2youli` 早有既存 v0.3 旧包（`ra2forge_install.json=fe3bdf62…`，「钢铁残响」，含 `BATTLEMD98.INI` 与替换过的 `ECH01.MAP`，`PAUSE_STATE_20261113.md` §5 `[转引]`）；W43 `TRACK_B_gates.json` 的 `overall_verdict=UNDETERMINED` / `is_clean_retail_gold=false` `[转引]` ⇒ 干净零售金标准**未定谳**。A 臂只能写成「本机这份绝对路径字节的目录副本」，不能写成「原版对照」（任务书 L89 同约束）。
3. **等价 ≠ 全等**。装包必然引入**安装态差异**（新增文件、清单/seal、`battle_cnt` +1 等）。这些是**设计预期的自变量结果**，不是行为不等价。规格必须事先给出「预期差异白名单」，白名单外的差异才算候选不等价。

### 2.2 可选臂 C：本次不可实现，明写

题面「可选臂 C：装包但禁用某特性」在本会话**不可判/未实现**，理由 `[本次读码]`：

- W43 `UNCOVERED.md` U-W43-6：`resolve()` 仍是**纯计划函数**，未回灌 `install.package_files()`；执行层仍是 v12 的**整包事务**「全有全无」`[转引]`。

- v13 新能力（版本守卫、`resolve`、`guard-check`）全是 **opt-in**，默认构建产物与 v12 逐字节相同（W43 §1 `8/8 IDENTICAL` `[转引]`）。

### 2.4 噪声基线（强制）

- **A 臂重复两次**（A1、A2），**B 臂至少一次**（B1）；有余力则 B2。
- `A1 vs A2` 的差异 = **环境噪声带** `N`。
- `B1 vs mean(A1,A2)` 的差异 `D` 只有满足 `D > N`（且超过 §3 各量阈值）才可进入「改造导致」的归因讨论；否则写「无法判定 / 噪声内」。
- 若 A1 与 A2 本身已在某个可比量上超出 §3 阈值 ⇒ 该量**不可判**（测量链不稳），不是「不等价」。
- 每趟必须记录 `run_id`、起止 UTC/local、`pid`、桌面预检结果、`frame` 序列、读失败数、收尾还原自证。

### 2.5 预期差异白名单（**开跑前**声明，白名单外才算候选不等价）

| # | 差异 | 为什么是设计预期 | 归属态 |
|---|---|---|---|
| W1 | 沙箱文件树多出包文件（`BATTLEMD98.INI` / `*.MAP` / `expandmd98.mix`，以及构建期 opt-in 的 `MAPSELMD.INI` / `ra2md.csf`）、清单 `ra2forge_install.json` + `.seal` + `.ra2forge.bak` 槽 | 安装事务本身 | **安装态** |
| W2 | `battle_cnt` 增加「包新登记的 battle 条目数」`k`（W44 实测 `k=1`：14→15 `[转引]`）；**`k` 必须由包内容事先算出，不得事后拟合** | 引擎把新增 battle 计入 Battles 表 | **安装态可见的 RPM 读数** |

## 3 · 判据（每项：等价 / 不等价 / 不可判）

> 记号：`A1,A2` = 对照臂两次；`B1` = 改造臂；`N` = A1/A2 噪声带；`D` = B1 与 A 的差异。所有比较在「稳定局内段」内进行，且两臂均已通过 §1.7 门禁。

### 3.1 局内定时器 `[0xA8ED84]`

| 判定 | 条件 | 理由 |
|---|---|---|
| **等价** | `\|D_rate\|/rate_A ≤ **0.5%**` ∧ 两臂 `≥64 ms` 间隔数 = 0 ∧ `Δframe≥2` 数 = 0 ∧ 读失败 = 0 ∧ 有效局内段 ≥ **60 s** | 0.5% 是 RE-N04 **预设**判据（HANDOFF §4.3 `[转引]`），不是本卡自定；A 线实测重复性 0.02%、W13 长时漂移 <0.01%、W14 无 ≥64 ms / 无跳多拍 `[转引]` |
| **不等价** | `\|D_rate\|/rate_A > 0.5%`（且 `D > N`）∨ 任一臂出现 `≥64 ms` 间隔 ∨ `Δframe≥2` | 超出预设阈且有区分力 |
| **不可判** | 有效段 < 60 s ∨ 读失败 > 0 ∨ 未通过进图门禁 ∨ `N` 本身 > 0.5%（测量链不稳）∨ 出现未剔除的菜单停推段 | 样本不足/相位污染，不能硬判 |

> 注意：单拍抖动（11.6–47.9 ms）本身是**已证正常现象**，不是不等价证据；只有 `≥64 ms` 或跳多拍才算节拍饿死 `[转引]` HANDOFF §4.4。

### 3.2 局内 Esc 菜单控件集合

| 判定 | 条件 | 理由 |
|---|---|---|
| **等价** | 归一化 `multiset(text,cls,visible,ctrl_id)` **A1 == A2 == B1**，且 6/6 必需控件全在、无多余必需项、连续 ≥3 轮询稳定 | 控件集合是离散量，可严格相等（W39/W44 6/6 `[转引]`） |
| **不等价** | 任一必需控件缺失/多出，或 `visible`/`ctrl_id` 在 B 臂不同，且 A1==A2 | 离散差异无噪声空间；A1==A2 排除枚举偶然失败 |
| **不可判** | Esc 菜单没打开 / 枚举到的是主菜单或确认框（相位错）/ 控件 `text` 为空 / A1≠A2 | 相位或仪器问题，不是行为差异 |

### 3.3 只读 RPM 字段

| 字段 | 等价 | 不等价 | 不可判 |
|---|---|---|---|
| `scen_filename` | 两臂**精确字符串相等**且等于本次目标官方场景名 | 任一字符不同（含大小写/扩展名） | `scen_ptr` 无效 / 读失败 / 两臂进的不是同一场景（相位错） |
| `scen_battle_idx` | 两臂**整数严格相等** | 不等 | 读失败 / 场景不同（相位错，不算不等价） |
| `battle_cnt` | `B − A == k`（`k` = 包新登记 battle 数，**事先算出**）且 A1==A2 | `B − A ≠ k` | A1≠A2（基线不稳）/ 读失败 / `k` 无法从包清单确定 |

> `battle_cnt` 是**唯一**允许「设计预期非零差异」的可比量（白名单 W2）。若不做白名单声明而直接要求字节相等，会把正常的安装态差异误报为行为不等价——这是本规格最容易被误用的一条。

### 3.4 存档文件字节

| 判定 | 条件 | 理由 |
|---|---|---|
| **等价** | 全字节相同 ∧ `sha256` 相同 ∧ `size` 相同 ∧ 两臂存档点 `frame` 差 ≤ **1 拍** | 字节级严格判据；tick 对齐防止「不同时刻的状态」被当成差异 |
| **不等价** | 存在白名单外字节差异 ∧ A1==A2（噪声带内无差异）∧ `frame` 已对齐 | 差异可复现且非噪声 |
| **不可判** | 存档对话框未到达 / 槽位或名字不同 / `frame` 差 > 1 拍 / A1≠A2（噪声已有差异）/ 差异落在未事先声明的字段且无法定位语义 | 必须能区分「改造导致」与「环境噪声」（题面硬要求） |

> 若 B 与 A 存档不同但 A1≠A2 ⇒ **只能写「无法判定」**，不得写「改造导致」。若差异可定位到 W44 已记录的 `ECH01.sav` 被游戏运行改写之类**已知运行副作用**，须单独列为噪声并留原始 diff，不能悄悄并入等价。

### 3.5 `verify` 退出码

| 判定 | 条件 | 理由 |
|---|---|---|
| **等价（作为门禁）** | A、B 均 `exit 0`，且 `--json` 字段与各自状态相符（A：`manifest_present=false`；B：structure/digest/seal/files 全 ok、无 changed/missing 超预期） | `verify` 只证**安装态**；两臂状态不同但都必须自洽 |
| **不等价（门禁失败）** | 任一臂 `exit ≠ 0`（1/5/6/7/8/9/20/21/22/23）或 B 报 changed/missing/orphan 超白名单 | 安装态被破坏，行为对照**不得继续**（先修安装态） |
| **不可判** | `verify` 未运行 / 输出不可解析 / 用了不同工具版本 | — |

> ⚠ **`verify exit 0` 不是行为等价证据**。它和 82/82 一样只落在安装态（RE-N09 L287）。本项只作为「允许开始行为对照」的前置门禁，不计入六项行为结论的通过数。

### 3.6 控件可见性

| 判定 | 条件 | 理由 |
|---|---|---|
| **等价** | 归一化 `set((text,cls,visible,ctrl_id))` 两臂相同、≥3 轮询稳定、A1==A2 | 与 §3.2 同源，离散量可严格相等 |
| **不等价** | `visible` 布尔在 B 臂不同且 A1==A2 | 可见性差异是可观测行为差异 |
| **不可判** | 相位错 / 枚举失败 / A1≠A2 | — |

### 3.7 总判定规则

| 条件 | 总判定 |
|---|---|
| 六项全「等价」且 `verify` 门禁过、噪声基线成立、真目录 PRE/POST 零改动、锁已还 | **「在本机/本镜像/本配置/单机/官方场景/本时段内，六项可比量等价」**（须连带全部作用域限定） |
| 任一项「不等价」且 `D>N`、可复现、给出**首个分歧点** | **不等价**，并区分「改造导致」/「环境噪声」（A1/A2 已做） |
| 任一项「不可判」或噪声基线不成立或门禁失败 | **无法判定**，照实写，不得降级成「等价」 |
| 装包后新增内容路径（新战役/新地图）的表现 | **不在本卡范围**（本卡只走官方既有路径），另立卡 |

> **首个分歧点格式**（RE-N09 L281）：`{quantity, first_divergent_sample_index, t_utc, frame, A_value, B_value, preceding_identical_samples, noise_band_N}`。

## 4 · 不可判项（**明写，不勉强给阈值**）

> 这一节比硬凑阈值更有价值：把「本会话授权内测不了的东西」列清楚，才能防止「六项全绿」被外推成「改造前后游戏行为等价」。

### 4.1 渲染侧 —— **不可判**（本会话禁止注入）

| 项 | 现状 | 依据 |
|---|---|---|
| GPU 时间 / `Present` / vsync 阻塞 / 掉帧 / 渲染帧时间 | **不可判** | A-line FINAL §5/§8.4：渲染帧计数静态定位失败（ddraw 0 处 `inc [abs]`；gamemd 仅 1 处且与 ddraw 无关；ddraw 走 COM vtable）；CPU 时间结构性不含阻塞等待 ⇒ 需**注入 / present 打点 / 调试器**，本会话明令禁止 `[转引]` |
| 「画面不卡」 | **不可判** | HANDOFF §4.4 明确 6 ms 高频卡「只能支持逻辑节拍没被饿死，不能支持画面不卡」`[转引]` |
| 文字/图像**逐帧渲染等价** | **不可判** | 截图只是单帧采样；控件文本 ≠ 渲染文本；无渲染通道则无逐帧对照 |

⇒ **即使 §3 六项全部等价，也不得写「渲染等价」「画面一致」**。截图在本卡只用于「进图门禁 / 人工读图判非加载屏非错误框」，不作为渲染等价证据。

### 4.2 函数级 / 模拟确定性对拍 —— **不可判**

RE-N09 L280–L281 要求的「真实原函数与候选函数同输入输出对拍」「按 tick 比较对象状态 / RNG 调用序列 / 事件顺序 / 目标选择」在本会话**无手段**：只读 RPM 只能取到 §1.3 几个字段，拿不到对象表、RNG 序列、事件队列；注入/调试器被禁。W36 §3.2.3 已把这两行标为「❌ 离线 / ✅ 必须真机」且需要额外手段 `[转引]`。⇒ 本卡**不承诺**这一层等价。

### 4.3 「原版对照 / 干净零售金标准」 —— **不可判**

W43 `TRACK_B_gates.json`：`overall_verdict=UNDETERMINED`、`retail_oracle_eligible=false`、`is_clean_retail_gold=false`；本机存在多个 `gamemd.exe` 物理副本、`73201cc0…` 留痕态与 `db264305…` 原始态并存、`RA2MD.INI` 是可写配置 `[转引]`。⇒ A 臂只能描述为「本机这份绝对路径字节的副本」，**不能**写成「官方未修改原版」（任务书 L89）。

### 4.4 联机 / 跨进程存读档 / 全战役链 —— **不在范围**

RE-N09 L282 的联机同步、跨会话存读档、`NextScenario → EndOfGame` 全链，本卡不测；单机范围必须明写（W44 已单独验过 v12 存读档 `[转引]`，但那是 C 线另一张卡、另一个包，不能挪作本卡证据）。

### 4.5 `mode[0xA8B238]` / `frame` 语义 —— **不可用 / 禁止**

- `mode` 只区分 intro/主菜单(0) 与其余(5)，**不能**区分加载/局内 ⇒ 不得作进图判据（HANDOFF §2 自纠 `[转引]`）。
- `frame` 是 32 ms 定拍计时器，**不是 FPS**，不得叫帧率（A-line FINAL §8.5 `[转引]`）。
- `scen_stage_idx` / `scen_battle_idx` 的偏移语义无符号级证明 ⇒ 只比较读数，不解释引擎内部含义 `[静态推断]`。

### 4.6 臂 C（安装期禁用某特性）—— **不可判 / 未实现**

见 §2.2：v13 执行层仍是整包事务，`resolve()` 未接线。强行「少装一个文件」得到的是**另一个 `package_digest` 的包**，不是「同一包禁用特性」。

### 4.7 外推边界 —— **不可判**

其它分辨率 / 其它汉化版本 / 其它渲染后端 / 更重战斗 / 大兵团 / 多包并存 / 多 AI 高难度 / 长时间（>10 min）漂移，均未测。任何「本项目交付线 B 行为等价」的全局结论都越界；正确写法是「在本镜像/本机/单臂零输入/本时段/官方场景路径下，六项可比量等价（或无法判定）」。
