## §2 V2 离散字段判据（事先声明）

### §2.1 候选方案（至少两种，本节全部给出）

**候选 (i) — 取值集合相等（严格）**
对每字段 `f`：`set(vals_A(f)) == set(vals_B(f))` 即通过；不相等 ⇒ `SHIFT_DETECTED`。
- 优点：完全与行数无关；实现简单；对**偶发值**极敏感（哪怕只出现 1 行的新值也会立刻抓到）。
- 缺点：硬判等、无噪声容忍，与连续量已采用的「噪声带 + 置换检验」口径**不一致**；对采样时长**间接**敏感（采得越久越可能撞到一个罕见值）；**无法给出检验量与 p 值**，无法满足本卡诊断重算"每字段占比差异、检验量、p 值、判定"的输出要求；一帧抖动即可整体翻转判定。

**候选 (ii) — 每字段各取值占比 + 与连续量同框架的检验（选定）**
把离散字段视作**分类分布**，用**经验占比**归一化，再用噪声带 + 置换检验判断是否超出噪声。详见 §2.2–§2.4。
- 优点：占比与行数无关（`n` 不等时无需任何截断/补齐）；与连续量（`dframe` 的 `N_ks`/`D_ks`/置换 `p`）**同一统计哲学**，不引入第二套判定标准；能输出占比差、检验量、p 值，可审计可复算；对采样量稳健。
- 缺点：见 §6（对稀有偶发值不敏感、常量字段上检验退化、多重比较、非平稳时序）。

### §2.2 择一决定与理由

**选定候选 (ii)**，理由（按权重）：
1. **与连续量同框架**：FROZEN 的 B-3 已经是「噪声带 `N_ks` + KS 距离 `D_ks` + 置换 `p` + `alpha`」。离散字段改用同一套（占比版），不引入第二套判定哲学，规则表可继续使用同一批常量。
2. **天然与行数无关**：占比按各自 `n` 归一化，A/B 行数不等时**直接比较分布**，从根上满足"禁止截断凑数"，无需任何预处理。
3. **可审计**：输出占比差异、检验量、`p` 值、逐字段判定，正是本卡诊断重算要求交付的读数；候选 (i) 只有一个布尔量，给不出检验量与 p 值。
4. **候选 (i) 的"严格"在本场景是伪严格**：它把"是否采到过某个值"当成行为等价，恰好是另一种形式的采样敏感；而本项目 W55b 的教训（`[转引 REVIEW\LEAD_VERIFY_W55B.md §2.1]`）就是"不可复现的噪声带不能拿来做判定"。占比检验把偶发值交给噪声带/`alpha` 裁决，而不是一票否决。

`[静态推断]` 这是一次**权衡**，不是"候选 (i) 错误"；(i) 的偶发值敏感度是真实优点，登记在 §6 与 `UNKNOWNS.md`，若 Lead 后续要求"零容忍任何新值"，应**另开卡**声明新判据，不得在本卡事后追加。

### §2.3 可比量定义（V2，替换 FROZEN §2.1 第 106 行）

对离散字段 `f ∈ {map_name, stage_idx, end_of_game, skip_map_select, battle_idx}`：

- 每臂按**行数**归一化：`p_S(f) = { v : count_S(v) / n_S }`，`n_S = len(rows_S)`（**行数**，非 `dframe` 长度；离散字段每行一个取值）。
- 值域取并集 `U_f = keys(p_A(f)) ∪ keys(p_B(f))`，缺失键占比记 `0.0`（不使用 `Counter` 判等）。
- **检验量（与顺序无关）**：`T_f = TVD(p_A, p_B) = 0.5 * Σ_{v∈U_f} |p_A(v) − p_B(v)|`，取值 `[0,1]`。
  - `[静态推断]` **为何不用 KS**：两样本 KS 定义在有序数值的 ECDF 上；离散类别（`map_name` 字符串、`stage_idx` 编号）无天然全序，强行编码会引入任意排序并伪造 `D`。故用总变差距离 TVD（分类分布上无需顺序、有界、对称），并用**置换检验**给出 `p` 值——这正是任务允许的第二条路径「与连续量相同的…置换检验」。
- **同臂噪声带**：`N_disc(f) = max( TVD(p_{A1}(f), p_{A2}(f)), TVD(p_{B1}(f), p_{B2}(f)) )`，其中 `A1/A2`、`B1/B2` 为同臂两条独立噪声轨迹（若某臂未提供噪声轨迹，该臂分量记 `0.0`）。
- **置换 p 值**：`pool = [f 的按行取值 ; A 全部] ++ [f 的按行取值 ; B 全部]`，长度 `n_A + n_B`；固定 `seed`，重分 `perm_iters` 次，每次按**真实** `(n_A, n_B)` 切分（**不补齐、不截断、不重采样到相等**），重算 `T_perm`；`p_f = ( count(T_perm ≥ T_f − ε) + 1 ) / (perm_iters + 1)`，`ε = 1e-12`。与 FROZEN `permutation_pvalue` 同构（`:130-145`）。
- **逐字段判定**：
  - `D_disc(f) := T_f`
  - 若 `N_disc(f) > N_max` ⇒ 该字段噪声带不稳定 ⇒ 整体 `UNDETERMINABLE(noise_band_unstable)`
  - 若 `D_disc(f) <= max(N_disc(f), D_floor)` **且** `p_f >= alpha` ⇒ `no_shift_detected`
  - 否则 ⇒ `shift_detected`
  - `[静态推断]` `D_floor` 在此**复用**为 TVD 的分辨率下限（与 FROZEN B-3 的 `max(N_ks, D_floor)` 同构）；这是复用既有常量、**不是新增阈值**，其解释性扩展登记在 `UNKNOWNS.md` / `DISAGREE.md`。

### §2.4 判定规则表（V2，事先声明；顺序短路不变）

| 序 | 条件 | 输出 |
|---|---|---|
| B-0 | `n_A < n_min` 或 `n_B < n_min`，或同臂重复数 < `n_noise_min`，或字段缺失/无法解析 | `UNDETERMINABLE(reason=insufficient_sample)` |
| B-1 | `N_ks > N_max` **或** `∃f: N_disc(f) > N_max` | `UNDETERMINABLE(reason=noise_band_unstable)` |
| B-2 | `∃f: shift_detected(f)` **或** `J < theta_ui` | `SHIFT_DETECTED(reason=discrete_or_ui_mismatch)` |
| B-3 | `D_ks <= max(N_ks, D_floor)` **且** `p >= alpha` | `SAME_DISTRIBUTION(reason=within_noise_band)` |
| B-4 | `D_ks > N_ks * k_ratio` **且** `p < alpha` | `SHIFT_DETECTED(reason=ks_beyond_noise)` |
| B-5 | 其余 | `UNDETERMINABLE(reason=grey_zone)` |

> 与 FROZEN §2.4 的差异**仅**：B-1 增加对离散噪声带的同款 `N_max` 检查（复用 `N_max`，不新增阈值）；B-2 把「多重集不等」换成 §2.3 的逐字段检验结论。B-0/B-3/B-4/B-5 与输出词表逐字不变。
> `SAME_DISTRIBUTION` 的准确含义仍是「**在本判据、本观测量、本样本量下未检出分布差异**」，**不是**"行为等价已成立"，**更不是**"B 线等价性已成立"。

### §2.5 `n` 不等时的处置（**禁止截断凑数**）—— 事先声明

1. 占比按**各自真实行数** `n_A` / `n_B` 归一化；`n_A ≠ n_B` **不是**异常，属预期（固定墙钟时长采集的必然结果）。
2. **严禁**：把较长臂截断到较短臂长度、把较短臂补齐/重采样到较长臂长度、丢弃任一臂的任何一行、用 `min(n_a,n_b)` 去做离散字段判等。
3. 置换检验按**真实** `(n_A, n_B)` 重分，保持边际样本量不等；`p_f` 在此非对称切分下计算。
4. `n_min` 检查仍按各自 `dframe` 样本点数独立进行（FROZEN B-0 语义不变），**不**因为"要凑相等行数"而放宽。
5. `[静态推断]` 遗留：`jaccard_mean` 仍沿用 FROZEN 的 `min(len_a,len_b)` 逐行截断语义（§6）。本卡**不擅自扩大改动范围**去改 UI 判据；登记为遗留弱点，建议后续卡单独处理。W65 四趟 `ui_controls` 全为 `[0]`、`J=1.0`，该截断不影响本次诊断读数。

## §6 新判据的已知弱点（事先声明，详见 `UNKNOWNS.md` / `DISAGREE.md`）

1. **对稀有偶发值不敏感**：占比 `1/n` 级的新值只带来 `T_f ≈ 1/(2n)`（W65 量级 `≈2.5e-5`），远小于 `D_floor=0.05`，会被判 `no_shift_detected`；候选 (i) 会立刻抓到。这是选 (ii) 的真实代价。
2. **常量字段上检验退化**：若某字段在两臂都是同一个值（W65 四趟正是如此），`T_f ≡ 0`、`p_f ≡ 1`、判定恒为 `no_shift_detected`。此时该读数**几乎无信息量**，只说明"值集与占比相同"，**不能**据此推断行为等价。
3. **多重比较**：5 个字段各自做置换检验，未做多重比较校正；`alpha` 未改动、也未新增 Bonferroni 规则（那是改阈值/加规则，超出本卡范围）。族系错误率高于单次检验，登记为弱点。
4. **非平稳/时序信息被抹掉**：占比、KS、分位数都只比较边缘分布，不比较取值顺序；若行为存在时间趋势（如中途切图），占比可能不变。这是 FROZEN 连续量已有的局限，V2 未改变它。
5. **`ui_controls` 截断语义遗留**：`jaccard_mean` 的 `min(n_a,n_b)` 逐行截断未改动（§2.5.5），是另一处对采样时长敏感的点，需后续卡处理。
6. **同臂噪声带依赖**：`N_disc(f)` 需要 A1/A2、B1/B2 四条独立轨迹；若采集层只给合并臂，`N_disc` 退化为 `0.0`，判定更依赖 `D_floor` 与 `p_f`。本卡 W65 四趟齐备。
7. **诊断重算不可反推结论**：见 §4；本卡不写"B 线等价性成立"，不写"装包无影响"。
