# W19 / RE-N04h 未覆盖与测不到清单（LoadBench U800）

run_id = NEXT_RE_20261112_R02 · 卡 = RE-N04h · 日期 = 2026-11-13

## §0 能测 / 测不到（卡面要求）

### 本卡能测
1. U800 臂（480 车 + 320 步兵声明）在局内静止状态下的**窗口线程每拍 CPU 分布**（cycle 主判读 + FILETIME 交叉核对）。
2. 窗口线程 CPU 占用率（单核 %，ΔCPU/有效墙钟）与进程级全线程求和趋势。
3. 与 A 臂（W15，52 建筑）、HexBay 臂（W18，144 建筑）的**单变量（只换地图）对照**。
4. 拍间隔分布 / 饿死计数（≥64 ms）/ 10 s 窗趋势。
5. `0xA8ED50` / `0xB0CE88` / `0x87E8E0` 取值变化（旁证描述）。

### 本卡测不到（结构性边界，非本趟失败）
1. **阻塞类等待**：Sleep / Present / vsync / 等消息全部不计入 CPU 时间——「一拍 CPU 低」≠「这一拍快」；「一拍 CPU 高」才是可靠的重活信号。U800 若单位多导致*等待*增多而 CPU 不变，本仪器读不出。
2. **GPU 侧耗时 / 画面掉帧**：需注入或 GPU 计时，均被禁止。
3. **单位运行实例数**：无已解码的「运行单位 Count」地址。声明 480 车 + 320 步兵 ≠ 运行实例数（LoadBench 系列教训：声明量可能不被实例化）；`0xA8ED50` 是候选 Bullet Count，语义未证，**不得**当单位数——本卡只能给出"是否非零"这一旁证。
4. **逻辑线程 vs 渲染/消息泵的拆分**：窗口线程 CPU 含渲染+消息泵+逻辑；进程级求和含全部线程。无法定位"多出来的 CPU 花在逻辑还是渲染"。
5. **归属窗口量化**：递增事件只能以 6 ms 采样粒度观测 ⇒ 每拍归属 = 1 拍 ± ~6 ms 量化。
6. **单趟性**：单趟 240 s，无重复趟；趋势/分布不做多次重复实验的统计推断。

## 本趟观察边界与不确定项
- 采样段为**开局静止+AI 自动交战**状态：无玩家输入。若 800 单位彼此未发生交战，Bullet 类活动少，`0xA8ED50` 可能仍为 0——「仍为 0」只说明无 bullet 旁证，不说明单位未实例化。
- FILETIME 通道 15.625 ms 记账量子：逐拍值多为 0/15.625/31.25 台阶，均值可用，逐拍分布不可信。
- `0x87E8E0`（可回绕 dword）只记录取值范围与变化，不做语义推断。
- 观察者 NtQuerySystemInformation tid 校验失败时 ctx 列为 null（如发生，如实计数于 ui_watch.ndjson `nt_note`）。
- 地图列表 268 条中 `[2] 0LoadBench U800` 精确唯一命中（索引 96），无撞名取舍问题；`[2] 0LoadBench U100`（索引 93）为相邻条目不干扰。
- cyc_per_ms 自标定依赖「全段 ΣcycΔ / ΣFILETIME Δ」长窗抵消量子；若 FILETIME 通道出现系统性丢拍，标定系数会有偏——与 W18 的 3,311,138 并列时读者可自行核对比例合理性（≈3.1–3.4 GHz 均为合理时钟频率区间）。

## 「没观测到」≠「不存在」
- 若 `0xA8ED50` 全程 0：只能得出"无 bullet 实例化旁证"，**不能**得出"480 车+320 步兵未实例化"。
- 若 CPU 中位与 A 臂无显著差异：只能得出"该维度在本仪器通道上无压力差"，不能排除单位数影响存在于等待时间/GPU/未采样路径。
