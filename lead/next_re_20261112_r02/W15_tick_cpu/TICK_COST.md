## §0 本卡能测 / 测不到（卡面固定口径）

**能测**：每拍的 **CPU 消耗**；哪些拍显著更贵（热点候选）；CPU 成本随对局推进的趋势。

**也测不到**：GPU 侧耗时、画面掉帧（需注入，本卡禁止）。`[0xA8ED84]` 单位是计数/s，非 FPS。

## §1 归属方式与误差（预declared）

- **归属规则**：只在 `frame` 递增的采样上结算；每拍成本 = 相邻两次递增采样之间
  `Δ(win_kernel_ms + win_user_ms)`（窗口线程 44788 的 `GetThreadTimes` 累计差）。
- **窗口**：1 拍 ± 采样量化（±~6 ms 观测延迟）+ 记账量子 ±15.625 ms（§0.2）。
- **内容**：窗口线程 = 逻辑 + 渲染提交 + 消息泵，**非纯逻辑 CPU**；无法把线程内时间切分到子系统（禁注入）。
- **df≥2**：全额记单行不摊分（本次仅 1 个：首个事件 frame 0→2，边界含加载尾，cpu=0.000，已排除于主表）。
- **fail 规则**：读失败/窗口线程查询失败的拍保留不填补；跨其上的递增不计算（本次 0 个）。
- 独立验证通道：`QueryThreadCycleTime`（周期计数，上下文切换粒度）——与主通道同窗口差分，粒度细于记账量子（§4.2）。
