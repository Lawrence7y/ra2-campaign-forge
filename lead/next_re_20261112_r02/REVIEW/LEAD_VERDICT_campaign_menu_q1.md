## 2. 可见徽章「结构上不可能」的依据（W32 报告，`[本次实测]`+`[本次读码]`）

- `GUI:CampaignMenu` 的 ASCII 字面量在镜像中 **0 命中**；UTF-16LE 命中在 `.rsrc`（FOFF `0x487410` → VA `0xB83410`）
- 该菜单是**一张固定 Win32 对话框模板**：`RT_DIALOG id=148`，`dlgVer=1`、`signature=0xFFFF`（DIALOGEX）、`cDlgItems=13`、rect (0,0,533,369)、字体 "MS Sans Serif" 8
- 13 个控件里**只有 2 个徽章 Static**：`1770` 与 `1772`（另有 `1109` ListBox、`1038` Load 按钮、`1295` Slider3、`1822` Difficulty、`1648` Harder …）
- WndProc `0x52EC00` 的徽章分派只有 **3 个硬编码立即数** `0x6EA` / `0x6EC` / `0x6EB`，分别绑死 `.data` 里的 `"all1"` / `"sov1"` / `"tut1"`（**但 `tut1`/`0x6EB` 是残留分支：模板无控件、`BATTLEMD.INI` 无条目 ⇒ 实际可借用只有 `all1`/`sov1` 两个，见开头更正框**）
- Battle 表名字查找 `0x46CC90` **全镜像仅 1 个调用点**（`0x52F260`，徽章点击处）
- ⇒ **不存在任何「按 Battle 表遍历生成徽章」的循环**

`[签发]` 这条结论强度高：它同时给出「模板固定」「分派只有 3 个立即数」「查表函数只有 1 个调用点」三重否证，不是单一证据外推。

## 4. 隐藏 ListBox 的可达性 — Lead 实测后**下调为「实测也不可达」**

### 4.1 W32 报告的事实（`[本次实测]`+`[静态推断]`）

- 该 ListBox 是引擎自带的 **debug/testing 战役选择器**：官方 `BATTLEMD.INI` 注释 "temporary campaigns to assist us in debugging"、`DebugOnly` 键、字面量 `" - for debug/testing"`（VA `0x81B18C`）、`STT:CampaignList`（VA `0x835630`）
- 填充循环 `0x52F018..0x52F048` **无过滤**遍历 `0..[0xA83D08]-1`，取 `[0xA83CFC][i]+0x2A0`（Description）用 `SendMessageA(0x4CD)` 逐条加入，末尾 `LB_SETCURSEL`
- **无任何过滤条件**：无 id 形式 / `CD` / `FinalMovie` / `Scenario` 可寻 / 数值区间 / `DebugOnly` / CSF 有效性过滤；`DebugOnly` 只给 Description 追加调试后缀
- 唯一硬门槛：`0x52F00B A0 AD F7 A8 00`（`mov al,[0xA8F7AD]`）+ `0x52F012 je 0x52F05C`；为 0 时 `ShowWindow(SW_HIDE)` + 隐藏禁用 `GUI:Load(1038)` + 整个循环跳过

### 4.2 Lead 独立实测（把「有条件」进一步收紧）

```
0xA8F7AD 的 LE 字节在全镜像出现次数 = 1
  唯一位置：FOFF 0x12F00C（VA 0x0052F00C），上下文 00 FF D3 8B E8 | A0 AD F7 A8 00 | 84 C0
  ⇒ 即 0x0052F00B 处 mov al,[0xA8F7AD]，**就是那条读**

绝对写形式扫描（均要求操作数恰为 0xA8F7AD）：
  mov byte  [abs],imm8   0 命中
  mov dword [abs],imm32  0 命中
  mov       [abs],al     0 命中
  mov       [abs],eax    0 命中
  mov       [abs],al(2)  0 命中
  mov       [abs],eax(2) 0 命中
```

`[本次实测]` ⇒ **该门控没有任何静态写入者**，`.data` BSS 装载初值为 0 ⇒ **零售态恒为 0**。
`[结论·签发]` 因此隐藏调试列表**不是「条件可达」而是「实测不可达」**：靠 INI / 配置文件 / 散装文件**开不了它**，只能改 exe 或运行时写内存（两者都在本会话纪律红线内，尤其注入被明令禁止）。

我此前在 §1 表格与 §4 旧稿里写「有条件可达」，**据此下调**。
