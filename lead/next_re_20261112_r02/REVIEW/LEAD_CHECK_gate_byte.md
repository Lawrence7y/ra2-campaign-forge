# LEAD_CHECK_gate_byte · 门控字节 `0xA8F7AD` 出现次数（Lead 第一手）

## 1 · 实测

目标：`ra2bench\gamemd.exe`，4,825,360 B。

| 编码形态 | LE32 命中 | 位置 |
|---|---:|---|
| 绝对 VA `0xA8F7AD` | **1** | 文件偏移 `0x12F00C` |
| RVA `0x68F7AD` | 0 | — |
| .data 页内相对 `0x27D7AD` | 0 | — |
| 绝对 VA `0xA8F7AC`（相邻字节） | **1** | 文件偏移 `0x2BE030` |
| RVA `0x68F7AC` | 0 | — |
| .data 页内相对 `0x27D7AC` | 0 | — |

**形态验证**：`A0 <abs32>`（`mov al, byte ptr [abs]`，x86 的 `A0` 是 moffs8 形式）——
- `A0` + `AD F7 A8 00` 命中 **1** 处 ⇒ 文件偏移 `0x12F00C` 的 `AD F7 A8 00` 正是该 `A0` 的操作数，即 **VA `0x52F00B` 处的读指令**（`0x12F00B + 0x400000 = 0x52F00B`）。
- `A0` + `AC F7 A8 00` 命中 **1** 处 ⇒ 对应 **VA `0x6BE02F`** 的读指令（`0x2BE02F + 0x400000`）。

## 2 · 结论

`[本次实测·签发]` **`0xA8F7AD` 在本镜像里只以"绝对 VA 操作数"形式出现 1 次，且那一次就是唯一的读指令 `0x52F00B`。** RVA 形式与页内相对形式**均为 0**。

⇒ 支撑 `LEAD_VERDICT_campaign_menu_q1.md` 的判断：「隐藏调试战役列表」在零售态**恒为 0**，且**连"改配置打开"都不是可行路径**（没有可写的配置落点经由静态代码）。

**限定（不得外推）**：
1. 这只覆盖**文件内静态字节**。**不覆盖**：基址相对写 `mov [reg+disp], imm8`（需指令边界解码 —— 正是 W57 在做的事）、间接跳转表、外部 DLL（`ddraw.dll`）写入、运行期 `WriteProcessMemory`。
2. "无静态写入者" ≠ "运行期绝不可能被写"。严格说法是：**本镜像内没有静态代码写入该字节**。
3. W56 报的「740 个 .text 候选」是**页窗口匹配**（`0xA8F0xx`–`0xA8F9xx` 一带的宽匹配），不是精确匹配；精确匹配在本卡口径下是 1。两者不矛盾，但**引用时必须分开说**，否则会显得"扫了 740 处"与"只有 1 处"自相矛盾。

## 3 · 补充：门控页邻域与"写宽度"独立核查（23:10，W57b 交付后复查）

`[本次实测]` 我把扫描从"精确等于 `0xA8F7AD`"扩到**邻域** `[0xA8F7A0, 0xA8F7B4]`（任何 1/2/4 字节写只要起点在 A6..AD 就会覆盖 AD）：
- 邻域 LE32 命中 **36** 处，其中**覆盖 AD 的只有 2 处**：`0xA8F7AC`@`0x6BE030`（`A0` 读的操作数）与 `0xA8F7AD`@`0x52F00C`（`A0` 读的操作数）——**都是读**。
- 其余 34 处是 `0xA8F7A0` / `0xA8F7A4` / `0xA8F7A8` / `0xA8F7B0` 四个地址。
- **写宽度核查**（排除 8/16 字节宽写从 A0/A4/A8 起覆盖到 AD 的可能）：对菜单初始化区 `0x52DDF0–0x52E500` 线性反汇编，所有引用该页的指令为：
  ```
  0x0052DF53 mov dword ptr [0xA8F7A0], ebx     0x0052DF59 mov dword ptr [0xA8F7A4], ebx
  0x0052DF5F mov dword ptr [0xA8F7A8], ebx     0x0052E047 mov dword ptr [0xA8F7A0], eax
  0x0052E04C mov dword ptr [0xA8F7A4], edx     （读侧同理，dword 载入 A0/A4）
  ```
  ⇒ **全部是 dword 写，最大覆盖到 `0xA8F7AB`，没有一条触及 `0xA8F7AD`**；该区无 SSE/16 字节存。
- ⇒ 与 W57b 的「受覆盖矩阵约束的②不存在」**独立一致**。我另加一条它未点明的残余面：**基址相对写**（`[reg+disp]` 且 reg 运行期取到该页）已由 W57b 第二层扫过（116,625 个 `[reg+disp]` 写操作数，37 条 disp 落在门控页，0 条覆盖 AD），这一层我**未独立复算**，按转引处理。
