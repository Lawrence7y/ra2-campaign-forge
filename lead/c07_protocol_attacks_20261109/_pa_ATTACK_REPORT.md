- **P1（严重）通过档硬条件是 OR 且「先于补登」无判定法** → 单 actor 伪造一件外部记载即解锁 REGISTERED（A6 实跑）。**加固**：①「先于」钉死为双判据——git log 在先性（`git log --follow -- <载体>` 无历史=不为先）＋ mtime vs 自载日期一致性；②外部记载只认**机器运行态记载**（如 .mimosa hook-status/finding-ledger 这类含 recordedAt+sessionId 字段的载体，本仓已大量存在），散文记载不计入硬条件；③把分布基线 operationalize：D1 增量化门槛（如「≥2 个非攻样本写域且命中数≥N」——实跑基线：已登真 ID 49 处/6 写域 vs 合成 3 处/1 写域）。
- **P2（严重）§D 见证槽代填无判定法、且无见证标识独立检索行**（A5）。**加固**：见证必须由编排方**在其自身写域**落一件独立见证件（含编排方会话标识+任务 ID↔run 标识对应+时点），来源会话件内 §D 永远留空；核验者按 D 组检索该见证件本体并交叉核对——把残缺点2 修入清单。
- **P3（严重）F 组证明机制真、不证明转录真**（A4 实跑坐实协议自认）。**加固**：B1.2 的「逐字输出」改为核验者可重算的确定性绑定（如：B1.1 命令实跑时同时把输出 SHA256 写入登记件 unresolved 备注面之外的可绑定槽——承认这仍非终证）；至少要求 B1.2 声明与 F1 重放输出做**逐字段结构比对**并如实登记残余；通过档对「仅机制证据」的件降为 PARTIAL。
- **P4（中等）N10 对照集基数=1**，而 lead/ 树有 112 个形制真未登 ID（侦察实跑）。**加固**：对照集动态装载全仓 hook-status/机器记载里的 sessionId 全集（fail-closed 保留），基数 1→100+；本次 A1 样本即会被拦。
- **P5（中等）E 组两枚锚纯自报**（会话启动、补登 timestamp）。**加固**：补登 timestamp 锚定 = 门禁实跑绑定行输出（门禁已打印被核对象指纹，可要求核验者留存）；会话启动「不可得」一律入存疑（消除清单 :51/:76 自相矛盾）。
- **P6（中等）D1 只查自报一致、不查载体类型与可信度**（A6 实跑）。**加固**：D1 增「逐命中打开载体分类：机器运行态记载 / 散文 / 攻样本树」，攻样本树命中不计入自然痕迹。
- **P7（根本性、不可加固）**：本生态无密码学身份；「真实外来 ID + 伪造外部记载 + 真读环境机制」的组合在任何离线文书协议面前都能走到「无已知伪造痕迹」。协议 §6-2 自认（`_tp_C07_TRUTH_PROTOCOL.md:173/:175`、`C07_TRUTH_SELF_PROOF.md:250-252`）：D1-D7 全部命中只证明「无已知伪造痕迹」，不证明「值为真」。**协议的效力上限 = 把伪造成本抬到「至少伪造一件机器记载形态的外部记载 + 长期暴露于可撤回性巡检」，并把通过档的授予从「文书一致」改为「机器记载 + 编排方独立落盘见证」双硬条件；不可能消除伪造可能性本身。**（若编排方见证仍只是文本，P2 加固也只抬成本——终极上限由生态是否给会话身份以密码学/平台级记账决定。）
