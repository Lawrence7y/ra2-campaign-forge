## 2 语料与口径

**语料（15 合格窗）**：5 趟（`l1c_20261021` / `l1d_20261021` / `l1e_20261021` / `l3_20261021` / `t55k_20261020`）× 3 窗（w0-w2），件路径 `out/re_work/work_chain/CONTINUE_20261003/lead/qc161_u0400_trip/<trip>/measure_w{w}.json`（`_r3_recompute_gapdiff.py:11,66`）。体检（`_r3_recompute_out.txt` [A]）：每窗 hz=500、span_s=25.0、n_samp≈12501、`gate.ok=True`×15、帧号 f 与采样 t 序列单调、无样本帧=0、f 越界=0。**15 份语料件的 SHA256/bytes 撰写员逐一实算（hashlib），与 [A] 节登记值 15/15 一致**（`_s604_fp_check.py` [3] 节输出；如 l1c/w0 = `9464cac4…556f` 257797 B、t55k/w2 = `3cb93314…b684` 272095 B）。

**口径**（`_r3_recompute_gapdiff.py:3-7`，对应台账 :9702-9703 原文「每窗按帧时长排序，取最快 1/3 与最慢 1/3，各自算帧内最大空档的中位」）：
1. **帧分组**：`samples.f` 相同 = 同帧。
2. **空档**：帧内最大空档 = 帧内采样 t 升序后相邻差的最大值 ×1000（ms）。
3. **帧时长**：主口径 **edge** = 相邻帧起点差 t[i+1]−t[i]（末帧剔除）；敏感口径 **span** = 帧内 max(t)−min(t)。
4. **三分**：按帧时长升序，k = n//3（主）/ ceil（敏感）；前 k = **快1/3**，后 k = **慢1/3**。
5. **中位** = statistics.median（偶数取中间两值均值）；**空档差 = 慢1/3 空档中位 − 快1/3 空档中位**。

**edge 口径的选择依据**：四组敏感口径中仅 edge 使时长两列与台账表 30/30 吻合；双锚点独立命中——`l1c_20261021/w0` 全帧 med_edge = 103.25 ms → 台账 :9613「103.2」（撰写员实读命中）、med_span = 100.83 ms → 台账 :9535「100.8」（实读命中）。

**比对容差**：时长 <0.05 ms（表显 1 位）、空档 <0.005 ms（表显 2 位）、空档差 <0.0005 ms（表显 3 位）；另做 round-to-显示位判等（[B2]）。
