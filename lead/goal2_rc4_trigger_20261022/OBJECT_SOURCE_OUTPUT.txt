=== 结论 ===
  MATCH（reg 基址 = 雷达本体 0x87F7E8）= 0 处：无
  ⇒ 若 MATCH 为 0，说明**没有**任何一处 static 上直接把雷达本体当 reg。
    这与 §349 相符：One_Time 是 slot5，不是 slot42；
    它调 v[42] 是**在它自己内部**用 `mov ecx,esi` 的 this 透传（§346 已证），
    所以那 29 处 +0xA8 站点与 One_Time 无关。

  GLOBAL-ONLY 里的 [0xA8B23C] 两处（0x68589C / 0x685FE6）:
    形态是「取当前活动对象 → cmp 判空 → call slot42」，
    在 Scenario.CPP 里，靠近 'Toggle display mode back to shell res'。
    ⇒ 这是**显示模式切换**时对当前场景对象调 slot42，
      而 slot42 = 0x4A8960 = 视口尺寸变更 + 缓冲重建。
    ⇒ **这才是 §349 要找的『别的时机』**，且它有 cmp 判空守卫。
