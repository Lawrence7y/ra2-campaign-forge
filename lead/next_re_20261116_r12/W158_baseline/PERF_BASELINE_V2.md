## 2 · 口径（**引用任何数字前必须一起引这一节**）

### 2.1 时间源：**`t_perf_ns`，不是 `t_monotonic`** `[已证]`

派发提示词写的是"按 `t_monotonic` 真实时间分窗"。本卡照做了（主表 P0 就是 `t_monotonic`），但同时发现**这个口径在不该出问题的地方出了问题**：

| 事实 | 值 | 后果 |
|---|---|---|
| `t_monotonic` 只有 3 位小数、且量化到 Windows 64 Hz tick（**15.625 ms**） | 实测量化档 0.016 / 0.015 s | 单窗口 `Δt` 的绝对误差 ≤ **15.625 ms** |
| 在"帧几乎不动"的重载窗口里，`Δframe` 只有 2–32 | 见 §5 异常段（`dframe` 列 3~39） | `ms/frame = 1000·Δt/Δframe` 的相对误差可达 **15.625/Δframe·1000 ms** |
| 实测两种时间源算同一段的 `\|Δ\|` | **中位 0.035 ms，最大 12.478 ms** | 中位可忽略，**尾部不可忽略** |
| **13 个文件根本没有 `t_monotonic` 字段**（`t_monotonic` 为 `null`） | 401,831 个样本 | 这些文件**只能**用 `t_perf_ns`；若强依赖 `t_monotonic` 会静默丢掉 6 个接战趟 |

**因此本文件的立场**：
- **P0**（主表，按派发要求）：`t_monotonic` 分窗 + `t_monotonic` 算 `Δt`；
- **P0'**（推荐引用）：同一批段，`Δt` 改用 `t_perf_ns`（100 ns 网格）；
- 两者**分桶中位差 ≤ 0.08%**（32.0000 vs 32.0257 等），**结论不受影响**；但**异常段（挂起）的量级差到 11%**，那种地方**必须**用 `t_perf_ns`。

### 2.2 窗口与段指标（**写死**）

```
窗口 k   = floor( (t - t_趟首样本) / 10.0 s )         # 真实时间分窗；绝不用样本序号插值
段 ms/帧 = 1000 · (t_last - t_first) / (frame_last - frame_first)
段 子弹  = 该窗口内 A8ED50 的算术均值（b_mean）；另记 b_max / b_min
```

| 参数 | 取值 | 依据 |
|---|---|---|
| **窗口长度** | **10.0 s**（真实时间） | 与上游/台账同口径，便于对账 |
| **最小样本数** `MIN_N` | **30** | 6 ms 采样下 10 s 应有 ~1660 个样本；30 是宽松下限，只用来剔除"窗口边缘只剩几帧"的碎片。**实测见 §5：`MIN_N ∈ {2,10,30,100}` 对五桶中位一位都不差** |
| **最小跨度** `MIN_SPAN` | **9.0 s** | 窗口内首末样本的自然跨度恒 < 10 s（典型 9.98 s），**故 `span ≥ 10.0` 会得到 0 段**（§5 已实测），不能用 |
| **`Δframe > 0`** | 必需 | 否则 `ms/帧` 无定义（帧没推进） |
| **异常段（挂起）** | 段 `ms/帧 > 200` ⇒ **整段剔除**并单列 | 见 §5 异常段表；共 17 段。阈值 200 是"比满帧 32 ms 高 6 倍"的保守线，**不是**统计判据 |
| **是否含 `mode=2`** | **不含**（主口径要求整窗 `mode == 0`） | `mode=2` 的非局内段 `ms/帧 ≈ 107–109` 而子弹 ≈ 0–3，会污染 0–24 桶尾部。**注意：本语料里这些段全部 `Δframe = 0`，本来也进不了表**（见 §5 mode 小节） |
| **趟纳入规则** | 趟名**不含** `crash_step2`（已知多格建筑重叠病态）；其余全纳入。不按"段数 ≥ N"筛趟 | 上游用的"段数 ≥12 的完整趟"无法从数据复现（§8 D-2），本卡改用**只按段质量筛、不按趟筛**，避免引入不可复核的趟级门槛 |

**n（可直接引用的样本量）**：

- 全部窗口段 **1623**；通过"跨度≥9 s + Δframe≥1 + n≥30" **1269 段 / 92 趟**（= 上游 F0，逐位吻合）
- **主口径 P0 = 1161 段 / 82 趟**（再加 mode==0 与 17 段挂起剔除）
- 分桶表里五个桶的 n 分别见 §3
