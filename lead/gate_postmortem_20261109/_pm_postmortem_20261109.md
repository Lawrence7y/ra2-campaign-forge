## 2 第一步：共同根因

### 2.1 一句话根因

**11 类误报是同一个结构性错误在两个失效方向上的投影：门禁把「字面词形是否出现在全文里」（surface containment）当作「合同义务是否成立」（obligation holding）的判据；而合同义务真正的谓词是三元组——(作用域 scope：义务只约束承载断言言语行为的区段) × (结构形态 shape：绑定对/成对块/编号所指/标识符，经归一化) × (断言极性 polarity：肯定断言 vs 否定/引用/元语言提及)。字面包含对这三层全不敏感：对词形变体（类 5/8/9/10/2）它「漏认存在」→ 报缺要素；对元语言使用（类 1/4/6/7/11）它「误认断言」→ 报越权；再叠加门禁自身无运行时自检（类 3）把「没查」当「查了没事」。**

r2 修正模板的总则已经点破同一根因：`GATE_TEMPLATE_FIXED.py.txt:47-52`（R0）「误报一/二/三的共同根因：旧门禁把『字面出现』当『违规』」以及「判 fail 必须能引用新增差异或结构事实；仅有字面命中而无行为差异 ⇒ 放行」。本复盘的贡献不在重述 R0，而在：把 11 类全部归一到 R0 原则、指出模板尚未覆盖的类（3/9/11，及 6/7 的极性层）、并给每类可运行的结构谓词。

### 2.3 字面谓词的一个致命统计性质

字面包含谓词与**合规性正相关**而不是负相关：守规矩的动作（逐条写「不宣告…已生效」「不授实施权」「不出现『放行 N-5』类断言」、引用复核意见原文）恰恰是产生禁词命中最多的动作。§3.4 用数据验证这一点。推论：这类门禁不只是「噪声大」，而是**系统性惩罚显式合规、奖励隐式合规**——agent 学会改写自查措辞绕开词表后，门禁对真违规的灵敏度同步退化（regression 报告已实证同类「消除机制自带绕过面」三例：`GATE_TEMPLATE_REGRESSION.md:130-134`）。

## 4 第三步：结构谓词替代方案（逐类，含本会话真件验证）

总框架：每条门禁检查改为回答四问——(a) 作用域：我在看承载义务言语行为的区段吗？(b) 形态：归一化后结构成立吗？(c) 极性：这是肯定断言还是 mention？(d) 自检：本次实际检查了几项？输出三态 PASS / FAIL / REVIEW（见 §6）。

### P-A 归一化匹配（类 5/10，兼及 8 的解析层）

两遍归一化（顺序敏感，沿 fp7 R9 的设计并简化）：N2 先修反引号跨度内换行拆断，N1 剥 markdown 修饰符（反引号/星号/波浪线）、压缩空白。**匹配 = 归一化(needle) ∈ 归一化(haystack)，双侧同函数。**

```python
def join_backtick(s):   # N2：`APPROVE_\nSCOPE` -> APPROVE_SCOPE
    out, pos = [], 0
    for m in re.finditer(r"`([^`]*)`", s):
        out.append(s[pos:m.start()]); out.append(m.group(1).replace("\n", ""))
        pos = m.end()
    out.append(s[pos:]); return "".join(out)
def norm(s):            # N1：剥 ` * ~ 修饰符，压空白
    s = re.sub(r"[`*~]+", "", s.replace("\u00a0", " "))
    return re.sub(r"[ \t\u3000]+", " ", s).strip()
```

实跑验证（`_pm_struct_pred_demo_out.txt:1-4`）：真件 `_g7_tv7_split_token.md`（`APPROVE_\nSCOPE` 拆断形态）raw=False → 归一化后 True；真件 `_g7_tv1_missing_element.md`（真缺要素）归一化后仍 False——**变体被救回、真缺不误放**，这正是结构谓词与「多写几条正则」的区别：归一化是有限、双侧、可约定的变换，不是词表膨胀。

### P-B 绑定行：可提取性 × 真实性两问（类 8/10）

把一个问题拆成两个独立谓词：
- **可提取性**（宽容）：归一化后按形状解析 `被核对象 [（…）] SHA256 = <64hex> [，] 字节数 = <n>`，括注路径、加粗、反引号一律容忍；解析不出 → REVIEW（转人工锚定，对应模板 R3-3b，`GATE_TEMPLATE_FIXED.py.txt:159-160`）。
- **真实性**（从严）：凡能解析出被核对象路径 → 现盘 hashlib 重算并与声明比对，失配 = FAIL（R3-3a，查真问题非误报）；被指向对象不在盘 → FAIL（R3-3c）。**排版宽容度只影响「能否提取」，永远不影响「是否真实」——最终判据是密码学比对，不是措辞。**「被核对象」与 hex 之间允许什么 infix（路径括注？）是合同参数，应显式写进任务书（现行铁律已禁 infix，则类 8 形态在现行合同下属违规；11 类清单把它列为误报说明当时合同与门禁口径不一致——修法是统一口径，不是门禁私改）。

实跑验证（`_pm_struct_pred_demo_out.txt:6-10、:43-46`）：真件 `CANDIDATE_RESIGN_YES_V2.md:122`（类 8 实例：路径括注+反引号 hex+加粗）——紧邻正则解析 False（**朴素门禁 FP 现场复现**）；宽容解析 True，路径形正则抽出 `lead/n4_yi_final_20261108/_cs_semantic_review_GLM_20261108.md`，现盘重算 `ee27b4caf4fa…/11948` 与声明 **MATCH=True**（R3-3a 真件通过）；加粗类 10 变体归一化后解析 True。

### P-C 断言极性判定（类 6/7）——为什么「前 N 字符有无否定词」注定不够，以及判定逻辑

**粗糙法失效的三类实证**：
1. **双重否定=肯定**：真件 `_g7_tv3_double_negation.md`（fp7 轮为此专门构造）——「本件**并非不**宣告 N-4 正式绑定已生效」「审阅**不得不**承认本候选已生效」是真违规，「上一轮回件**不**宣告…已生效」应豁免。编排方式 A 口径（窗 24 回看）把三处全判否定语境 → **漏检 2 处真违规**（`_pm_struct_pred_demo_out.txt:34-37`、`_pm_negation_probe_out.txt:82-87`）。
2. **引号 mention**：CANDIDATE:130 翻案条款引文（§3.3）——回看窗内无否定词，回看法判 assertion（误报）。
3. **长辖域否定**：「以下均不成立：放行 N-5；解除 PAUSE。」——分号切句后第二项落在否定辖域外（本跑 B 口径同样失判，属已知残限；`_g7_predicates.py:71` 的 CLAUSE_BREAK 设计明确「否定回看不跨句」，代价即此类）。

**为什么否定词奇偶计数也不行**：fp7 轮已论证并否决——两个独立否定短语（「无越权断言…不出现」）会被奇偶法误判成肯定、三个否定词（「并未…并非不…」）会被误豁免（`_g7_predicates.py:74-75、137-139`，R12 注释原文）。奇偶是语法玩具，不是语义判定。

**判定逻辑（分层，B 口径，本会话实现并跑在真件上）**：
```
第 0 层 use-mention（结构性，可靠）：
  命中落在代码围栏 / 行内反引号 / 短引号跨度（「…」『…』“…”）内
  → mention，非断言（另计 warnings 留审计）。覆盖本语料 6/14 命中。
第 1 层 双重否定构式（词表限闭类）：
  子句前缀含 R12 构式词表（不得不|并非不|并不是不|不是不|无不|没有不|不无|不能不|不可不|未曾不）
  → 肯定断言（FAIL）。tv3 实证捕获 2/2 真违规。
第 2 层 单否定（子句辖域）：
  否定算子（与编排方同词表）出现在同一子句（。！？；\n 之前）→ 否定语境（豁免+warning）。
第 3 层 条件/假设语境：子句前缀含 若/如果/一旦/假设/触发/出现 → 假设性提及（REVIEW）。
第 4 层 兜底：以上皆无 → 肯定断言（FAIL）。
```
B 口径在本语料 14 命中上：非断言 14/14（0 误报），tv3 上 2 真违规全捕 + 1 豁免正确（`_pm_negation_probe_out.txt:80`、`_pm_struct_pred_demo_out.txt:32-37`）。

**覆盖率的诚实结论（§5 展开）**：第 0 层是结构判定、可依赖；第 1-3 层是词法启发式，**对自由散文的极性判定本质不可判定**（长辖域、隐含否定、元话语无限多变体）。所以极性判定器只允许做**分诊**（把命中分流进 REVIEW 人审队列），不允许做终审 pass/fail；终审靠作用域限定（P-D）把断言约束进合同指定区段。

### P-E 编号归一化（类 9）

```python
def idtok(s):                       # D-01 / D01 / D_01 / D.01 / D 01 -> D01
    s = re.sub(r"(?<=[A-Za-z])[-_.\s]+(?=\d)", "", norm(s))
    return re.sub(r"\s+", "", s).upper()
```

判定 = 双侧用同一 idtok 提取 token 集合，比对**集合等价与计数**，而不是数某种拼写。实跑（`_pm_struct_pred_demo_out.txt:12-21`）：五种分隔形态全部归一为 D01；DIM 风格行上 `\bD(\d+)\b` 命中 0（FP 现场复现），归一化 token 命中 True。

## 6 第五步：优先级建议

排序原则：先修「危险」类（真违规被放过/门禁自身失效），再修「吵闹」类（合法被误杀）；同优先级内按「修复面 × 成本」。

|---|---|---|---|
