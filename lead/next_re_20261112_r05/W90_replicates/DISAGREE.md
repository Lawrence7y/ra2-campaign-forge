# W90 DISAGREE · 与既有签发口径的差异点（如实列出，不粉饰）

1. **交战臂 CPU 消耗率绝对值略低于 W88**：本卡 C6_c/C6_d = 31.01/31.97% vs
   W88 33.61%。对照臂基本一致（17.75/17.76 vs 18.10）。差异方向使**比值变小**
   （1.746/1.801 vs 1.857），即本卡没有放大 W88 的结论——重复趟把初估比值
   收窄到 1.75–1.80 一带。判定不受影响（三对全部 ≥1.10），但"85.7%"应理解为
   三对 1.857/1.746/1.801 的上端，不是稳定值。
2. **"cycle 通道逐位一致"（W88 口径）未复现**：见 UNKNOWNS U1。本卡两通道比值
   方向/量级一致但数值差 ~1.5–2.5%。若 W88 的"逐位一致"来自不同换算口径
   （例如对同一趟内逐样本相除后取中位），两种算法本卡都已落盘（analysis.json），
   供 Lead 复核 W88 数据时对照。
3. **W86 文档预期 clamp=60，实测 210**：见 UNKNOWNS U2。主自洽判据（maxfps/interval）
   通过，不影响「限帧放行间隔」统计有效性，但 W86 报告若引用了 +0x5EE48=60
   的断言，需要复核。
4. **A8ED50 非零拍占比高于 W88**：97.8%/93.2% vs 94.05%——同量级，无矛盾，
   仅列出。X87E8E0 变化次数 6509/6197 vs W88 6518——同量级，无矛盾。
5. 与 W88 结论**无冲突点**：零交战对照臂 A8ED50 全 0 / X87E8E0 恒值、四趟零崩溃、
   比值 ≥1.10 的方向全部复现。
