1. 理论上界推导（采样周期 2ms / 500Hz）
--------------------------------------------------------------------------------
推导过程：
  设连续物理时间中，游戏停滞的物理发生点为 S。
  以标称频率 fs = 500 Hz 对游戏状态离散采样，标称采样周期 Ts = 1 / fs = 2.0 ms。
  离散采样序列为 {..., t_{k-1}, t_k, ...}，相邻采样时间间隔标称为 t_k - t_{k-1} = Ts = 2.0 ms。
  在帧号时间序列 samples.f 中，停滞平台首个采样观测点为 t_k（即 startTick 对应的采样点，作为 S 的代理 S_hat = t_k）。
  在此点之前，t_{k-1} 处的帧号为推进中的前序帧 f(t_{k-1}) != f_stall；
  在 t_k 处首次观测到该停滞帧 f(t_k) = f_stall。
  因此，物理跃变点 S 必落在半开半闭区间 (t_{k-1}, t_k] 内，即 t_{k-1} < S <= t_k。
  若以 t_k 作为 S 的代理估算值（S_hat = t_k），其单向滞后观测误差 e 为：
    e = S_hat - S = t_k - S
  由 t_{k-1} < S <= t_k 可得：
    0 <= e < t_k - t_{k-1}
  在理想均匀采样下，t_k - t_{k-1} = Ts = 2.0 ms：
    0 <= e < 2.0 ms
  ⇒ 起点观测误差的理论上界（单向最坏偏差）为 Ts = 2.0 ms。
  （注：若在线因果触发仅能在 t_k 及之后感知状态变化，则当 S 紧随 t_{k-1} 发生时，
   t_k 相对物理起点已延滞接近完整的采样周期 Ts = 2.0 ms；
   若采用离线非因果区间对称中点估算 S_mid = (t_{k-1} + t_k) / 2，则绝对误差上界为 Ts / 2 = 1.0 ms，
   但在实时在线捕获场景下，必须以首次观测到状态变化的采样拍作为因果锚点，故最坏单向偏差理论上界为 2.0 ms）。

  依据 D-29 / :177 要求，现场必须在物理停滞发生后 50ms 内完成捕获保存（C - S <= 50 ms）。
  当以离散采样首拍 S_hat 作为观测锚点时，若观测误差为 e（S 相对 S_hat 提前发生 e ms，即 S = S_hat - e），
  则从观测时刻 S_hat 到保存完成时刻 C 的可用物理窗口为：
    C - S_hat <= 50 - e ms
