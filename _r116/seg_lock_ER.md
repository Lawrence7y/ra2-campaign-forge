
ER. R116 —— IID 的**客户端请求面**首次下钻：0x7f7c80 侧定死为 IPersistStream 角色，0x7f7c70 侧 L4 未证

ER1. **换面**：R112–R115 四轮全在**服务端**（slot0 的 `repe cmpsd` 比对序列）判
0x7f7c70 / 0x7f7c80，那面上两者永远同现、命中写回同一指针 ⇒ 认领类各 90、对称差 0
⇒ 不可区分（**该结论正确**，但适用域仅识别集）。本轮读**客户端请求集**：
谁把哪个 IID 当 riid 请求、返回值交给哪个 ole32 API。识别集对称**不蕴含**请求集对称。

ER2. **L1 字节事实**：0x7f7c70 = `0000010C-0000-0000-C000-000000000046`；
0x7f7c80 = `00000109-0000-0000-C000-000000000046`。GUID 形状常量（+4==0、+8==0xC0、
+12==0x46000000）全 .rdata 共 **6 个**。请求面：0x7f7c80 命中 64 = mov 4 + **push 60**、
落 **36** 函数；0x7f7c70 命中 **4** 全为 `mov edi,imm32`（服务端 cmpsd 基址：
0x4102b1 / 0x4f68c9 / 0x5125dd / 0x55aa2d），**push 0 / 请求函数 0**。
IUnknown 对照 push 56 / 8 函数（证明「被请求」不是普遍现象）。

ER3. **替代解释已排除且反控有正控**：两步形态（mov R,imm ; push R）全 .text 实测
**273 例**、栈槽形态（mov [esp+X],imm32）**4495 例**，两者正控均存活，其中 0x7f7c70 者
各 0 例。全镜像扫描确认 0x7f7c70 的 4 处全在 .text。

ER4. **L2 耦合（唯一外部前提：ole32!OleSaveToStream 的公开签名里第 1 实参是 IPersistStream*）**：
36 个请求函数**全部**在请求后调用 OleSaveToStream（IAT 0x7e15f4），两种调用形态都算
⇒ **36/36**。数据流 35/35 可机械证明「第 1 实参 == QI 从 ppv 栈槽装回的指针」；
ppv 偏移错开 4 字节命中 0；换 IUnknown 命中 0。第三面：OleLoadFromStream 的 REFIID 位
0x7ed358 出现 5 次、0x7e9af0 1 次、**0x7f7c70 0 次**。

ER5. **关键降级（必须与所有比例同框）**：35 站点**不是** 35 份独立实现 ——
35 个 dispatcher 调用点全满足 `mov ecx,esi ; mov edx,imm32 ; call rel32` 锚形态，
35 份被调函数体前 **112 字节逐字节全等**，35 个 edx 两两不同全落 .data
⇒ 实为 **1 个模板 + 1 张 35 项 .data 表**；代码维度独立证据 = **1**，
按指令形状去重 36 个请求函数只有 **2 类**。审计员据此判「97.2% vs 0%」不可当效应量
（Fisher 单侧 p=2.70e-09 方向极显著，但两侧有效样本都小；baseline 10 对中 8 对
与 IUnknown 反控重叠）。**主会话接受该降级。**

ER6. **分级**：1.1/1.2/1.3/1.5 = L1；1.4 = L2；1.6（0x7f7c80 = IPersistStream 语义）= **L3**；
**1.7（0x7f7c70 = IPersist）= L4 未证，不编**。不编理由：该 IID 零正面客户端证据，
名字只能来自「沉默 + 排除法」，而 COM 继承约定**预测**这个沉默（派生接口已覆盖基类方法，
客户端无理由再请求基类）⇒ 基类 push 计数 0 是正常用法预期，不是它等于 IPersist 的证据。

ER7. **范畴不越界**：R112 域（服务端识别集）内结论**仍正确**；R116 域（客户端请求集）高度不对称。
二者正交可同时为真：类可同时响应两 IID，客户端因类型只请求派生接口。
用 R116 + 外部 SDK 签名声称「R112 错了」是拿域外前提推翻域内结论 —— 范畴错误。

ER10. **方法论（记住）**：① **识别集对称不蕴含请求集对称** —— 「我认识哪些 IID」与
「我被谁按哪个 IID 要过」是两个正交的判据域，换域才可能出差异；
② **零命中也要有正控** —— 一条「处处 0」的检测器不能用来排除任何假设，
必须先在真实镜像里找到它**应该**命中的正控样本（本轮 273 / 4495 例）；
③ **模板拷贝 ≠ 多份证据** —— 逐字节全等的 N 份函数体，独立证据数是 1，
必须按「代码形状 / 数据项 / 站点」三粒度并列报告，不许只挑好看的那个；
④ **阴性事实不能定名** —— 「从没被请求」可以支持「它不是被客户端按名请求的接口」，
但推不出它的名字；**名字需要映射表，映射表不在二进制里**；
⑤ **域外前提不能推翻域内结论** —— 用外部 SDK 签名去修正一个明示限定「本库静态证据下」的
结论，是范畴错误，正确做法是把新证据写成「边界外推」而不是「旧结论作废」。
