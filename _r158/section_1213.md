### 七 · 🔴 交付六：F24 的 bounds 字节对应用**最弱判据**测得 100.000000%

R136 用「落在任一指令起始集内」得 **99.992%（1,392,481 / 1,392,592）**。本轮改用**更弱的判据**（只需 PE 节表：VA 是否落在某节 `SizeOfRawData` 内，不做指令边界、不做可达性），`gamemd.exe` sha256 `73201cc0…` 自校验（`_r158/r158d_bounds_bytes.py` 14 断言 0 FAIL）：

**1,392,592 / 1,392,592 = 100.000000%，未命中 0 条。**

正反控六条全过：`.text+0x10` 命中 / `ImageBase` 不命中（PE 头不在节内）/ 映像末尾外 1 MB 不命中 / 恒真判定下未命中归 0 / 1000 个映像外地址命中 0 / `.text` 内随机 1000 地址命中 1000。

⇒ **弱判据 100% > 强判据 99.992%**，弱判据给出上界，**R136 的 99.992% 不是过估**。但两者**不可互换引用**：一个是「落在节内」，一个是「落在指令起始集内」。

### 八 · 📌 交付七：「单列地址、无第二列」判据首次有可机械复核的支撑
