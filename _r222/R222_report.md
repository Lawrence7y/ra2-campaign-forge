### 1 · 方向：解包器不是编码器

```

7c6307  mov  al, byte ptr [esi]      ; 读 1 B = 2 nibble
7c6309  mov  word ptr [ebx+0x1c], ax ; 缓存整字节
7c630d  inc  esi
7c630e  and  eax, 0xf                ; 取低 4 位
...
7c637c  cmp  word ptr [ebx+0x38], 0x10
7c6383  mov  word ptr [edi], ax      ; 16 位：写 1 个样本
7c6386  add  edi, 2
7c638b  xor  ah, 0x80
7c638e  mov  byte ptr [edi], ah      ; 8 位：无符号→有符号

反控：全函数**无** `mov [esi],..`、**无**把 `[edi]` 读进 `al/ax/eax`（`m8_inline_dec.py` R1 两项皆空）。

```

7c632c  test eax,2   → shr edx,1 / add                     (step/2)
7c633a  test eax,1   → shr edx,2 / add                     (step/4)
7c6349               → shr edx,3 / add                     (step/8，无条件)
7c6351  test eax,8   → 0x7c6358 neg dword ptr [ebx+0x18]   (符号)

### 3 · 16 项索引表

```
7c6397  xor  eax, eax
7c6399  shl  ecx, 1                     ; ecx = 2 * nibble
7c639b  mov  ax, word ptr [ecx + 0x8758c4]
```

nibble ∈ 0..15 ⇒ 读地址范围 `0x8758c4..0x8758e3`，其中 `0x8758d4..0x8758e3` 就是"0 条字面引用"的那 16 B。

```
16 项有符号字 = (-1,-1,-1,-1,2,4,6,8) × 2       (T16 == T8 + T8)
0x8758c4..0x8758d3 与 0x8758d4..0x8758e3 逐字节相同
```

⇒ 一张 16 项表：低 3 位选幅度调整、bit3 是负号。R221 QX7 的「未被引用的重复常量」订正。
