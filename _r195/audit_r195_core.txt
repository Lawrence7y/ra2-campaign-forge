    得到 80。多出的 2 张是模板容器表：
      008009b0  .?AV?$DynamicVectorClass@PAVAbstractClass@@@@ / .?AV?$VectorClass@PAVAbstractClass@@@@
      008009e0  .?AV?$VectorClass@PAVAbstractClass@@@@
    ⇒ 78 是「精确匹配」口径的正确数，80 是子串误吞口径。

  形态细节：mov, 2 操作数, 目的操作数为内存, 指令长度 6 字节 332 条 / 7 字节 9 条

以 0x4A1CA0 起始单条窗口解码至首个 ret：

  末指令 004a1d23  ret 4

  字节长度 = 134 字节（004a1ca0 .. 004a1d26）

对状态对象（ecx）访问的偏移集合（做了 mov reg, ecx 的寄存器别名传播；
含 [eax+ecx+8] 这种 ecx 作 index 的复合寻址）：{ +0x0, +0x4, +0x8, +0xC }

  +0    ? 是   读于 004a1cec `mov eax,[ecx]`
  +4    ? 是   004a1ca0 读 / 004a1cbb 读 / 004a1cc1 写 / 004a1cc9 字节读 / 004a1ccf 读
  +8    ? 是   004a1ca9 写（条件清零） / 004a1cb7 字节写 [eax+ecx+8] / 004a1cd7 字节读 / 004a1ce4 读
  +0xC  ? 是   004a1ccc 字节写 `mov byte ptr [ecx+0xc], al`

结论：四个偏移 +0 / +4 / +8 / +0xC **全部被访问**，一个不少。

Q4  0x4A1CA0 体内对 [+0] 的写 —— 我复算成立
================================================================
存在，且仅 1 处：
  VA        = 004a1d1b
  字节序列  = 89 01
  助记符    = mov dword ptr [ecx], eax

是否「先读入再写回」：**是先读入再写回（read-modify-write），没有独立的初值写入**。
依据：同一寄存器 eax 在 004a1cec 由 `mov eax, dword ptr [ecx]` 从 [+0] 读入，
随后 004a1cf3 `not eax`、004a1cfa..004a1d16 对 4 字节（edi=4 作计数）做
`shr eax,8` / `mov ebx,[ebp*4+0x81f7b4]` / `xor eax,ebx` 的表驱动循环（CRC 形态），
004a1d18 `not eax`，最后 004a1d1b 写回 [+0]。
中间没有任何对 [ecx] 的立即数/常量初始写入。

（附带：004a1ca9 有一处对 [+8] 的条件写 `mov dword ptr [ecx+8], edx`，edx 在 004a1ca3 已 xor 清零，
  这是「+8 清零」而不是 +0 的初值。）

Q5  0x4A1CA0 被调用次数 —— 两口径相等
================================================================
(a) 全段 resync 线性反汇编，mnemonic == "call" 且 IMM 操作数 == 0x4a1ca0 的指令条数

(b) 字节模式：.text 内每个 E8 字节，取其后 4 字节作有符号 rel32，
    (E8VA + 5 + rel32) & 0xFFFFFFFF == 0x4a1ca0 的次数

331 条出现在 0x00410429 至 0x00772c7f 之间；其中 007172d8/007172f4/00717302/00717310

（补充说明：call 指令在 x86 上恒为 E8+rel32，故两个口径在本机上必然一致；

import sys,struct; sys.path.insert(0,'_r185')
from pe185 import RAW,B,sec_of,dw,cstr
r={}
for i in range(B['.rdata']['rawsize']//4):
    o=B['.rdata']['rawptr']+4*i
    d0,d1,d2,d3,d4=struct.unpack_from('<5I',RAW,o)

S=0;H=0
for s in [B['.rdata']]:
    for i in range(1,s['rawsize']//4):
        va=s['lo']+4*i
        if not(TL<=dw(va)<TH) or dw(va-4) not in CS: continue
        k=0
        while TL<=dw(va+4*k)<TH: k+=1
        S+=k; H+=1
print('COL',len(r),'main',sum(1 for v in r.values() if v[1]==0),'sub',sum(1 for v in r.values() if v[1]),'headers',H,'slots',S)
EOF
