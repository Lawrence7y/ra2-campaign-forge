## 1. 裁决（分两层，各自到字节能撑处）

**(a) 证伪的部分**：kb/21 §1.2 的候选解释「`+0x54` 或由 `TriggerClass` 的存档负责」——
**不成立**。`TriggerClass::Save`（主表 `0x7F5858` slot13 @`0x726790`）整窗 **0x86 字节**
（53 指令，head→`ret 4`）逐字节钉死（T2），窗口内：

- **disp 形态普查 = +0x54 零处**（T3）。阳性对照：同一解析器在窗内看得见
  `{+0x24,+0x28,+0x30,+0x34,+0x3c,+0x40,+0x44}` 七个字段 disp8 ⇒ 「零」是事实不是瞎
  （G-60 判据 1 对本线自身执行）。`[esp+0xc]` 是 SIB（rm==4，G-61）不入字段表。
- **直接 call 目标集（capstone 线性解码取 imm）= 恰 {基类 Save `0x410410` ×1,
  `0x4A1CA0` ×2, `0x4A1D50` ×4}**（T4；后两族头字节钉死=字段 writer，`0x4A1D50` 与
  R-042 X5 同一 writer）。另有 2 个**间接** call `[ecx+0x10]`/`[edx+0x10]`——与 R-042
  X2 同形态（facet slot4 取 ID 写流；TriggerClass 侧 facet 未重解，登记）。
  ⇒ Save 序列化的只有自身字段与 ID，**无任何被调方可能触到事件 +0x54**。
- **handler 交叉**（T5）：`event+0x54` 唯一存活写入者 handler `0x71E940` 的全镜像 E8
  入口集恰 = {`0x726540`}（在消费循环 `0x7264C0` 体内，非 TriggerClass 虚方法，S1）；
  Save 窗口既不含 `0x726540`、其 call 集也不含 handler ⇒ **Save 路径与 +0x54 的写链
  在直调面完全不相交**（间接面按 charter 只登记不宣称）。
- 类身份闭合（T1）：slot11=WhatAmI `mov eax,0x26`、slot12=GetSize `mov eax,0x48`(=72,
  触发器族尺寸台账复证)、slot13=Save；名字表第 0x26 对 word1=0x26/word0='Trigger'。

**(b) 保持开放的部分（L-20 不关闭）**：「+0x54 由谁存档」的完整答案需要裁决
`+0x54` 的读侧容器（消费方 `0x7264C0`/容器 `[esi+0x2C]`）宿主类归属（L-30 域）——
本轮只证伪了 kb/21 里**点名**的那个候选路径。现状收敛为：R-042 的「运行时缓存⇒
天然无需存档」假说**未被任何存档路径反驳、且现在又多一条负证据**（TriggerClass::Save
亦不存它），但**仍非证明** ⇒ **L-20 维持开放**（诚实边界：证伪一条候选 ≠ 定谳问题）。

## 3. 诚实账（本轮抓到并修复的三件事）

1. **★ 探索脚本用回双游标 `dump()` 助手**（`a+=size` 与 `o+=size` 同推进——G-63 刚定谳的
   漂移机制），其输出的地址表（call 目标 `0x4a1d6d` 等、字段 disp 址）是**幻影表**；
   变异套件首版的偏移正是从这张表抄的 ⇒ M3 目标 0x726837 落在窗外（rc=0 不红）、
   M5 打到字段 disp 而非 call rel、disp 字节位 +1/+2 混乱——**8/12 偏差把幻影表暴露**。
   修正：所有偏移按权威 dump 重导（「disp 字节=操作数 VA+2、rel32 首字节=call VA+1」，
   现由 capstone 线性解码现场打印），12/12 全中。
   **注意区分责任**（防二次误诊）：T4 断言首版用 raw E8 扫描取目标集，本窗内其结果
   {0x410410, 0x4A1CA0×2, 0x4A1D50×4} 与权威解码**完全一致**——断言本身没错；但方法
   脆弱（bytescan-phantom 记忆在册：E8 侧幻影率 ~7.7%，只是此窗的 imm 里恰好没有 0xE8
   字节），故仍改为从解码器取操作数——**换的是取数方式，不是纠错**。
   **教训升级**：探索输出与断言取数必须共用同一解析器；凡从"另一段脚本的打印表"抄
   常量进代码（本轮的变异偏移），先核该脚本用的解析器是不是在册的漂移形态。
2. **我自己的误诊现场（二次传染前掐灭）**：本节初稿把上述事件写成「T4 首版把幻影
   钉进台账、门禁 5/5 是巧合」——对产物重查后证伪（raw 扫描与解码两版目标集相同）。
   这是 G-63「错误自诊比错误本身更难发现」在**写诚实账的同时**的复发，删改为本。
3. **正向确认 G-65 工序有效**：本轮 T1/T2/T4/T5 的 hex 全部先 print 后贴，一次通过；
   变异偏移错配由**首跑偏差**当场暴露，未流入台账。
