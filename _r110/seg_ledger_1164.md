## §1164 R110（2026-11-24）· COM 暴露面 172 类 × 17 IID（6 个标准 OLE 接口，4 个与 RTTI 类名逐字对应）；COL.offset 可证伪预测 12/12；第二套函数边界判不存在；并纠出 R109 的位移正则缺陷（总数对、分类全错）

**任务**：接 R109 §EK9 的两条未取得项（COM 暴露面、异常处理表可否当第二套边界），
外加一次对 R109 自身数字的复核。全部在 t628 本机静态完成，无真机、无 win-main。

**取得（四条）**

1. **COM 暴露面**：954 个类里 **172 个（18.0%）** 的 slot0 具备 QI 头部字节形态
   （头 120 B 内 `mov ecx,4` → `mov edi,<IID>` → `repe cmpsd`，IID 指针必须落 PE 数据节）。
   反控随机 20000 指令起点同判据命中 105（0.525%）⇒ 富集 **34.3 倍**。
   distinct QI **实现**仅 **90 个**（模板工厂族大量共享）。每类认 1/2/3/4 个 IID 的类数 = 1/92/3/76，和 = 172。
   distinct IID 按指针 **17**、按内容去重也 **17**（双射）；17 个全在数据节，**0 个**在 `.text`。
2. **17 个 IID 里有 6 个是标准 OLE 接口**，且其中 **4 个的语义与其认领类的 RTTI 类名逐字对应**：
   IStream→CStreamClass、IEnumConnections→EnumConnectionsClass、IConnectionPoint→ConnectionPointClass、
   IEnumConnectionPoints→EnumConnectionPointsClass（GUID 在 slot0 体内、类名在 TD 里，两条独立证据）。
   另两个是 IUnknown（171 类）与 IClassFactory（78 类）。其余 11 个为自研 IID，
   最宽的是 `170DAC82-12E4-11D2-8175-006008055BB5`（76 个类共同认领）。
3. **COL.offset 语义的可证伪预测 12/12 命中**：R109 只给了分布（942 个 0 / 12 个 4）与一句「基类子对象」的解释。
   本轮列出 12 张表的类名（**全是 Locomotion 族**），并做预测检验：若 offset 是对象内偏移，
   这 12 张的装配点必须 `mov [reg+4], vt` ⇒ **12/12 的 disp 全为 4**。
   反控：全段 8240 个 `mov [reg+disp],imm32` 里 disp==4 仅占 **5.52%**，若语义为假，12 张全中的概率约 **8.0e-16**。
4. **「第二套函数边界」判为不存在**（R109 §EK9⑥ 的未取得项）：SEH 链成对点仅 **15 个 / 6 个函数 / 17766 = 0.03%**；
   C++ EH FuncInfo 完整形态全镜像 **1 条**（`0x87c1d0` 在 `.data`），`.text` 内 3 条立即数引用；
   另 2 处 magic 命中经周边字节判为巧合（`.rdata` 那处紧跟星期字符串）。

**纠错（一处，属 R109 缺陷、非本轮引入）**

R109 的 `r109a_attr.py` / `r109e_container.py` / `r109f_vtmodel.py` 三处共用一条位移正则，
字符类 `[a-z0-9+* ]` 含空格与 `+`，贪婪吞掉 `" + 0x15c"` ⇒ **disp 恒为 0**。
- **总数只差 5**：正确分桶 = 裸寄存器基址 **4271**（disp==0 的 2774 + disp≠0 的 1497）+ 绝对地址 **340** + 负位移 **5** = **4616**；
  R109 报 4611 = 4616 − 5（旧正则字符类不含 `-`，5 条负位移一条没进）。
  注意 R109 的「写偏移 0 = 2762」与本轮 disp==0 的 **2774** 差 12 条 `[esp], vt`，两者口径不同不可混用。
- **分类全错**：R109 的「2762 / 非 0 偏移 1849」是假二分；1849 里混着 1497 条真 this 内偏移与 340 条全局对象写入（语义不同）。
- **受污染的结论**：「写 `[reg+0]`=vt 后同 reg 又被 `[reg+disp≠0]` 读 = 1304/2438（53.5%）」
  → 正确判据（正确正则 + HB 边界）为 **1478/1637 = 90.3%**，反控富集 7.1 倍。
  **方向不变、结论加强**（53.5%→90.3%），但引 R109 §EK4④ 必须改用新数或引本条。

**方法学（可复用）**

- 把「解释」升级成「可证伪预测」是廉价且高产的：COL.offset 这一条前后不到 40 行脚本，
  但把「一句括注」变成了 12/12 + 8.0e-16 的硬证据。凡是 R109 里出现「（= 某某）」这类括注，
  都值得问一句「若真如此，还应当观察到什么」。
- 位移正则这类「看起来显然」的解析，必须配一条**覆盖率/不变量断言**（本轮 L-05 连错三次，
  每次都是断言抓出来的）。正确的断言不是「覆盖率 ≥99%」（形态本来就杂），
  而是「未解析形态里不含目标对象」（P2a3）。
