EL2. ✅ **COM 暴露面：172/954 个类（18.0%）的 QI 认 17 个 distinct IID**
- 判据：slot0 函数体**头 120 B** 内按序 `mov ecx,4` → `mov edi,<imm32>` → … → `repe cmpsd`，
  且 imm32 必须落在 PE 数据节（节区间**从 PE 头现读**，不手抄）。
- 反控：随机 20000 指令起点同判据同窗口命中 **105（0.525%）** ⇒ 富集 **34.3 倍**。
  其中 78 个是「窗口漂进已知 QI 函数头」，故基线不是判据松。
- distinct QI **实现** 仅 **90 个** < 172 个类 ⇒ 模板工厂族大量共享同一实现。
- 每类认 IID 个数分布 `1→1 / 2→92 / 3→3 / 4→76`，四项和 = 172。
- distinct IID 按指针 17、按 16 字节内容去重也 17（**双射**）；17 个全在 `.rdata/.data/.detour`，**0 个**在 `.text`。

EL4. 🔴 **一个假例外被查清：AircraftClass 是「经委托」认得 IUnknown（自错 L-04）**
    r110a 的 S7 报「172 类里 1 个不认 IUnknown」。逐字节看 0x414290：

EL5. ✅ **COL.offset 语义：可证伪预测 12/12 命中**（把 R109 的「一句括注」升级成硬证据）
    R109 §EK4 只给分布（942 个 0 / 12 个 4）并括注「= 基类子对象」。本轮列出 12 张类名 ——
    **全是 Locomotion 族**（Drive/DropPod/Fly/Hover/Jumpjet/Mech/Rocket/Ship/Teleport/Tunnel/Walk + LocomotionClass）。
    预测：若 offset 是对象内偏移，装配点必须 `mov [reg+4], vt` ⇒ **12/12 disp 全为 4**（每个类 2～6 个装配点）。
    反向（修正版）：offset==0 且有装配点的 846 张里「无任何 disp==0 装配点」的仅 **51 张（6.0%）**。
    反控：全段 8240 个 `mov [reg+disp],imm32` 里 disp==4 仅 **455（5.52%）**，

EL6. ✅ **「第二套函数边界」判为不存在**（R109 §EK9⑥ 未取得项，三条路都走到底）
    - SEH 链：`mov eax,fs:[0]` 14 / `mov fs:[0],esp` 15 / `push dword fs:[0]` 1 / `mov fs:[0],eax` **0**；
      「取链头→挂帧」距离 <64 B 的成对点 **15**，落在 **6 个** HB 函数 ⇒ **6/17766 = 0.03%**。
    - C++ EH：magic 0x19930520/21/22/10 对齐命中 2 处，仅 **1 处**满足完整 FuncInfo 形态（`0x87c1d0` 在 `.data`）；
      另一处 `0x7f993c` 后面紧跟星期字符串 `4d6e7553`（"SunM"），`.text` 那处周边全是立即数 ⇒ 均判**字节巧合**。
    - `.text` 中指向该唯一 FuncInfo 的立即数引用 **3 条**（0x7cb3a6 / 0x7cc1ab / 0x7cc1b4）。
    三者都给不出量级 ⇒ **只有一套现成边界（HB）**。这不是「没找到」，是「三条路都算过、都不成立」。

EL7. 🔴 **纠错：R109 的位移正则使 disp 恒为 0 —— 总数凑巧对，分类全错**
    `r109a_attr.py` / `r109e_container.py` / `r109f_vtmodel.py` 共用
    `^(?:dword ptr )?\[([a-z0-9+* ]+)\](?: \+ (0x[0-9a-f]+))?, (0x[0-9a-f]+)$`。
    字符类含空格与 `+`，贪婪把 `"esi + 0x15c"` 整段吞进 group(1) ⇒ group(2) 恒 None ⇒ **disp 恒 0**。
    （4611 条装配点里 group(1) 含空格的 5131 条，含全部写入点形态。）
    正确分桶：裸寄存器基址 **4271**（其中 disp==0 的 **2774**、disp≠0 的 **1497**）+ 绝对地址 `[0x87e73c]` **340**
    + 负位移 `[eax-8]` **5** = **4616**；R109 报 4611 = 4616 − 5（旧正则字符类不含 `-`）。
    注意 R109 的「写偏移 0 = 2762」与本轮 disp==0 的 **2774** 差 12 条 `[esp], vt`，口径不同不可混用。
    **总数只差 5，但「2762 / 非 0 偏移 1849」是假二分** —— 1849 里混着 1497 条真 this 内偏移
    与 340 条全局对象写入，语义完全不同。
    受污染结论：「写 `[reg+0]`=vt 后同 reg 又被 `[reg+disp≠0]` 读 = 1304/2438（53.5%）」
    → 正确（正确正则 + HB 边界）**1478/1637 = 90.3%**，反控富集 7.1 倍。
    **方向不变、结论加强**；引 §EK4④ 必须改用新数或引本节。
