## §3 🔴 两块 9056 B 数据块完全同一（本轮结构主证）

- 块1 = `[0x8759b4, 0x877d14)`，块2 = `[0x879b30, 0x87be90)`，各 **9056 B**，**逐字节相同**（D 5696 + S 2848 + A 256 + B 256 = 9056）
- 块间空隙 `[0x877d14, 0x879b30)` 共 **7708 B**，**全 `0x00`**
- 块1 之后 `0x877d14` 起 16 B 全 0；块2 之后 `0x87be90` 起为 `94957f0000000000 2e3f415674797065`（`.` 起 `?AVtype_` = RTTI 名字串）

- ⇒ 这**不是两个不同的表**，是**同一套 ADPCM 解码常量表被整块复制两份**，各自配一个同构解码器（见 §5）；R220 只发现了 `0x87b170` 一侧

## §4 🔴 律 D / 律 S 双双 1424/1424 闭合（推翻 R220「余 22 块未解」）

索引口径（本轮新证）：**字节偏移 `S = 32m | 2n`**，`m`=0..88（step 下标）、`n`=0..15（nibble）。

- **律 D（差分表，1424×int32）**：`dword[16m+n] = ±( (s>>3) + [n&4]s + [n&2](s>>1) + [n&1](s>>2) )`，`s = IMA[m]`，`n>=8` 取负
  ⇒ **1424 / 1424 命中，0 残留**
- **律 S（状态表，1424×uint16）**：`word[16m+n] = 32 * clamp(m + ADJ[n&7], 0, 88)`，`ADJ = (-1,-1,-1,-1,2,4,6,8)`
  ⇒ **1424 / 1424 命中，0 残留**；`min=0 / max=2816(=32×88) / 全部 32 的倍数`
- 两副本同值：律 S @ `0x876ff4` = 1424/1424；律 D @ `0x8759b4` = 1424/1424

### R220「floor(s·(2i+1)/8) 只命中 44/89 块、余 22 块未解」的定性：**口径错，不是数据缺失**

R220 用的口径是 `floor(s·(2a+1)/8)`（整体乘除）。逐式核对：

- floor 式在差分表命中 **1020 / 1424**，移位式命中 **1424 / 1424** ⇒ 表是移位式生成的
- floor 式**精确的块数 = 44 / 89**，与 R220 记的 44 **一致**（其数字没算错，是**口径不对**）
- 精确性判据（代数证明，非拟合）：设 `s = 8q + r`，`2a+1 = 1 + 8[a≥4] + 4[(a>>1)&1] + 2[a&1]`，故两式相等 ⟺
  `floor(r(2a+1)/8) == [a≥4]r + [(a>>1)&1](r>>1) + [a&1](r>>2)` 对全部 8 个 `a` 成立
  ⟺ **`r = s%8 ∈ {0,1,2,4}`**。实测该判据与「逐块 8 项全等」**89/89 判决一致**
- 失配 residue 分布：`r=3` **11** 块 / `r=5` **10** / `r=6` **13** / `r=7` **11**，合计 **45** 块 = 89 − 44
- ⇒ R220 待办①「余 22 块的舍入口径」**关闭**：不存在 22 块残差，全部 89 块在移位式下精确。R220 的「22」是 floor 式下 89−67 的放宽口径余数，与移位式无关

## §5 🔴 打包索引 `S = 32m | 2n` 的结构性证明

| 证 | 内容 |
|---|---|
| D1 | `32m \| 2n == 32m + 2n` 对全部 m<89, n<16 成立（OR 拼接无进位冲突） |
| D2 | 反控：`33m \| 2n` 会进位冲突 ⇒ 乘数 **32 是结构性必需**，不是巧合 |
| D3 | 字节偏移 S 用于 **word** 表 ⇒ 字索引 `S/2 = 16m+n` |
| D4 | 字节偏移 2S 用于 **dword** 表 ⇒ dword 索引 `2S/4 = 16m+n` |
| D5 | 状态表值 `32m` 的**低 5 位恒 0** ⇒ `or dl, 2n` 写入不破坏 m 部 |
| D6 | `2n` 占 bits1..4 且 n≤15 ⇒ OR 后回读 `m=S>>5`, `n=(S>>1)&15` 唯一 |

指令级证据：解码器 `mov eax, dword ptr [ebx]`（+0）、`mov dx, word ptr [ebx+4]`（+4）读出 `S`，
`or dl, byte ptr [ebx+0x87bc90]` / `[ebx+0x87bd90]` 写回 `S` 的 bit1..4；
`0x7c75b4 pop ecx / 0x7c75b5 shr ecx,1 / 0x7c75b7 and ecx,7 / 0x7c75ba jmp [ecx*4+0x7c7758]`（8 分支 nibble 取值）。

## §6 🔴 双解码器 `0x7c6808`（块1）vs `0x7c7428`（块2）：逐字节差 = 纯表地址重定位

- 长度 **428 / 427 B**，差分段 **26** 个
- **25 个 2 字节段** = 4 组表地址重定位，计数 **8/8/4/4**：
  `0x59b4→0x9b30`(8) / `0x6ff4→0xb170`(8) / `0x7b14→0xbc90`(4) / `0x7c14→0xbd90`(4)
- 第 **25** 个 2 字节段是**跳转表地址** `0x6b38→0x7758`；其偏移 **0xc20** 恰等于**函数体偏移** `0x7c7428−0x7c6808 = 0xc20`
- **1 个 15 字节段**（`0x7c69a4` vs `0x7c77bd`）= 尾声不同：块1 版 `5b5d89431466895322 8b450c 5a595b5f5ec9c3`（写回状态），块2 版 `8d4900 83ed0c 55…`（进下一条对齐分支）
- **跳转表两两逐项差 0xc20**（8/8 项），即两表也是同一套
- 归属：块1 解码器引用块1 表 **8+8+7+8**（D/S/A/B），块2 解码器引用块2 表 **24+24+21+24**；**交叉引用 0 条**

## §7 抖动表语义（R220 只记了「第 r 行全 2r」）

| 表 | 字节律 | 半字节出口 |
|---|---|---|
| A = `0x87bc90` | `A[i] == 2*(i & 15)` 256/256 | **低半字节**（decoder `mov bl, cl`） |
| B = `0x87bd90` | `B[i] == 2*(i >> 4)` 256/256 | **高半字节**（decoder `shr ecx,0x10` / `mov bl,ch`） |

- `B == A 转置`，`A != B`，逐项差 **240/256**（对角 16 项相同）
- ⇒ 不是「一张表 16×16 第 r 行全 2r」，是**一对互为转置的表，分别按低/高 nibble 索引**
