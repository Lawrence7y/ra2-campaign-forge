EG5. ✅ **A2：19 张表分两种 idiom，两种都被字节实测确认**（本段第一版判据 9/19 FAIL，是判据错）：
- **两级形态 10 张**：`cmp k,BOUND / ja default / xor r,r / mov rl,[k+BYTETAB] / jmp [rl*4+TAB]`。
  BYTETAB **恰好紧贴 DWORD 表尾**（== base+4n）10/10；表内每个字节值 **< n** 10/10；
  BOUND+1 个输入压缩映射到 <= n 个目标（有重复）10/10。这是 MSVC 压缩跳转表的固定布局。
- **直接形态 9 张**：`cmp k,BOUND / ja default / jmp [k*4+TAB]`，BOUND == n-1 **9/9**。
自错 1：第一版断言「多数持有指令前是 cmp 同一索引寄存器 + jcc」得 9/19 FAIL。
逐窗口打印确认是判据错：两级形态里被 cmp 的是输入值 k、jmp 用的是从字节表加载的压缩下标 rl，
两者结构性不可能相同。改按形态分类后 19/19 全部有界，且保留 N3 反控（去掉同寄存器约束后 19/19 > 9/19）。

EG12. 📌 **本轮新增的可复用判据（建议进纪律）**
1. 判「表项是代码还是数据」**不得**用 prologue 形态、也不得用「前一条单元是 ret/jmp」——
   对 case 标签与函数入口两者都不成立判别，实测 275/292 是噪声（EG2）。
2. 正确闭环 = 合法单元起点 + 前向性 + 经分派可达；「无 call 直引」**只能当伴随事实**。
3. 归属某项到某表必须**按字节区间**判，不得先做 DWORD 对齐过滤（EG3，3 个宿主非对齐）。
4. 报「拒解/invalid」数必须分开「在 ip 集合里」与「is_invalid == True」两个集合
   （EG8④ 连续两轮栽在同一地址的根因）。
5. **任何「0 个命中」型结论必须附零假设 P 值**；基率小、样本有限时「0 个」常完全不显著
   （本轮 P=0.62）。把它写成「强证据」是统计错，与口径错同族。
