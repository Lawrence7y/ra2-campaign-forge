[0] 结论摘要
1. **F2 主因 = C1（第二段乘性压暗），且第二段不在我们这边：实测落像素 = 「先 ×0.71875（184/256 = 23/32）再 ×0.5」**，合成 **0.359375 = 23/64**（设计口径本应只有 0.5）；三通道中位比值 0.3333/0.3438/0.3333 与 0.324/0.335/0.316 同族。
2. 设计口径 `s=256 ⇒ 逐通道精确 ⌊c/2⌋` 代数成立（桩字节级）；但按该式复算仅吻合 0.29%/0.14%/4.52% 像素 ⇒ **「一次 s=256」已被实测决定性否定**。
3. **C2（黑幕边缘帧）否定**：引擎黑幕像素算子是覆盖式 `dst:=瓦片字节`，且我方对 0x47EFE0 只计数后原样放行，两档都画 ⇒ 比值中抵消。**C3（frame=15 满菱形）只解释均匀性，不解释 1/3 与 1/2 之差**。
4. 最大风险：第二段的**代码位置未静态定位**（DLL 内已穷举：无 184/72/23/41 立即数 imul、无 0x7BEF 掩码变体、无整字算术、非位掩码型）；其 ~20% 非函数性指向**调色板/地表层缩放**。已给 3 个真机判别实验（[F5]）。

## F1 · 数值链路（算式，逐处 ≤3 行 + 锚点）
1. ini `EnableStarCraftFog=1`（ra2youli/ra2render.ini:33）→ DLL 门 `[0x1002200b]`（Hook 内 RVA 0x2225 判定；=0 ⇒ 不画雾，日志「跳过压暗」）。
2. Hook_CellClass_Draw（DLL RVA 0x2110，替换 CellClass::Draw）：0x2192 读 Shroudedness[cell+0x120]，0xFE=未探索→放行；0x21A6-0x21AF 格索引 `esi=(y<<9)+x`。
3. 每格强度 `s`（0x21B1-0x2223）：非渐变档 `s=cl<<8∈{0,256}`；渐变档 `al=[cell+0x102a2A28]` ⇒ `s=48·al`（0x21E2-0x21E5）或 `s=(5-al)·64`（0x21F2-0x220F，钳 ≤0x100）。
4. 写强度 0x2256 → **每格每帧 1 次** `Draw_Fog(0x47F250, cell, x, y, frame=0x0F)`（0x226E/0x2276/0x227B）→ 恢复 256（0x227D/0x2282）。
5. 桩（DLL 0x2310/0x23B0 取代 exe 0x47F40F(49B)/0x47F4AE(51B)）：`c50=(c>>1)&0x7BEF`；`delta=c−c50`（逐通道 ⌈c_ch/2⌉）；`t_ch=(delta_ch·s)>>8`；`out_ch=c_ch−t_ch`。
6. ⇒ **s=256：out_ch=c_ch−⌈c_ch/2⌉=⌊c_ch/2⌋（逐通道精确 50%，设计口径成立）**；s 的**单次上限 50%**（s≤256）或 `s=48·al`。
7. 实测链路（决定性与设计口径不符）：`S1_ch ≈ ⌊⌊S2_ch·184/256⌋/2⌋` ⇒ 合成 **×0.359375**；即**地表先被 ×0.71875，我们的 0.5 在其后**。

## F3 · 反推校验（判据核心）
- 取亮雾区（S2 亮度≥110，n=80,780/通道）逐像素 565 索引对拍：`⌊c/2⌋`（设计）R 0.29% / G 0.14% / B 4.52%；`⌊⌊c·184/256⌋/2⌋` R 82.5% / G 74.9% / B 75.2%；`⌊c·92/256⌋` 同分。
- 中位比值口径：R 0.3333 / G 0.3438 / B 0.3333（floor 结构使中位略低于 0.359375），与卡片 0.324/0.335/0.316 同族 ⇒ 一致。
- 排他表（逐通道吻合率）：单次 0.5 = 0.017；0.5²(两级 256,256) = 0.057；两级 (256,192) = 0.457、(256,176) = 0.624、(256,144) = 0.359；**直接乘性 ⌊⌊c·184/256⌋/2⌋ = 0.775** ⇒ 同时排除 0.5、0.5² 与一切两级桩组合，且第一段形状为**直接乘性缩放**。
- 结论：**预测值与实测在「先 ×0.71875 再半分」下吻合、在「设计单段」下不吻合**；差额因子 0.5/0.359375 = 1.391。

## F4 · 校准方案设计（不实现）
- 目标：`s=256` ⇒ 实测 0.50±0.03。总因子需 ×1.391。
- 方案 A（一处改动，兜底）：写强度时 `s' = round(s·1.391)`（s=256⇒356），落在桩公式内；代价是桩的 ⌈⌉ 结构与实测 map 有 ±1 档差。
- 方案 B（推荐，先定位）：在雾区**抵消/关闭第一段 ×0.71875**（保持 s=256），保形；需先完成 [4] 的定位。
- 键：`FogStrengthPct=0..100`（新键）；**默认 71.875（=184/256）**⇒ 输出等价现网 0.359375，「默认不改观感」；`=50` 目标 0.50。
- 影响面：方案 A/B 都不改未探索黑幕与直视档；渐变帧（48·al、(5−al)·64）在两方案下都要逐档回归；不触及 MP 同步/存档。

## F5 · 真机判别实验（交 ZCode，≤3）
1. **应用次数探针**：在 DLL 0x2256（写强度）与 0x231D（桩介入）旁各挂一次性计数，按「每格每帧」汇总 ⇒ 若 `桩介入/格 · 帧` 恒 ≈ 844（=菱形面积）则单次应用成立、第二段必为另一次「地表级」压暗；若 ≈1.7k 则第二段是同像素二次桩。
2. **强度阶梯**：`s=256→128` 各跑 1 档（同场景同镜头）⇒ 若比值 0.326→≈0.48（=0.71875×0.75）说明第一段与 s 无关（固定乘子）；若 →≈0.24 说明两次相乘。
3. **纯白底单点**：对已知纯白地表/白建筑外框取样 S1 像素 ⇒ 设计单次 565 展开期望 ≈123/126/123；两段式期望 ≈89/92/89。一次截图定谳。
