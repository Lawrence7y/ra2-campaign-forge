### 1.1 拆卡原则

1. **按环境前提聚类**：同硬件前提的条目进同一卡，避免重复搭台（如 N14/N15/N01 共享 NETCOND 注入场次）。

3. **双机卡默认双端同补丁**：除索引显式授权的混联探针（B-N11，在 B5 ZB5-M01）外，SOLO 双机场**双端同镜像同种子**，不混端。
4. **Top10 优先**：★B-L11 在 ZB-S10 内标 `★`，执行序优先于同卡 B-M11。
5. **收尾统一动作**：每卡结束检 `except.txt` 0 字节；回执按 `AGENT_DELIVERY_FORMAT`；**禁写「已实测」/「MP 可发布」**。

### 3.2 边界红线

1. **混联唯一授权**：仅 B-N11（ZB5-M01）允许「诊断镜像 vs 原版」混联探针。SOLO 双机卡（S07/S09）**双端同镜像**，发现混端立即停。
2. **SYNC 裁决权**：SOLO 场次若出现 `SYNC*.TXT` / OOS，只**记录时间戳与文件名**交 B5 对拍面裁决；SOLO 回执不写「通过/失败同步」。
3. **MP 发布宣称**：SOLO 与 B5 全程 **G-R5 禁写「MP 可发布」**；MP 发布宣称仍以 **G-R1 裁决为唯一门**。
4. **DUAL-LAN 预约错开**：S07/S09 与 ZB5-M01/M02/M04 共用双机台，排期互斥；建议顺序 `ZB5-M01 → ZB5-M02 → ZB-S07 → ZB-S09 → ZB5-M04`（或并行但分时段）。
5. **B-N06 / B-L11 样本锚点**：B-N06↔B-03、B-L11↔B-06 对照关系不变；断点习惯可复用 ZC-RE1 调试器段 A，但不断言其为 B5 内容。
6. **证据纪律**：本票与 B5 均不得写「已实测」；真机回执另出，按 `AGENT_DELIVERY_FORMAT`。
