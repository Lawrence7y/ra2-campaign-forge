## [0] 结论摘要（≤8 行）

1. **8-bit 合成顺序定谳**[实证]：`Pal[j] → RGB2HSV(0x6613A0) 保 H,S → V'=(V·k·2)//(S−1) 存 al（8-bit 截断）→ HSV2RGB(0x517440) → NN(0x626200) → BufferA[k*256+j]=index`。与 16-bit 路径（`factor=k·0x20000/(S−1)` 三通道线性）**根本不同**。
2. **量化 ABI**[实证]：`0x626200` stdcall（`ecx=pal base 256×3`，`[esp+4]=RGB*`，`ret 4`，返回 eax=index）；距离 `0x661350` = **加权 L1 `2·dR+4·dG+3·dB`**（非欧氏）；并列**取先**（`jge` 不替换）。全库 6 处调用均在表生成期。
3. **暗端抬升闭式**[实证·可复算]：调色板暗端有空隙（黑→下一档 v≥28）时，缩放后 V 落入空隙，NN **向上吸附**。灰阶仿真暗带（v≤64）`lift_ratio=23.1%`，`mean_eff_gain=0.767`（> 名义 0.731），最大 **+8 luma**；中/亮带 lift=0。
4. **桥面更亮闭式**[实证·可复算]：亮暖色（桥/木）V 缩放后 NN 落点 **≥ 理想缩放**（`eff_vs_ideal=1.01..1.03`），相对纯 ×0.7308 **+0.7..+2.9 luma**。加权 L1 中 **R 权最低(2)**，暖色更易吸附到更亮暖档。
5. **与 0.71875 残差表**[实证]：切片最佳 **k=19，gain=0.730769，abs_res=+0.012019（+1.672%）**；k=18 −3.679%；精确 23/32 需 `64k=23(S−1)`，S=53 无解。8-bit 合成暗带 `mean_res8=+0.0286`，16-bit `mean_res16=−0.003`（16-bit 更贴名义但均**非** 0）。
6. **V 溢出**[实证]：`mov [mem],al` 仅存低 8 位；k≥27 且 V>127 时 `V'=2kV/(S−1)` 回绕（k=52,V=255 → 存 254）。**k=19 安全**（max V'=186）。
7. **残差归属**[推演]：0.71875 = **k=19 切片地板 + 暗端 NN 抬升 + 亮端 NN 微抬** 的经验合成，非字面常数。16-bit 像素环无 NN，C11 **仅 8-bit 路径存活**（继承 R-BUFFERA §4.2）。
8. **最小 dump**[待实测]：`BytesPerPixel(+0x04)` 1 B 判路径 + THEATER_PAL 768 B + BufferA 全表（8-bit 13,568 B / 16-bit 27,136 B）重点切片 k=18/19/20/26 + 像素环 256 组。**离线用 dump 的 pal 即可复算 BufferA 全表**。

## [2] 量化 ABI 与合成顺序

### 2.1 8-bit 路径合成顺序 [实证]（ctor `0x48EA51–0x48EB10`）

```
for k = 0 .. S-1:
  BufferA[k*256 + 0] = 0
  for j = 1 .. 255:
    (R,G,B) = Pal[j]
    (H,Sat,V) = 0x6613A0(R,G,B)        ; 保 H,S
    q        = (V_byte * k * 2) / (S-1) ; idiv，截断
    V'       = q & 0xFF                 ; ★ mov [mem], al
    (R',G',B') = 0x517440(H, Sat, V')
    idx      = 0x626200(Pal, (R',G',B'))
    BufferA[k*256 + j] = idx            ; BYTE
```

**与 16-bit 对照**（`0x4BBB00`，勿混）：

| | 8-bit 路径 | 16-bit 路径 |
|--|-----------|------------|
| 缩放域 | **仅 V（HSV 明度）** | R,G,B 三通道 |
| 因子 | `2k/(S−1)` 作用于 V 字节 | `factor=k·0x20000/(S−1)`，`chan·factor>>16` |
| 量化 | **调色板 NN（加权 L1）** | pack 565/555（运行期掩码） |
| 表项 | BYTE 索引 | WORD 像素 |
| stride | 256 B/slice | 512 B/slice |

S=1 另支：`BufferB=new(0x100)`（`V>>=1` 后 NN），BufferA 填恒等。

### 2.2 `0x626200` / `0x661350` ABI [实证]

```
; 0x626200  stdcall  ret 4
;   ecx = palette base (256 × 3 bytes RGB)
;   [esp+4] = target RGB* (3 bytes)
;   eax = best index
;   并列取先：cmp eax,esi; jge skip  → 严格 < 才替换

; 0x661350  距离
;   lea ecx,[esi+edx*2]      ; |dR| + 2|dG|
;   lea edx,[eax+eax*2]      ; 3|dB|
;   lea eax,[edx+ecx*2]      ; 2|dR| + 4|dG| + 3|dB|
```

调用点 6 处：ctor 8-bit 路径 3（`0x48E9C9/0x48EA3B/0x48EAE3`）+ 调色板转换簇 3（`0x4C39D7/0x4C3B30/0x4C3BD4`）。**均不在 DrawTile/DrawSHP 像素环**（继承，不重复论证）。

### 2.3 闭式（8-bit 一条表项）

```
V'   = ((V_byte · 2k) / (S-1)) mod 256          ; 截断 + al 回绕
RGB* = HSV2RGB( H(Pal[j]), Sat(Pal[j]), V'/255 )
BufferA_8[k][j] = argmin_i  ( 2|R_i−R*| + 4|G_i−G*| + 3|B_i−B*| )
                  并列取最小 i
```

k=19, S=53：名义增益 `2·19/52 = 0.730769`（作用于 V）。

## [3] 暗端抬升 / 桥面更亮

### 3.1 暗端抬升（C11 机制定量）[实证·可复算]

**条件**：调色板暗端存在空隙（黑之后下一档 v≥28，RA2 theater 常见）。

**机制**：缩放后 `V'≈0.73·V` 落入空隙 → NN 无法命中真黑附近 → **吸附到更亮档**。

| 带（灰阶输入 v） | n | mean_eff_gain | mean(NN−ideal) | max | lift_ratio |
|---:|---:|---:|---:|---:|---:|
| 0–64 暗 | 39 | **0.767** | **+1.44** | **+8** | **23.1%** |
| 65–160 中 | 102 | 0.726 | 0 | 0 | 0 |
| 161–255 亮 | 114 | 0.728 | 0 | 0 | 0 |

暗带 `mean_eff_gain` **高于**名义 0.731 与目标 0.719 ⇒ 与 ZC-9B「暗像素变亮」同向。theater-like 暗带 `mean_eff8=0.747` vs `mean_eff16=0.716`，`max_abs_res8=0.35`（个别色被吸到远档）。

### 3.2 桥面更亮（亮暖色 NN 微抬）[实证·可复算]

桥面/木纹 = 高 R 中 G 低 B。V 缩放后 NN：

| 样本 | eff_vs_in | eff_vs_ideal | NN−ideal | 相对纯乘抬升 |
|---|---:|---:|---:|---:|
| (200,180,140) | 0.735 | **1.008** | +1.0 | +0.7 |
| (170,150,110) | 0.751 | **1.032** | +3.3 | **+2.9** |
| (180,160,120) | 0.744 | 1.024 | +2.7 | +2.0 |
| (220,200,160) | 0.736 | 1.014 | +2.0 | +1.1 |

**恒 ≥ 理想缩放**（亮暖 8/8）。加权 L1 **R 权=2 最低、G=4、B=3**：暖色目标在 R 维误差代价低，更容易吸附到更亮的暖档。

**边界（勿越权）**：NN 解释的是「相对纯 ×0.7308 的亮端微抬 / 暗端抬升」。ZC-9B 的 BRIDGE 跨 s 反向（s=256 比 s=0 亮）属**向灰混合层**（M1/M4），本卡**不**用 NN 重开常数 k/向灰之争（已另案）。

### 3.3 加权方向敏感性 [推演]

`2dR+4dG+3dB` 对 G 最敏感、R 最迟钝。同亮度下：
- 暖色（R 主导）→ 容差大 → 更易被亮档吸走 → **桥面/亮端微抬**
- 冷色（B 主导）→ 介于两者；暗冷色在空隙区仍可抬（样本 max +5.6 luma over multiply）

## [4] 残差表

### 4.1 切片增益 vs 23/32 [实证·可复算]（S=53）

| k | gain | abs_res | rel |
|---:|---:|---:|---:|
| 18 | 0.692308 | 0.026442 | −3.679% |
| **19** | **0.730769** | **+0.012019** | **+1.672%** |
| 26（Midpoint） | 1.000000 | 0.281250 | +39.1% |
| 精确解 | 0.718750 | 0 | 0（需 S∈{65,129,193,257}） |

**S=53 可达域内最小残差 = +0.012019（k=19）**。无整数切片 = 23/32。

### 4.2 合成有效增益分带（theater-like，k=19）[实证·可复算]

| 带 | n | mean_eff8 | mean_eff16 | mean_res8 | mean_res16 | max\|res8\| | max\|res16\| |
|---|---:|---:|---:|---:|---:|---:|---:|
| 暗 0–50 | 39 | 0.7473 | 0.7158 | **+0.0286** | −0.0030 | **0.3527** | 0.0188 |
| 中 50–140 | 146 | 0.7276 | 0.7248 | +0.0088 | +0.0060 | 0.0737 | 0.0114 |
| 亮 140–256 | 62 | 0.7284 | 0.7278 | +0.0097 | +0.0091 | 0.0395 | 0.0119 |

- 8-bit 路径残差**随亮度强变化**（暗带 max 0.35），正是 NN 吸附签名。
- 16-bit 路径残差小且均匀（**继承结论：565 量化不收敛到 0.71875，反而把均值拉低**）。
- 两条路径**都锁不死** 0.71875；0.71875 是 k=19 地板 + NN 修正后的**经验等效**。

### 4.3 V 回绕表（8-bit 路径缺陷）[实证]

| k | V | q=(V·2k)/52 | al 存 | 回绕 |
|---:|---:|---:|---:|---|
| 19 | 255 | 186 | 186 | 否（安全） |
| 27 | 255 | 264 | **8** | **是** |
| 52 | 255 | 510 | **254** | **是** |

k≥27 且 V>127 时 V' 回绕（46 组）。雾切片 k=19 不受影响；但**高位切片表项不可信**，dump 解读须带此约束。
