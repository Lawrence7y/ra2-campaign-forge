## 2. 装到 ra2youli（BATTLEMD C2-b 优先）

### 2.1 C2-b 主路径（推荐：导航坐标稳定）

| 步 | 动作 | 命令/要点 | 留证 |
|---|---|---|---|
| I1 | 备份 `BATTLEMD.INI` | 复制为 `ra2youli\BATTLEMD.INI.pre_a3`（或 `out/.../R_a3_install/instr/BATTLEMD.INI.pre_a3`） | sha256 + 字节数 |
| I2 | 部署地图 | 复制 `build\ECHGAP.MAP` → `ra2youli\ECHGAP.MAP`（游戏目录已有同名则先备份为 `.pre_a3`） | 部署后 sha256 == 金样 |
| I3 | 改一行 | 散装 `BATTLEMD.INI` 中 `[SOV1]` 节 `Scenario=ECH01.MAP` → `Scenario=ECHGAP.MAP`（只此一行；`Description=DESC:SOV1` 等勿动） | 改后全文 diff = 1 行 |
| I4 | 校验片段 | 对照 `build\ECHGAP.battlemd.C2-b.patch.txt`（红线：不占 `[Battles] 1..14`、不占 `ALL*/SOV*` 条目名、`expandmd98.mix` 0 个 INI） | 片段头红线过目 |
| I5 | 图面自检 | `python out/re_work/re_sprint/R_a3_impl/a3_map_gen.py --check-only --design out/re_work/re_sprint/R_a3_impl/a3_map_design.default.json`（或对已部署副本） | `check.json` V01–V15 全 PASS |

变体选择：验收 P-2.2 雷达面用 **`ECHGAP.MAP`（full）**；只验 P-2.1 且要避开 SpySat 在线路径时用 **`ECHGAP_NR.MAP`（nr）**，I2/I3 同步改为该文件名。

### 2.2 C2-a 备选（`--calib-nav` 通过后可迁）

1. 不改官方 `BATTLEMD.INI`；新建散装 `ra2youli\BATTLEMD98.INI` 追加（或合并进现有文件）：
   ```ini
   [Battles]
   16=GAPA3

   [GAPA3]
   CD=2
   Scenario=ECHGAP.MAP
   FinalMovie=
   Description=ZC-GAP-P21-A3 裂缝验收（单关）
   ```
2. ID 跨包唯一（现 `BATTLEMD98.INI` 已占 `15=RA2F1`）；禁 `1..14` / 纯数字 / `ALL*` / `SOV*`（V14）。
3. 风险：海报屏多一条可能分页/DebugOnly 过滤 → 导航坐标需重校（`--calib-nav`）。

### 2.3 ra2forge 安装能力（包路径备选，C2-a 同族）

> 只引用 `ra2forge/install.py` 契约，**不改其源**。适合整包战役（`BATTLEMD98.INI` + `*.MAP` + `expandmd98.mix`）。

```powershell
# 装（包目录需含 BATTLEMD98.INI；*.MAP 散装；expandmd98.mix 仅资源）
python -m ra2forge install --package <package_dir> --game D:\Project\ra2-campaign-forge\ra2youli

# 卸（按 ra2forge_install.json 还原备份；sha 不匹配的文件默认保留）
python -m ra2forge uninstall --game D:\Project\ra2-campaign-forge\ra2youli
# 旧版残留：python -m ra2forge uninstall --game <dir> --legacy
```

契约要点：被替换文件先落 `*.ra2forge.bak`；清单写 `ra2forge_install.json`；备份槽不二次覆盖（最旧原件优先）；**永不写官方 `BATTLEMD.INI`**（战役注册只认散装 `BATTLEMD*.INI`，MIX 内不加载）。C2-b 单关验收**不必**走此路径。

### 2.4 补丁开关（同图 A/B）

`ra2render.ini` `[FogOfWar]` 节写 `EnableGapProtection=0|1`（缺键插到节头后）。harness `--run` 内置写入/还原；手工装图时勿用末尾追加。`gamemd.exe` 全程只读。

## 4. Harness 启动（`gap_p21_a3_campaign.py`）

工作目录：`D:\Project\ra2-campaign-forge`。产物/证据：`out/re_work/zcode_live/gap_p21_a3/`（`instr/`、`shots/`、`cells_*.json`、`run_*.json`）。

```powershell
# 0) 地图与 mapreport 就绪（与 build/ 金样对拍）
python out/re_work/zcode_live/gap_p21_a3/gap_p21_a3_gen.py

# 1) 导航 / 暂停菜单校准（必跑；审 shots/ 后填 ui_calib.json 的 save/load 坐标）
python out/re_work/zcode_live/gap_p21_a3/gap_p21_a3_campaign.py --calib-nav   --tag calibnav1
python out/re_work/zcode_live/gap_p21_a3/gap_p21_a3_campaign.py --calib-pause --tag calibpause1

# 2) A/B 两档完整跑局（内置：插桩 C2-b + 开关 + 装图 → 进战役 → before → 开图 → after/after2 → A4 存读档 → A5 长时 → 还原）
python out/re_work/zcode_live/gap_p21_a3/gap_p21_a3_campaign.py --run --profile off --tag r1off
python out/re_work/zcode_live/gap_p21_a3/gap_p21_a3_campaign.py --run --profile on  --tag r2on
# 变体：--variant full|nr|auto（auto 按 mapreport 选）

# 3) 兜底还原与对拍
python out/re_work/zcode_live/gap_p21_a3/gap_p21_a3_campaign.py --restore
```

插桩契约（`--run` 内置，`instr/` 留证）：`BATTLEMD.INI` 只改 `[SOV1] Scenario=` 一行；`ra2render.ini` 节内写开关；`ECHGAP*.MAP` 部署前查同名、收尾移除；`gamemd.exe` preflight/收尾各验 sha256；每档末强杀游戏。

菜单导航基线（已实证）：主菜单(700,218)→单人游戏→新战役→海报屏→苏联锤子(320,430)→简报/电影。走 C2-b 不新增条目 ⇒ 坐标不变。

## 5. 验收勾选

> 逻辑计数为主、截图像素为辅；**「没崩」≠成功**（C-J5）。verdict 词表：`PATCH-WORKS` | `GAP-WIPED` | `NO-GAP-DETECTED`。

### 5.1 安装面

- [ ] A-1 产物 `ECHGAP.MAP` sha256 == 金样 `fc49b149…`（或 NR `b6d43d7c…`）
- [ ] A-2 `*.check.json` V01–V15 全 PASS
- [ ] A-3 备份 `BATTLEMD.INI.pre_a3` 已落且 sha256 记录在案
- [ ] A-4 C2-b 改后 diff 仅 `[SOV1] Scenario=` 一行；`[Battles] 1..14` 与 `ALL*/SOV*` 条目名未动
- [ ] A-5 注册前后 `BATTLEMD*` 清单 diff（文件名/大小/sha256/`[Battles]` 行）已留证
- [ ] A-6 `gamemd.exe` sha256 == 基线（跑前跑后）

### 5.2 行为面（harness `--run`）

- [ ] **C-J1 缝在**：before `gap_cells>0` 且目标格 `+0x134≥1`；`bld_cells>0` 反证 B-1 已绕
- [ ] 触发器活体：t≈20s TA11 文本「PROBE: trigger alive」截图
- [ ] **C-J2 缝仍在**：after/after2 目标格 `+0x134` 不清 0（on 档 kept≈100%）
- [ ] **C-J3 对照**：off 档同图同路径出现 `GAP-WIPED`（被开图格归 0）——无对照不判 PASS
- [ ] **C-J4 视觉**（辅助）：before/after2 PNG md5 互异；扫描退去后回黑雾/缝层
- [ ] **C-J5**：`except.txt` 无本次新增 **且** C-J2 成立

### 5.3 A4 / A5（同图同局）

- [ ] **A4-J1**：存 `.SAV` → 读档 → 目标格 `+0x134` 逐格一致（kept=100%）
- [ ] **A4-J2**：`except.txt` 空；`gap_cells` 与存档前同量级
- [ ] **A5**：长时抽样（含 Reshroud 旁路 `0x50BD20`/`0x481FC3` 面）各时点 `+0x134` 未清零；off 档对照

### 5.4 收尾

- [ ] `--restore` 后 `BATTLEMD.INI` / `ra2render.ini` `byte_identical=true`
- [ ] 验收图已从游戏目录移除（或明确留存并记录）
- [ ] 证据齐全：`instr/` + `shots/` + `cells_*.json` + `run_*.json` + mapreport

## 6. 风险与红线

| ID | 风险 | 控制 |
|---|---|---|
| R-1 | 动官方 `BATTLEMD.INI` 超出一行 | C2-b diff 门禁 + 还原对拍；越界即停 |
