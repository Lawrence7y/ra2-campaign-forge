# 子代理交付回报格式规范（强制）
# Mandatory Delivery Report Format for All Delegated Agents

> 适用对象：**全部**被委派的执行方 —— Antigravity(agy)、DSH 子代理、MiMo 桌面、以及任何后续新增执行方。
> 维护：Lead。凡派工提示词**必须**附带本规范（可只附 §A 回执骨架），执行方的最终答复**必须**逐节填写。
> 生效日期：2026-09-27（v1）。

---

## A. 回执骨架（执行方必须按此顺序输出，缺节即视为交付不合格）

```text
[META]
task=<任务号>  executor=<执行方名/会话ID>  elapsed=<秒>  mode=<read-only|accept-edits>
scope_declared=<提示词给定的写作用域>

[0] 结论摘要（≤5 行，必须能独立读懂：做了什么、成立的核心结论、最大风险）

[1] 逐条必答项结论表（每个提问一行）
| # | 问题 | 结论 | 证据等级 | 证据锚点 |
证据等级只用三档：[实证]（VA+FileOffset+原始字节+反汇编+xref）/ [推演] / [待实测]
证据锚点必须给 文件:行 或 VA，禁止只写“见文档”

[2] 关键证据块（每条：VA / FileOffset / 原始字节 / Capstone 反汇编 / xref 来源）
机器可读断言写入 claims.txt，格式固定：0xVA = HEXBYTES # 注释

[3] 勘误（对任何既有文档/结论的更正，逐条给）
目标文件:行号 | 改前原文 | 改后文本 | 理由 | 影响面（是否影响产品决策/其他文档）
若无勘误，必须显式写“无勘误”；禁止把勘误藏在正文里

[4] 未闭环清单
每条给：缺口 | 为何无法静态闭环 | 下一步取证方法（可直接执行的命令/断点/地址） | 阻塞级别(P0/P1/P2)
无未闭环项时显式写“无”

[5] 写作用域合规声明
改动文件清单（路径 + 字节数 + 起止时间）；未触碰清单（ra2render/**、台账、他人 docs、二进制）
另附：目标二进制 MD5/哈希（证明只读）

[6] 门禁实跑输出（原文粘贴，不许概述）
至少：python tools/verify_anchors.py（须 323/323 PASS）
      python tools/audit_bytes.py <你的 claims.txt>（须全 OK）
若无法运行，说明原因与等效替代证据，不得静默跳过

[7] 风险与红线提示
显式回答：本结论是否触及 ①同步语义/命令序 ②随机数消费序 ③存档结构 ④渲染像素等价性
触及者必须写“需要 MP 门控矩阵/真机对拍验收”，禁止宣称“零风险/零 Desync”

[8] 交付物清单
新文档：路径 + 行数；脚本：路径 + 数量；断言：条数；dump：路径 + 大小

[9] 待裁决项（需要人/Lead 决定的分叉，附建议方案与理由）
```

## B. 硬性纪律（违反即回退重做）

1. **禁止伪造实测**：未运行过的验证一律标 [待实测]；把“推测/应有”写成结论视为不合格。
2. **禁止省略证据锚点**：任何结论都要能回溯到 VA+字节或 文件:行。
3. **禁止越界写入**：只写提示词给定的作用域；发现需要改别人的文件时，写进 [3] 勘误清单交 Lead 处理。
4. **禁止把建议写成定谳**：规格、建议、可选方案必须与“已验证事实”分节呈现，用词区分「已定谳 / 已落地生效 / 仅纸面规格 / 建议」。
5. **区分快照**：若任务期间工作区被其他会话改写，回报必须声明快照时点（双快照口径），并给出 mtime/Hash 证据。
6. **长度纪律**：正文 ≤ 4 页（约 1500 字）；细节进交付文档，回报只给结论 + 锚点。
7. **不改他人文档**：除非提示词明确授权；否则只产出“最小订正清单”交 Lead。

## C. 执行方特化附加要求

| 执行方 | 附加要求 |
|---|---|
| **Antigravity (agy)** | 必须贴 `conversation_id`、wrapper 报告的 elapsed；代码任务须贴**编译产物级反汇编验收**片段与旧件备份路径 |
| **DSH 子代理** | 必须贴 `subagentId` 语义的任务号；写文档者须给新文档行数与 claims 条数 |
| **MiMo 桌面** | 必须给 ① 结论表 ② 分级订正清单（P0/P1/P2）③ 门禁原文输出；不接受只有散文式总结 |

## D. Lead 侧对应动作（收到回报后）

1. 与回报**独立复算**（自写 Capstone/字节脚本，不许直接采信）。
2. 越界扫描（mtime/Hash）+ 门禁亲跑。
3. 抽验其断言（至少 5 条跨类别），不符则打回，并列出**具体错误地址/行号**。
4. 登记台账（§九 模板）+ 回填看板（RE_COORDINATION.md）。
5. 只有门禁全绿且抽验通过，才把任务标为 ✅ 已闭环。
