## 1. 🔑 本卡的核心：**三条约束联立**

**三条约束的原文（都要当作"假设"来检验，不是当作结论）**：
```
约束 A（掩码法）：删掉 gamemd 的某一槽后，各类「是否覆盖基类」的**位模式**与 RA2 完全一致
                  ⇒ 候选集跨类交集 = {42, 43, 44}
约束 B（S7 约束法）：末三个 `or eax,0xffffffff` 桩（YRpp: Get_Track_Number / Get_Track_Index /
                  Get_Speed_Accum，三者都 return -1）**必须占据末三槽** ⇒ 插入位 ≤ 46
约束 C（YRpp 声明序）：`YRpp/Interfaces.h` 里 YR 独有的 `ILocomotion_B8` 位于
                  **ILocomotion 自身序 43 = 绝对索引 46**
```

**⇒ 你要判死的是**：**`A ∧ B ∧ C` 能否同时成立？**
- **若能** ⇒ 三条约束都指向同一解，**给出该解**
- **若不能** ⇒ **指出哪一条的假设错了**，并**给出它错在哪**（给字节）

## 3. 纪律（逐条遵守）
1. **判据锚定行首/字段**，不得"关键词出现即算"。
2. **空结果报 `未命中 / INSTRUMENT_FAILED`** + 判据与扫描范围；**不得报"无"或 `0`**。
3. **提取类工具必须带物理边界断言**；**先让它能红，再去修**。
4. **`None` / `[]` / `not_attempted` / 数值 —— 四种输出必须可区分。**
5. **FileOffset 用段映射**（`E-W3-01`）：`.text`/`.rdata`/`.data` = `VA−0x400000`；**`.rsrc`/`.detour` = `VA−0x6FC000`**。
6. 🔴 **跨构建比对虚表只能按「槽索引 + 语义」，不得按「地址相等」**（`E-W3-25`）。
7. 🔴 **收紧判据时必须保留"放宽版"输出做对照**（今晚已有 3 次"收紧后结果变空"的教训）。
8. **不确定就写"不确定 + 缺什么证据"，禁止圆。**
9. **产物原子落盘**（`.tmp` → `assert size > 0` → `os.replace` → 再 `assert`）。**`0 字节` = 失败，不是结果。**
10. 🔴 **只读**：`ra2youli/**`、`ra2bench/**`、`ra2render/**`、`tools/**`、`docs/**`、`out/re_work/agy/**`、`out/re_work/zcode_live/**`（**含 S7 目录**）。
