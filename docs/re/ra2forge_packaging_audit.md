### 2.2 `expandmd98.mix.ra2forge.bak` 语义

- **语义**：仅当目标已存在 `expandmd98.mix` 时，先 `copy2` 成 `.ra2forge.bak` 再覆盖（`cli.py:71-73`）。
- **不是**官方文件备份；是「上一次 mix 包」备份。
- 实测 bak 为 36347 B（≠ 当前 43702 B），内容同为 5 条目 MIX（`audit_dump.txt` §1）。
- **卸载不会**把它改回 `expandmd98.mix`；需人工处理。

### 3.1 方案对比

### 3.2 方案 A — 保持现状 + 补备份/补完整卸载

**改动点（规格级）**：

| 文件:行 | 改前 | 改后 |
|---|---|---|
| `ra2forge/cli.py:68-86` | 仅备份 mix | 安装前若 `BATTLEMD.INI` 存在 → 复制为 `BATTLEMD.INI.ra2forge.bak`；同理 `.MAP` 可选备份 |
| `ra2forge/cli.py` 新增 `uninstall` 子命令 | 无 | 按 `ra2forge_uninstall.txt` 逐个删除；若存在 `.ra2forge.bak` 则还原 |
| `README.md:23-24` | 「卸载=删 expandmd98.mix」 | 改为「用 `python -m ra2forge uninstall`」 |
| `ra2forge/builder.py:87` | 写 MIX 内 `BATTLEMD.INI` | 可保留（无害）或删除（减小包体） |

**迁移（已装用户）**：
1. 备份现有 `ra2youli\BATTLEMD.INI` 为人工存档；
2. 从 `extracted\found_battlemd.ini` 或安装介质恢复官方 `BATTLEMD.INI`；
3. 重装新版 installer（会自动 `.bak`）。

**回滚**：`uninstall` 命令还原 `.bak`；或人工把 `.bak` 改回原名。

**风险**：仍覆盖官方名；与其它 mod 冲突不消。
**验证**：安装后 `sha256(BATTLEMD.INI)` ≠ 官方且存在 `.bak`；卸载后恢复官方哈希。

### 3.3 方案 B — 散装 `BATTLEMD98.INI`（推荐）

**原理** `[实证+推演]`：引擎 `0x52CB90` 用 `FindFirstFileA("BATTLEMD*.INI")` 枚举散装文件并**追加**战役列表（官方注释原文：「Additional files that begin with "BATTLE" will augment this list」）。`BATTLEMD98.INI` 匹配通配且不占官方名。

**改动点（规格级）**：

| 文件:行 | 改前 | 改后 |
|---|---|---|
| `ra2forge/builder.py:63-83` | 生成覆盖式 `[Battles] 1=ALL1 2=SOV1` + 改写 SOV1/ALL1 | **只写追加段**：`[Battles] 1=RA2F1`（或保留索引约定）+ `[RA2F1]` 自有 ID；**不写** `[ALL1]/[SOV1]` 覆盖段 |
| `ra2forge/builder.py:83` | `_write_map_file(out/"BATTLEMD.INI")` | `_write_map_file(out/"BATTLEMD98.INI")` |
| `ra2forge/builder.py:87` | `mix_files["BATTLEMD.INI"]=…` | **删除**该行（MIX 内 ini 为死代码） |
| `ra2forge/cli.py:74-81` | 复制 `*.INI`（含 BATTLEMD.INI） | 只复制 `BATTLEMD98.INI` + `.MAP` |
| `README.md:8,40,65` | 名称混用 | 统一写 `BATTLEMD98.INI` |
| `builder.py:372` INSTALL 文案 | 「overrides the battle list」 | 「appends a new battle entry (official list untouched)」 |

**追加段规格（BATTLEMD98.INI）**：

```ini
; RA2 Campaign Forge - appended battle entry (does NOT override official list)
[Battles]
1=RA2F1

[RA2F1]
CD=2
Scenario=ECH01.MAP
FinalMovie=
Description=钢铁残响（3关）血色黎明
```

> 注意：`[Battles]` 的索引语义（是否与官方文件的 `1=ALL1` 冲突/合并）**需真机复核** —— 见 §6 未闭环 U-MB1-1。

**迁移**：
1. 删除旧 `BATTLEMD.INI`（或还原 `.bak`）；
2. 若无 `.bak`，用 `extracted\found_battlemd.ini` 的 `[ALL1]/[SOV1]` 段重建官方列表；
3. 安装新版（写 `BATTLEMD98.INI`）。

**回滚**：删除 `BATTLEMD98.INI` + `expandmd98.mix` + `.MAP`；官方列表从未被改，无需还原。

**风险**：
- `[Battles]` 索引合并语义未实测（P1）；
- 通配是否大小写敏感（`BATTLEMD98.INI` vs `battlemd98.ini`）（P2）；
- 某些精简版/Mod 启动器可能禁用通配枚举（P2）。

**验证方法**：
1. 装官方 `BATTLEMD.INI` + 散装 `BATTLEMD98.INI`，启动 → 新战役条目应出现且官方两条仍在；
2. 删除 `BATTLEMD98.INI` → 战役列表恢复官方；
3. 全程 `BATTLEMD.INI` 哈希不变。

### 3.4 方案 C — 双轨兼容

**改动点**：A 的备份/卸载 + B 的 `BATTLEMD98.INI` 并存；`expandmd98.mix` 仍带 ini（兼容「只丢 mix」的旧用户）。

**迁移**：同 A，再加装 `BATTLEMD98.INI`。
**回滚**：同 A。
**风险**：双倍冲突面；过渡期结束后应删 A 轨。
**验证**：A/B 轨各自独立可回滚。
