## 四、本轮重大技术突破与定谳亮点

### 1. 寻路算子与阻挡体系核心突破
- **推翻 A* 启发式假说，确证纯 Dijkstra 算子**：
  在 `0x0042CCD0` 循环体内取证证实，原版节点排序完全无距离启发式函数 $h(n)$，且在 `0x004D3E3B` 处硬编码最大展开深度 `0x7D0`（2000 节点）。空旷平原上的波前发散与障碍物前的盲目扩散是掉帧根因；
- **破译 Generation Stamp 免清零机制**：
  在 `0x0042A5B0` 证实 `inc dword ptr [ecx+0x28]` 计数器机制，每次寻路仅耗费几纳秒进行整数自增，比对 Stamp 即刻判别节点访问态，彻底免除 512×512 网格的全图 memset，平摊开销为严格的 $O(1)$；
- **格子阻挡位原子并发定谳**：
  证实 `0x004D3780` / `0x006F4A70` 中的 `OccupationFlags` 读写均为普通标量单字节指令，无任何 `lock` 前缀，依赖逻辑帧单线程串行保障；严禁无锁多线程并发修改；
- **拔除 Jittered Backoff 指针哈希安全漏洞**：
  原案中 `(uintptr_t)pUnit >> 4` 违背联机锁步基本法（ASLR 内存指针跨机分叉必导致 desync），彻底定谳将其替换为全局锁步确定性公式：`(pUnit->UniqueID + CurrentFrame) % 4`。

### 2. 寻敌体系（Greatest_Threat）核心突破
- **严格大于比较链与同分先见原则**：
  取证 `0x006F936B` 处机器码 `3B C1 7E 08`（`cmp eax, ecx; jle skip`），确证仅当候选威胁分严格大于当前最高分时方更新目标。因此同分目标的决议完全依赖枚举先见顺序，空间哈希优化必须严格保序；
- **粗空间网格 20×20 结构数学确证**：
  在 `0x00412B9A` - `0x00412BC0` 证实通过乘法魔数 `0x66666667` 与 `cmp eax, 0x13`（十进制 19）将坐标划分为 20 个区间，证明 `0x00887888` 物理上为 20×20 = 400 桶粗网格单例。

### 3. RLE 与非 RLE Blitter 族核心突破
- **Alpha 128KB 动态缓存表实证**：
  证实 `0x00420140` 处动态分配 `0x20008` 字节（128KB 颜色表 + 8 字节头部），维护 $256 \times 256 \times 2$ 字节的 2D 表并缓存在 `0x0088A084`；`aBuf` 为 `uint16_t*`，取值 0..255 选择行，`idx` 选择列；
- **8 位 RemapDest 族语义闭环**：
  证实 `0x007E5AE0` (`0x004919B0`) 的核心汇编为 `mov cl, [esi]; mov cl, [eax+ecx]; mov [esi-1], cl`，确证其语义为对 RLE 剪影目标像素进行查表换色（`*dst = RemapTable[*dst]`）；
- **非 RLE 族每像素无条件步进实证**：
  证实 `0x00492B55` 处无论 Z 测试是否通过、无论当前像素是否透明，`src`、`dst`、`zBuf` 均无条件同步步进；
- **Clock::Now 零侵入接管架构发现**：
  证实全游戏 35 处统一调用 `0x004093B0`，其内部通过间接跳转 `jmp dword ptr [0x0087E848]` 分发。接管全局高精时钟仅需单次写入数据段函数指针，无需修改 `.text`。
