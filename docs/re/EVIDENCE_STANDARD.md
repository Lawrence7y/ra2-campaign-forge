## 三、可执行校验器（tools/verify_evidence.py）

校验器为全工程提供无人工偏见的机械式合规筛查，代码位于 [`tools/verify_evidence.py`](file:///d:/Project/ra2-campaign-forge/tools/verify_evidence.py)。

### 1. 命令行接口
```bash
# 基本用法：校验指定证据目录（自动关联 ra2youli/ra2render.log 与 except.txt）
python tools/verify_evidence.py <evidence_dir>

# 完整检验：关联存档目录，输出 JSON 与 Markdown，并强制检测崩溃
python tools/verify_evidence.py out/loadbench/shots/calib \
    --log ra2youli/ra2render.log \
    --except-file ra2youli/except.txt \
    --sav-dir ra2youli \
    --json-out out/re_work/evidence_check/result.json \
    --md-out out/re_work/evidence_check/result.md
```

### 2. 退出代码契约
- `0`：**PASS**（全量截图均满足体量、色彩多样性、哈希唯一性，无崩溃，遥测计数非零，存档与日志闭环）；
- `1`：**FAIL / UNVERIFIED**（命中崩溃、伪造、哈希重复、体量不足、遥测零生效或关键凭证缺失）。

## 五、已知局限与人工独立抽验规范

> [!IMPORTANT]
> **工具边界声明**：自动化校验器能够 100% 机械化排查**“运行期崩溃、未生效按键连拍、单色占位伪造、尺寸下溢、遥测全零”**等缺陷，但**无法证明图像未经过后期离线图像篡改合成，亦无法评估画质审美层面的平滑度**。

因此，验收流程严格执行**“两级过滤机制”**：
1. **第一级（机械过滤）**：由独立验证方直接运行 `tools/verify_evidence.py` 对交付目录执行全自动化扫描。只要有一项 FAIL 或 UNVERIFIED，即刻驳回重测，不进入人工环节；
2. **第二级（人工深度抽验）**：在机械过滤判定全项通过后，由验证专家进行人工像素级与语义核对：
   - **画面语义核对**：检查小地图雷达在静止视角下敌方红点是否完全消除；
   - **三态轮廓核对**：检查未侦察建筑是否 100% 隐形、侦察后是否正确常驻、盟军建筑是否正常全彩；
   - **渐变观感核对**：观察 4 帧渐变过渡是否存在锯齿、色斑或通道借位黑斑；
   - **读档恢复核对**：核实读档后 `s_everSeenGrid` 是否按当前局重新盖章，有无跨战局幽灵残留。

**两级过滤均完全达标，且在无崩溃前提下关键遥测计数确证非零，独立验证方才准予签署通过报告，建议项目 Lead 解除功能闸门。**

## 追加 · QC1 W2_20261001 三条机检硬规则（2026-10-01）

> 【W3 勘误 · PATCH_SUGGESTIONS BLK-N3-1】追加机检三条硬规则（SIB scale 口径判 `*8` 须用 `(sib & 0xC0) == 0xC0`；grep 0 命中类断言须带样本与排除范围；实测不存在类断言须带 find 命令原文与时间戳）；依据：QC1 W2_20261001 复核实证；分级：[实证]

1. **SIB scale 口径**：判 `*8` 必须用 `(sib & 0xC0) == 0xC0`（`0x80` 是 `*4`）。
   凡结论形如「全 `.text` 扫描 `reg*8 + disp` **0 命中**」者，须同时写出所用掩码与反例样本，否则视为**未通过复算**。
   实例：同一目标在 `0x80` 口径下 5 命中（全为整型噪声）、在 `0xC0` 口径下 18 命中（含 9 处 FPU），
   而旧结论文本写的是「0 命中」——既非任一口径的输出（`errata/verdicts/verses_offset.md` §2.3）。
2. **「grep 0 命中」类断言必须带命中样本与排除范围**：本轮实测有 4 处「0 命中」断言失效
   （`p223_readiness_check.md:258,275`、`pending_execution_master_table.md:638,670` 称 `GapProt Version` 0 命中；
   实为 `blitter_hooks.cpp:940,3411` + `ra2render.h:338` + `ra2render.ini:191` 各 1 命中，且三处 `ra2render.dll` 二进制含该串）。
   正确写法应区分「**字面 grep 命中**」与「**实现存在**」：本例字面有命中，但 `CreateStream/GapProtVersion/gap_prot_version` **0 命中** ⇒ **无写档实现**（结论不变，论据换掉）。
3. **「实测不存在」类断言必须带 `find` 命令原文与时间戳**：本轮实测 `RESULT_GAP_P21_A3.md` **存在**（23,820 B，mtime 2026-10-01 13:11:34），
   而 `dual_track_status_note.md:218` 与 `pending_execution_master_table.md:638` 仍写「本轮实测仍不存在 / 不存在（本次 `find` 实测）」；
