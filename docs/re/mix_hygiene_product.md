## [0] 一页结论

1. **混合安装（ra2forge + 补丁）的优先级是确定的**：散装 > `langmd` > `language` > `expandmd99…00`（**大号先装=赢**）> `ra2md/ra2` > `cache/local`。ra2forge 占 **`expandmd98`**，被任何 **`expandmd99`** 压过（同 CRC 条目）；压不过 `langmd/language`。
2. **战役注册只认散装 `BATTLEMD*.INI`**：`0x52CBA0` 通配走 `FindFirstFileA`（FS-only），MIX 内 `BATTLEMD98.INI` **永不加载**；`0x52CCCD` 回退官方名 `BATTLEMD.INI` 仅在「目录里一个散装 `BATTLEMD*.INI` 都没有」时触发。`0x46CE10` 按 `[Battles]` 条目名归并、**后装载者覆写**。
3. **安装包现状（本机 ra2youli 快照）可放行，但有 6 项残留**：清单 sha256 与在位文件 **5/5 一致**；槽位仅 `expandmd01`+`expandmd98`（无 99）；`BATTLEMD.INI` 2733B 为官方原文（非 FORGE 覆盖件）；`BATTLEMD98.INI` 追加 `15=RA2F1`。残留见 §2。
4. **安装器「MIX 卫生」清单见 §4**（可直接贴进 `install.py` / INSTALL.txt / 发布门禁）。

## [1] 混合安装：优先级与冲突面（产品加固）

### 1.1 查找优先级（高 → 低）[实证]

| 序 | 来源 | 产品含义 |
|:--:|:---|:---|
| 1 | **散装文件**（游戏目录） | 永远最高；`BATTLEMD*.INI` 唯一可见域 |
| 2 | `langmd.mix` | **改语言/CSF/官方文案时不可被 expandmd 压过** |
| 3 | `language.mix` | 同上 |
| 4 | `EXPANDMD99.MIX … EXPANDMD00.MIX` | **序号大者先装载 ⇒ 同 CRC 赢**（`0x5301BA mov edi,0x63` → `dec edi/jns`） |
| 5 | `ra2md.mix` / `ra2.mix` | 官方资源基座 |
| 6 | `cachemd/cache/localmd/local` / `ecache*` / `elocal*` | 低 |
| 7 | 次级 `conqmd…movies*` | 最低 |

依据：ATLAS §17.2（`0x6BD7EF`/`0x6BD818` lang 先于 `Init`；`0x5301BA–0x53028A` expandmd 循环；FIFO 尾插 `0x5B3DE2/0x5B3E00` + Find 头起 `0x5B44A1`）。

### 1.2 ra2forge 槽位定位

| 产物 | 形态 | 槽位/域 | 冲突面 |
|:---|:---|:---|:---|
| `BATTLEMD98.INI` | **必须散装** | FS 通配 `BATTLEMD*.INI` | 与其它散装 `BATTLEMD*.INI` 抢「后装载者赢」；与官方 `BATTLEMD.INI` **追加共存**（`15=RA2F1`） |
| `expandmd98.mix` | MIX（**只放地图**） | expandmd 槽 **98** | 被 **99+ 压过**；压过 01–97 与 `ra2md/ra2` 同名 |
| `ECH01–03.MAP` | 散装 + mix 双份 | 散装最高 | 散装赢 mix 内同名 |

### 1.3 混合安装冲突面矩阵（ra2forge ⨯ 补丁）

| 对方资产 | 谁赢 | 产品动作 |
|:---|:---|:---|
| 补丁带 `expandmd99.mix`，且内含同名 MAP/资源 | **补丁**（99>98） | 安装前告警；要么改用 99，要么确认无同名 CRC |
| 补丁带 `expandmd97.mix` 及以下 | **ra2forge**（98>97） | 可共存；同名条目 ra2forge 覆盖补丁 |
| 补丁/第三方散装 `BATTLEMD*.INI` | **枚举序后者**（引擎不保证字母序） | **禁止跨包重复战斗 ID**；安装器已告警（`install.py:76-80`） |
| 补丁改写官方散装 `BATTLEMD.INI` | 二者经 `0x46CE10` **按 id 归并**；同 id 后者覆写 | 保留官方文件；本包只追加 `RA2F1` |
| 补丁要改 CSF/语言串 | 只能**散装**或改 `langmd/language` | expandmd98 **改不到** lang 域 |
| 补丁往 MIX 里塞 `BATTLEMD98.INI` | **永不生效** | 卫生项：MIX 内 0 个 INI（FORGE-2 R6 已做） |
| 非补零名 `expandmd9.mix` / `expandmd98.MIX` 大小写 | **整包不被装载** | 卫生项：强制 `EXPANDMD%02d.MIX` |

## [3] 引擎战役注册路径再确认（产品影响）

```asm
0x52CBA0  push "BATTLEMD*.INI"          ; @0x8261A8
0x52CBA9  call [0x7E1208]               ; FindFirstFileA  ★FS-only
0x52CBB1  cmp esi,-1 → je 0x52CCCD      ; 一个都没有才回退
; 每文件: CCFileClass → INIClass::Load(0x4741F0) → 0x46CE10 归并
0x52CCCD  push "BATTLEMD.INI"           ; @0x826198 回退
0x52CCD6  call 0x4739F0                 ; CCFileClass（磁盘→MIX 回落）
0x52CD2C  call 0x46CE10                 ; 同一归并函数
```

| VA | 产品影响 |
|:---|:---|
| `0x52CBA0` | **`BATTLEMD98.INI` 必须散装**；打进 MIX = 静默失效（全镜像无 `"BATTLEMD98.INI"` 字面量） |
| `0x52CCCD` | 官方 `BATTLEMD.INI` 可来自 MIX，但**仅当目录无任何散装 `BATTLEMD*.INI`**。⇒ 迁移**禁止**「删散装官方件指望 MIX 回退」（Lead 已实测推翻：17 个 MIX 均无官方 `BATTLEMD.INI`） |
| `0x46CE10` | 归并键=`[Battles]` 条目名（`_stricmp`）；**后装载者覆写字段**；新对象 `new(0x3A0)`。产品侧：`15=RA2F1` 与官方 1..14 **追加共存**；跨文件重复 ID 会静默覆盖（枚举序未定，U-FORGE2-2） |

**再确认结论**：FORGE-2「散装 `BATTLEMD98.INI` + 仅地图的 `expandmd98.mix`」形态与引擎路径**完全吻合**；产品唯一硬约束是 **ID 唯一 + 散装 INI + 不依赖 MIX 内 INI**。`0x46CE10` 的「按战斗 ID 归并」仍有一层 [推演]（由 `[Battles]` 键名语义 + 同名段覆写行为推出），不影响装机形态结论。

## [4] 安装器「MIX 卫生」清单（可执行）

### A. 装前（Pre-flight）

| # | 检查 | 判据 | 失败动作 |
|:--|:---|:---|:---|
| A1 | 游戏目录存在 `gamemd.exe` | 有 | 拒绝安装（现网 `install.py:95-97`） |
| A2 | 包内有散装 `BATTLEMD98.INI` | 有 | 拒绝（旧包须 rebuild） |
| A3 | `expandmd98.mix` **内部 0 个 `.INI`** | mixlib 枚举 | 拒绝（防 MIX-INI 幽灵） |
| A4 | MIX 文件名两位补零 | `expandmd98.mix` 精确匹配 | 拒绝 `expandmd9.mix` |
| A5 | 扫描 `expandmd00–99.mix` 现存槽位 | 列出 | 记录；**99 存在 → WARN 高优先级** |
| A6 | 扫描目标机 `BATTLEMD*.INI` | 列出 | 标记 legacy 覆盖件 / 第三方冲突 ID |
| A7 | 官方 `BATTLEMD.INI` 若含 `Generated by RA2 Campaign Forge` | 前 400 字节 | WARN「旧覆盖件，须迁移」 |
| A8 | 包内战斗 ID 不与官方 `1..14` / 既有 `BATTLEMD*.INI` 的 ID 重复 | 解析 `[Battles]` | 拒绝重复（改 `campaign.id`） |

| # | 动作 | 现网 |

### C. 装后（Post-check）

| # | 检查 | 判据 |
|:--|:---|:---|
| C1 | 在位 sha256 == 清单 sha256 | 5/5 MATCH（本机已核） |
| C2 | `BATTLEMD98.INI` 含且仅含自有 ID 段 | `[Battles] 15=RA2F1` |
| C3 | 三图 `NextScenario` 链完整、末图 `EndOfGame=yes` | 读回断言（构建期已有，装后再读盘） |
| C4 | 游戏目录 **无** `*.old-pre-migrate` / 双层 `.bak` 堆积 | 警告列表 |

### D. 卸载 / 迁移

| # | 规则 |
|:--|:---|
| D1 | 只删 sha256 仍匹配清单的文件；用户改动则保留（除非 `--force`） |
| D2 | 按清单逆序还原 `.ra2forge.bak` |
| D3 | `--legacy` 额外清旧 mix/散装图/`ra2forge_uninstall.txt`；**无备份的 legacy `BATTLEMD.INI` 默认不删**（`--drop-legacy-battlemd` 才移开） |
| D4 | **禁止**「备份后删除官方 `BATTLEMD.INI`」——正确迁移是 `extracted/found_battlemd.ini` **恢复**（FORGE-2 §附，已实测） |
> 【W3 勘误 · Forge P-6】改前：假定 MIX 内无官方件；改后：嵌套 MIX 内确有官方 `BATTLEMD.INI`（2,733 B / sha256 `7e40691a…`），但回退读取是否生效真机仍未闭环（U-FORGE2-3）；维持恢复规范，理由订正为路径权威与防提取件首行损坏；依据：`battlemd_authority.py` 实测；分级：[实证]
| D5 | 迁移完成后清扫 `*.old-pre-migrate`、多余 `.bak`、`ra2forge_uninstall.txt.pre-migrate.bak` |

### E. 发布门禁（打包方）

1. `BATTLEMD98.INI` 散装；`expandmd98.mix` 仅地图；文件名两位补零。
2. 战斗 ID = `RA2F1`（或设计文件合法 `campaign.id`），不占官方 1..14、不撞 `ALL\d+/SOV\d+`。
3. 官方 `BATTLEMD.INI` 零改动（hash 对照 `extracted/found_battlemd.ini` = `7E40691A…`）。
4. 交付物 sha256 与 `ra2forge_install.json` 一致；无 `*.old-pre-migrate`。
5. 文档写明优先级一句话：「**散装 > langmd > language > expandmd99…00 > ra2md**；99 会压过我们的 98」。
